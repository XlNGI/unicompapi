# UniComp｜项目级 Codex 永久追加规则

> 本文件用于合并到代码仓库根目录的 `AGENTS.md`。  
> 如果仓库已经存在 `AGENTS.md`，不得覆盖原文件，应由 Codex逐条审计、去重和合并。

## 1. 唯一事实来源

发生冲突时按以下优先级执行：

1. 项目负责人最新明确决策；
2. `handoff/UniComp-技术开发启动包-V1.0.0/03-最终UI交接包-已解压/UniComp-AI-最终UI与开发交接包-V1.2.1/`；
3. 仓库内已经审计并标记为 active / frozen 的正式文档；
4. 原始 `docs.rar`；
5. 旧代码、旧 UI、旧归档和历史实现。

不得让旧代码结构、旧组件或实现便利性降低已确认 UI 和产品标准。

## 2. 当前产品边界

- Windows 与 macOS 桌面应用；
- 本地优先；
- 无 UniComp 账号依赖；
- 图片与视频是核心能力；
- 服务商、模型、能力、费用和外发范围动态展示；
- BYOK、自定义兼容接口和本地服务必须平等处理；
- 在线调用前必须显示实际服务、模型、内容、素材、费用和数据离开本机情况。

## 3. 最终一级导航

1. 对话
2. 项目
3. 图片创作
4. 视频创作
5. 任务中心
6. 作品库
7. 模型与服务商
8. 本地设置

不得重新加入“首页”。

## 4. 最终二级导航

### 图片创作

- 快速生图
- 专业生图
- 图片识别
- 图片编辑
- 图片转提示词

### 视频创作

- 快速视频
- 文生视频
- 图生视频
- 基础编辑

以下内容已经废止，不得实现：

- 多图参考独立页面；
- 图片批量创作独立页面；
- 视频批量创作独立页面。

## 5. UI 纪律

- 权威设计图是页面视觉和布局的直接依据；
- 不得擅自更换已确认页面设计；
- 不得增加登录头像、会员、PRO、充值或云同步；
- 不得把页面做成聊天软件、管理后台或 API 调试器；
- 默认深色主题，同时实现语义化浅色主题；
- 组件必须使用 Design Tokens，不允许页面散落硬编码视觉值；
- 不得因为开发方便删除业务状态或透明确认。

## 6. 对话页边界

- 只负责问答、分析和项目上下文整理；
- 不能直接创建图片或视频任务；
- 未保存对话不能被创作页自动读取；
- 保存到项目后，创作页仍需用户主动引用；
- 附件默认只服务于当前对话；
- 不增加直接生成图片、生成视频或提交创作任务按钮。

## 7. 草稿、任务、作品

- 保存草稿不等于创建任务；
- 提示词增强不等于提交生成；
- 进入其他创作页只建立草稿；
- 重试创建新执行记录，不覆盖原失败记录；
- 远端完成不等于作品完成；
- 下载、校验和本地保存完成后才能登记作品；
- 所有失败、取消、重试和版本关系必须可追溯。

## 8. 视频基础编辑

开发前必须阅读：

`docs/09-视频基础编辑技术架构与能力边界-V1.2.1.md`

不得：

- 扩展成专业多轨剪辑器；
- 直接修改原视频；
- 每次编辑都重新编码完整视频；
- 省略任务中心、恢复、校验或硬件回退；
- 因硬件加速失败阻止软件导出。

## 9. 开发方式

- 先读文档和设计图，再修改代码；
- 先审计再重构，不破坏性删除旧代码；
- 长任务必须维护 `PLANS.md` 或等效执行计划；
- 每阶段必须执行 lint、typecheck、unit test、integration test 和 build 中当前仓库可用的项目；
- 未通过验证不得宣称完成；
- 每次完成必须更新开发记录、变更日志和验收结果；
- 发现文档冲突时停止相关实现，记录冲突并按优先级解决，不得自行猜测。

## 10. 禁止事项

- 不得改变已确认产品范围；
- 不得重新规划导航；
- 不得写死未验证模型、价格、时长、数量和能力；
- 不得把密钥写入代码、日志、项目文件或导出包；
- 不得上传用户素材或诊断日志，除非用户明确授权；
- 不得用占位状态伪装真实成功；
- 不得以“暂时实现”为由永久跳过关键状态和安全边界。
