# 资料优先级与禁止事项

## 资料优先级

1. 项目负责人最新明确决策；
2. 最终 UI 与开发交接包 V1.2.1；
3. 合并后的根目录 AGENTS.md；
4. active / frozen 正式开发文档；
5. 最初 Codex 文档归档 docs.rar；
6. 旧代码、旧 UI 和历史归档。

## 严禁

- 用 docs.rar 中已经过期的导航覆盖 V1.2.1；
- 恢复“首页”一级入口；
- 恢复多图参考、图片批量创作或视频批量创作；
- 更换交接包中的权威设计图；
- 把对话页做成直接生成入口；
- 加入登录、会员、充值和云同步；
- 写死服务商、模型、价格、时长、分辨率和数量；
- 直接把 API Key 写入代码或配置仓库；
- 没有本地文件校验就把远端结果标记为作品；
- 用硬件加速失败阻止软件导出；
- 跳过 Windows 或 macOS；
- 在没有测试和构建结果时宣称完成。
