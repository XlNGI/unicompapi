# 建议开发阶段与验收门禁

## 阶段 0｜接管审计与工程基线

验收：

- 文档优先级明确；
- AGENTS.md 合并完成；
- PLANS.md 建立；
- 当前构建和测试结果真实记录；
- 不破坏旧项目。

## 阶段 1｜桌面壳、导航、主题与组件

验收：

- 八项一级导航；
- 正确二级导航；
- 深浅主题；
- Design Tokens；
- Windows / macOS 结构一致；
- 基础组件和路由骨架。

## 阶段 2｜本地领域基础

验收：

- 项目、草稿、素材、文件、任务、作品实体；
- 本地目录和索引；
- 状态机；
- 错误与恢复；
- 不依赖在线服务即可运行基础壳。

## 阶段 3｜全局页面

验收：

- 对话；
- 项目；
- 任务中心；
- 作品库；
- 权威设计图对齐；
- 对话不直接创建任务。

## 阶段 4｜模型与服务商

验收：

- BYOK；
- 凭证安全存储；
- 动态模型目录；
- 能力验证；
- 默认、备用和降级；
- 外发与费用透明。

## 阶段 5｜图片创作

验收：

- 五个最终页面；
- 分析前后状态；
- 提示词三层透明；
- 草稿与正式任务分离；
- 下载、校验和作品登记。

## 阶段 6｜视频创作

验收：

- 快速视频；
- 文生视频；
- 图生视频；
- 真实任务和下载状态；
- 动态能力和费用。

## 阶段 7｜视频基础编辑

验收：

- 独立技术架构文档全部落实；
- 非破坏式；
- 单轨；
- 代理预览；
- 本地导出；
- 硬件回退；
- 恢复和文件校验。

## 阶段 8｜本地设置

验收：

- 十个分类；
- 真实本机状态；
- 高风险操作确认；
- 不自动上传日志；
- 不自动删除项目和作品。

## 阶段 9｜跨平台与完整验收

验收：

- Windows / macOS；
- 崩溃恢复；
- 网络异常；
- 文件丢失；
- 磁盘不足；
- 凭证安全；
- UI 对照；
- 性能和稳定性。

## 阶段 10｜打包与发布准备

验收：

- 安装与卸载；
- 升级；
- 代码签名；
- 许可证；
- 组件分发；
- 日志和诊断；
- 发布回滚。
