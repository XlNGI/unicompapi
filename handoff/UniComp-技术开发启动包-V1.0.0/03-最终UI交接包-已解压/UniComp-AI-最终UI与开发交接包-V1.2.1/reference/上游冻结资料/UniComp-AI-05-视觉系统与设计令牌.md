## 1. 文档目的

本文将已冻结的“A｜深空专业（Deep Space Professional）”视觉方向转化为可执行、可复用、可验收的 Design System 基础令牌。

本文负责确定：

- 深色默认主题与完整浅色主题；
- 颜色语义、内容舞台和媒体判断背景；
- 字体、字号、字重、行高和数字表现；
- 间距、栅格、控件尺寸和桌面信息密度；
- 圆角、边框、分隔、阴影、透明度和层级；
- 图标语言；
- 动效时长和缓动；
- 键盘焦点、对比度与无障碍要求；
- Windows 与 macOS 的共享令牌和差异边界；
- 未验证能力、示例数据、外发和费用状态的统一表达。

本文不设计完整业务页面，不修改已冻结产品功能，不决定任何真实模型、价格、参数上限和生成时长。

## 2. 设计系统总原则

1. **内容优先：** 图片、视频、作品和正在编辑的内容拥有最高视觉权重；
2. **工具后退：** 导航、面板和参数通过稳定色阶与细边框组织，不与作品争抢注意力；
3. **深色专业而非黑客风格：** 默认深色主题沉静、精确，不使用霓虹、网格、发光描边和装饰性渐变；
4. **浅色完整对等：** 浅色主题复用相同语义、尺寸和交互，不是简单反色或后补皮肤；
5. **真实状态：** 状态必须由文字、图标、色彩和操作共同表达，不使用虚假百分比、虚假成功或虚假取消；
6. **能力驱动：** 模型与参数的显示、禁用、限制和未知状态均由动态能力声明控制；
7. **桌面效率：** 标准偏紧凑，但不通过缩小正文、焦点和命中区域换取信息密度；
8. **跨平台一致：** Windows 与 macOS 使用同一令牌和组件结构，只保留平台窗口与系统控件差异；
9. **可访问：** 颜色不是唯一表达，键盘焦点清晰，正文对比度满足长时间阅读；
10. **令牌优先：** 页面和组件不得直接使用任意颜色、尺寸、圆角、阴影和动效值。

## 3. 令牌架构

Design Token 分为四层：

| 层级 | 作用 | 示例 |
| --- | --- | --- |
| 原始令牌 Primitive | 保存不带产品语义的色阶和数值 | `violet.500`、`space.16`、`radius.8` |
| 语义令牌 Semantic | 描述用途并映射深浅主题 | `text.primary`、`surface.panel`、`status.danger.foreground` |
| 组件令牌 Component | 将语义令牌应用到特定组件 | `button.primary.background.default` |
| 页面令牌 Page | 仅描述经过批准的页面区域，不允许自行扩散 | `workbench.stage.background.dark` |

使用规则：

- 页面优先使用语义令牌和组件令牌；
- 原始令牌只能在 Design System 内部映射，不直接写入业务页面；
- 页面令牌数量必须受控，不能按页面临时创建一套颜色；
- 深浅主题切换只替换语义映射，不改变信息结构与组件尺寸；
- 状态、能力、费用和外发令牌必须保持统一含义。

机器可读令牌文件：

`设计令牌/UniComp-AI-Design-Tokens-V0.9.0.json`

## 4.1 主强调色

主强调色使用受控紫蓝色阶。主色承担品牌识别、唯一主操作、选中、焦点和少量关键入口，不承担所有状态。

| `violet.800` | `#493AB8` | 浅色主题深强调 |
| `violet.900` | `#392E8F` | 高对比强调 |
| `violet.950` | `#241D5C` | 深强调背景 |

关键对比：

- `#6D5DFB` 配白色文字约为 4.56:1，可用于标准正文尺寸的主按钮；

禁止：

- 大面积紫蓝背景；
- 彩色发光边框；
- 每张卡片都使用强调色；
- 用主色代替成功、警告或失败语义。

## 4.5 动态能力状态映射

| 能力状态 | 映射语义 | 图标建议 | 文案要求 |

| 已验证支持 | 成功 | 圆形勾选 | 显示验证来源和时间 |

## 4.6 外发、费用与隐私颜色

外发与费用不能被普通信息状态淹没：

- `privacy.external.foreground`：深色 `#FFB36F`，浅色 `#9A4A00`；
- `privacy.external.background`：深色 `#2E1D10`，浅色 `#FFF3E8`；
- `privacy.local.foreground`：映射成功或中性，不使用夸张绿色；
- 费用未知映射警告；
- 跨境或处理地区未知映射需要处理；
- 同服务商重试仍需显示费用范围；
- 接收方变化必须使用“变化提醒”，不能仅改变一行灰色文字。

## 4.7 内容舞台颜色

图片和视频判断需要独立于应用主题的内容舞台背景。

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `stage.dark` | `#090C12` | 暗色作品、视频播放、沉浸预览 |
| `stage.mid` | `#252C36` | 默认中性预览背景 |
| `stage.light` | `#F2F4F7` | 白底电商图、暗部作品判断 |
| `stage.checker.a` | `#DDE2E8` | 透明背景棋盘 A |

规则：

- 用户可在深、灰、浅、棋盘之间切换；
- 舞台背景切换不改变作品本身；
- 缩略图底板根据媒体亮度选择中性背景，避免吞没暗部或白边；
- 选中态使用外围描边，不覆盖作品像素。

# 5. 字体系统

## 5.1 字体栈

### 产品字体

- 拉丁、数字与常用符号：`Inter Variable`；
- 简体中文：`Noto Sans SC Variable`；
- 后备字体：macOS `PingFang SC`，Windows `Microsoft YaHei UI`、`Segoe UI Variable`；
- 最终系统后备：`sans-serif`。

推荐字体栈：

`Inter Variable, Noto Sans SC Variable, PingFang SC, Microsoft YaHei UI, Segoe UI Variable, sans-serif`

说明：

- 设计文档只冻结字体选择和排版规则，不在本阶段分发字体文件；
- 正式打包前由技术与合规确认字体许可、子集和体积；
- 若字体未能随应用打包，系统后备仍需满足同一字号与行高；
- 不使用代码字体制造技术感。

### 等宽字体

仅用于：

- 文件路径；
- 任务 ID；
- 接口地址；
- JSON 或诊断证据；
- 用户明确进入的技术详情。

等宽字体栈：

`JetBrains Mono, SFMono-Regular, Cascadia Mono, Noto Sans Mono CJK SC, monospace`

- 数字、时间、费用和任务数量使用等宽数字特性 `tabular-nums`；
- 状态词不使用全大写英文。

| 全局导航 | 72px 宽 | 紧凑 56px |
| 上下文面板 | 264px 宽 | 220—360px |
| 右侧检查器 | 344px 宽 | 300—440px |
| 中央内容舞台 | 自适应 | 最低 560px，优先获得剩余空间 |
| 任务活动条 | 折叠 36px 高 | 展开约 260px |

## 6.3 控件尺寸

| 尺寸令牌 | 高度 | 用途 |
| --- | --- | --- |
| `control.xs` | 24px | 只读标签、微型工具，不用于关键操作 |
| `control.sm` | 28px | 紧凑工具栏、分段控件、缩略图操作 |
| `control.md` | 32px | 默认按钮、输入、选择器、导航操作 |
| `control.lg` | 36px | 表单主操作、提交前步骤、明显操作 |
| `control.xl` | 40px | 首次引导和少量强主操作 |

命中规则：

- 常规交互最小命中区域 32×32px；
- 图标按钮默认 32×32px；
- 危险、提交、外发确认等关键操作建议至少 36px 高；
- 视觉图标可以小于命中区域；
- 不通过把控件降到 24px 来容纳更多参数。

## 6.4 页面栅格

- 工作台不强制使用网页式等宽 12 栏；
- 项目概览、作品库、模型与设置页可使用 12 栏辅助栅格；
- 1440px 窗口推荐页面内边距 24px、栏间距 16px；
- 1200—1439px 使用 20px 页面内边距；
- 1024—1199px 使用 16px 页面内边距；
- 保护布局使用 12px，但不减少控件命中区域；
- 工作台采用固定辅助面板＋自适应中央舞台；
- 面板内标准内边距 16px，密集工具栏可使用 8—12px。

## 7.1 圆角

| 令牌 | 数值 | 用途 |
| --- | --- | --- |

| `radius.2` | 2px | 小型状态条、细节 |
| `radius.4` | 4px | 紧凑标签、缩略图内操作 |
| `radius.6` | 6px | 默认按钮、输入、菜单项 |
| `radius.8` | 8px | 面板分组、素材卡、任务卡 |
| `radius.10` | 10px | 作品卡、较大容器 |
| `radius.12` | 12px | 对话框、抽屉内大型模块 |
| `radius.16` | 16px | 首次引导和少量空状态容器 |
| `radius.full` | 999px | 状态点、胶囊标签，不用于大按钮体系 |

- 组件默认使用 6—10px；
- 不建立大圆角消费级卡片体系；
- 图片和视频边缘优先保证判断准确；
- 同一层级不混用多种圆角。

## 7.2 边框

| `border.width.selected` | 2px | 媒体和关键选中 |
| `border.width.drop` | 2px | 拖放目标 |

- 常规面板不使用厚描边；
- 焦点边框必须位于组件外侧或不改变布局；
- 缩略图选中描边不得覆盖媒体内容；
- 失败状态边框只用于发生错误的组件，不对整个页面铺红。

# 9. 图标系统

## 9.1 视觉语言

- 默认使用 1.75px 等视觉笔画的线性矢量图标；
- 16px、18px、20px、24px 为主要尺寸；
- 拐角轻微圆润，但不使用幼态圆角图标；
- 图标默认位于 20×20 或 24×24 视图框；
- 选中态允许有限实心填充或强调底板；
- 同一界面不混用线性、彩色 3D、Emoji 和不同透视图标。

## 9.2 图标尺寸

| 令牌 | 尺寸 | 用途 |
| --- | --- | --- |
| `icon.12` | 12px | 状态点旁辅助图标 |
| `icon.14` | 14px | 标签、紧凑元数据 |
| `icon.16` | 16px | 按钮、输入、列表 |
| `icon.18` | 18px | 全局导航和重要工具 |
| `icon.20` | 20px | 标准功能入口 |
| `icon.24` | 24px | 空状态、首次引导、明显入口 |

## 9.3 必须独立的图标语义

- 项目、任务、作品、模型、设置；
- 图片、视频、识别、编辑、转提示词、多图参考、批量；
- 本地、在线、服务商、模型、能力；
- 外发、跨境、费用、凭据、连接；
- 排队、生成、处理、下载、保存；
- 成功、失败、警告、未知、需要处理；

- 版本、对比、父子关系、来源；
- 文件丢失、损坏、移动和外置盘断开。

危险操作必须配合文字，不得只显示红色垃圾桶。

# 10. 动效系统

## 10.1 时长

| 令牌 | 时长 | 用途 |
| --- | --- | --- |
| `motion.instant` | 80ms | 按下反馈、状态点变化 |
| `motion.fast` | 120ms | 悬停、焦点、标签切换 |
| `motion.standard` | 180ms | 常规展开、列表更新 |
| `motion.panel` | 220ms | 面板折叠、抽屉 |
| `motion.modal` | 260ms | 审查层、确认层 |
| `motion.max` | 320ms | 版本对比和有限空间重排 |

常规产品动效不超过 320ms。

## 10.2 缓动

| 令牌 | 曲线 | 用途 |
| --- | --- | --- |
| `easing.standard` | `cubic-bezier(.2, 0, 0, 1)` | 常规移动和尺寸变化 |
| `easing.enter` | `cubic-bezier(.16, 1, .3, 1)` | 浮层进入 |
| `easing.exit` | `cubic-bezier(.4, 0, 1, 1)` | 浮层退出 |
| `easing.emphasized` | `cubic-bezier(.2, .8, .2, 1)` | 拖放、重排、版本对比 |

## 10.3 动效规则

- 面板折叠保持空间连续性；
- 抽屉从触发方向进入；
- 素材拖放和镜头排序应持续显示来源位置；
- 任务状态变化只做短促强调，不循环呼吸；
- 加载允许使用低干扰骨架或进度指示，不使用装饰粒子；
- 不使用页面整体缩放、弹跳和无意义旋转；
- 视频和图片聚焦模式使用亮度及透明度过渡。

## 10.4 减少动态效果

启用系统“减少动态效果”时：

- 取消缩放、位移和弹性；
- 面板和模态使用 0—80ms 淡入淡出；
- 拖拽保留位置提示但不使用惯性；
- 加载保留静态状态与文字；
- 状态变化不能依赖动画才能被理解。

# 11. 焦点、键盘与无障碍令牌

## 11.1 焦点

- 焦点环宽度 2px；
- 焦点与组件边界保持 1—2px 间隔；
- 深色主题焦点色使用 `#9B91FF`；
- 浅色主题焦点色使用 `#5F4BD8`；
- 在同色背景上增加中性外环，保证至少 3:1 可见对比；
- 鼠标点击后可不持续显示强焦点，但键盘导航必须清晰；
- 模态打开后焦点进入，关闭后返回触发点。

## 11.2 对比度目标

- 默认正文与背景至少 4.5:1；
- 关键正文、授权和错误恢复建议达到 7:1；
- 大号文字至少 3:1；
- 图标和控件边界在需要辨识时至少 3:1；
- 禁用内容不承担关键事实；
- 颜色不是状态的唯一表达。

基础令牌对比度抽查：

| 组合 | 约对比度 |
| --- | --- |
| 深色主文字 / 应用背景 | 17.5:1 |
| 深色次文字 / 应用背景 | 10.7:1 |
| 深色三级文字 / 应用背景 | 6.6:1 |
| 深色强调文字 / 应用背景 | 7.2:1 |
| 浅色主文字 / 应用背景 | 16.1:1 |
| 浅色次文字 / 应用背景 | 6.6:1 |
| 浅色三级文字 / 应用背景 | 4.5:1 |
| 主按钮白字 / 主填充 | 4.56:1 |

## 11.3 键盘顺序

统一顺序：

`全局导航 → 项目与页面上下文 → 左侧上下文面板 → 中央内容舞台 → 右侧检查器 → 任务活动条`

覆盖层打开后只在覆盖层内循环。关闭后返回原触发位置。

## 11.4 高对比与系统设置

- 支持 Windows 高对比或强制颜色模式；
- 支持 macOS 增强对比度；
- 支持系统减少透明效果；
- 透明和阴影不能成为分层的唯一方式；
- 系统缩放 100%、125%、150%、200% 均需验证。

## 12.1 示例数据标签

## 12.2 未知状态

- 未知费用必须出现在外发确认中；
- 取消能力未知时不显示“取消任务”承诺，可显示“停止本地等待”或查看说明；
- 生成时间未知时显示已等待时间和最近查询时间。

# 15. 禁止项
