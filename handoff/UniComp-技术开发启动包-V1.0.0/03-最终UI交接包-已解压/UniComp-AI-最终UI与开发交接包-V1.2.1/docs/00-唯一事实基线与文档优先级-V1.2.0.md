# UniComp AI｜唯一事实基线与文档优先级

**版本：** V1.2.0  
**状态：** 最终交接基线  
**适用：** 产品、设计、Codex、前端、桌面端、测试与验收

## 1. 冲突裁决顺序

发生冲突时，按以下优先级执行：

1. 产品负责人在当前项目中的最新明确决策；
2. 产品负责人本轮重新上传并认可的设计图；
3. 此前对话中已经明确确认的默认设计图；
4. 本包 V1.2.0 正式文档；
5. 上游产品与技术冻结规则；
6. 旧归档、旧菜单、候选图和历史方案仅作审计参考。

用户重新上传某页，只表示覆盖该页可能保存错误的版本，不代表其他已确认页面失效或缺失。

## 2. 产品定位

UniComp AI 是本地优先的 Windows / macOS 桌面 AI 视觉创作工作台。

它不是：

- 普通聊天软件；
- 管理后台；
- API 调试器；
- 强制登录、会员或充值平台；
- 用聊天记录替代项目、任务与作品管理的产品。

## 3. 产品核心闭环

`对话沉淀上下文 → 保存到项目 → 图片/视频创作草稿 → 提交前检查与授权 → 任务中心执行 → 下载与校验 → 本地作品库`

## 4. 不可写死的事实

以下内容必须由能力声明、真实验证或运行时状态决定：

- 服务商和模型名单；
- 分辨率、比例、时长、数量与文件限制；
- 参考图片、首尾帧、蒙版和编辑能力；
- 价格、费用估算与计费结果；
- 取消、恢复、结果重取和幂等能力；
- 任务进度、耗时和成功率；
- 本机硬件、系统和媒体组件能力。

## 5. 草稿、任务、作品和文件

- 保存草稿不创建外部任务；
- 提示词增强不创建生成任务；
- 进入其他创作页只创建草稿；
- 用户最终确认后才创建正式任务；
- 重试创建新的执行记录；
- 远端完成不等于作品完成；
- 下载、写入、校验和本地登记成功后才进入作品库；
- 原图、原视频和历史版本不得被覆盖。

## 6. 在线外发

提交前必须展示：

- 实际服务商；
- 实际连接；
- 实际模型；
- 最终提示词；
- 发送的图片、视频、蒙版、区域和项目上下文；
- 费用状态；
- 数据是否离开本机；
- 用户授权状态。

自动路由、备用、降级和升级不能绕过该确认。

## 7. UI 资产规则

- 不再修改任何已确认 UI；
- “业务流程与交互说明区亮色化”方案已撤销；
- 相关测试图、拼图和衍生文件全部废止；
- 本包资源清单中的 `authoritative-frozen` 图片为唯一开发视觉依据；
- 图片中出现旧菜单时，不修改图片像素，代码实现按 V1.2.0 信息架构执行。
