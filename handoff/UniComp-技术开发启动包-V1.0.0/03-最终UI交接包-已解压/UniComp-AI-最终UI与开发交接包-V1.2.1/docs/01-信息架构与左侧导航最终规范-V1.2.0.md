# UniComp AI｜信息架构与左侧导航最终规范

**版本：** V1.2.0  
**状态：** 最终冻结

## 1. 一级导航

固定顺序：

1. 对话
2. 项目
3. 图片创作
4. 视频创作
5. 任务中心
6. 作品库
7. 模型与服务商
8. 本地设置

名称、顺序和语义不得因实现方便、窗口宽度或平台差异而改变。

## 2. 对话

- 独立 AI 问答、分析、整理和上下文沉淀页；
- 只允许将用户明确选择的内容保存到项目；
- 不允许直接创建图片、视频或编辑任务；
- 未保存到项目的对话内容不得被创作页自动读取；
- 当前未提供独立高保真图，Codex 只能按本文件和组件规范实现，不得从旧图猜测。

## 3. 项目

- 取代旧“首页”名称；
- 是启动后的主要项目入口；
- 展示最近项目、最近任务、最近作品和创作入口；
- 项目是素材、上下文、草稿、任务和作品的持续本地容器。

## 4. 图片创作二级菜单

1. 快速生图
2. 专业生图
3. 图片识别
4. 图片编辑
5. 图片转提示词

明确删除：

- 多图参考；
- 图片批量创作。

只在图片创作域展开；当前二级页高亮；视频创作折叠。

## 5. 视频创作二级菜单

1. 快速视频
2. 文生视频
3. 图生视频
4. 基础编辑

明确删除：

- 视频批量创作。

只在视频创作域展开；当前二级页高亮；图片创作折叠。

## 6. 全局管理页

任务中心、作品库、模型与服务商、本地设置：

- 均为独立一级页面；
- 不展开图片或视频二级菜单；
- 不显示创作步骤条；
- 不伪装成项目内临时页面。

## 7. 本地设置第二列分类

固定为：

1. 常规
2. 存储与文件
3. 任务与性能
4. 本地媒体处理
5. 隐私与权限
6. 网络与代理
7. 通知
8. 快捷键
9. 日志与诊断
10. 应用更新

最左侧全局导航保持不动，只切换第二列高亮与中间主体。

## 8. 顶部系统栏

可包含：

- 当前页面或项目；
- 搜索；
- 通知；
- 帮助；
- 设置；
- 深色/浅色主题切换；
- Windows/macOS 原生窗口控制安全区。

禁止：

- 账号头像；
- 登录、会员、Pro、充值和云同步状态；
- 固定模型与固定费用承诺。

## 9. 旧图覆盖规则

- 图中“首页”实现为“项目”；
- 图中缺少“对话”时，代码按本规范补入；
- 图中出现“多图参考/批量创作”时，代码删除；
- 图中导航顺序不一致时，以本文件为准；
- 页面主体布局、视觉和已确认交互保持原样。
