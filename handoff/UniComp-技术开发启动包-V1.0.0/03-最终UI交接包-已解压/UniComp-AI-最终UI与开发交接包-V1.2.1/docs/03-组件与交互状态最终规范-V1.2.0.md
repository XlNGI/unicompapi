## 1. 文档边界

本文负责组件级结构和交互状态，不替代第七阶段的完整页面状态设计。

本文确定：

- 组件组成、尺寸、视觉层级和基础行为；
- 默认、悬停、按下、焦点、选中、禁用、加载、错误和只读状态；
- 键盘、鼠标、触控板和拖拽行为；
- 组件在深色与浅色主题下的统一语义；
- 组件可组合边界；
- 哪些信息必须始终显示，哪些可以渐进披露；
- Codex 后续不得自行改变的组件规则。

本文不完成所有页面的空白、失败、恢复和批量状态；这些在第七阶段统一补齐。

## 2. 通用组件状态模型

除明确不适用外，每个交互组件必须定义：

| 状态 | 含义 | 视觉和交互要求 |
| --- | --- | --- |
| 默认 | 可操作且未交互 | 使用默认表面、边框和文字 |
| 悬停 | 指针停留 | 轻微表面变化，不改变布局 |
| 按下 | 正在点击或拖动 | 80ms 内反馈，不做夸张缩放 |
| 焦点 | 键盘定位 | 2px 高对比焦点环，保持可见 |
| 选中 | 当前值、模式或对象 | 强调描边、背景和图标共同表达 |
| 禁用 | 当前不可操作 | 降低层级，同时提供原因或提示 |
| 加载 | 操作正在进行 | 防重复操作，显示真实状态 |
| 错误 | 输入或操作失败 | 靠近组件显示原因和恢复入口 |
| 只读 | 可查看不可编辑 | 保留可读性，不等同禁用 |

通用规则：

- 加载不等于禁用：用户应知道正在执行什么；
- 只读不降低为难以阅读的灰色；
- 错误不能只显示红色边框；
- 禁用组件若影响流程，必须显示禁用原因；
- 选中态不得覆盖图片和视频内容；
- 焦点不得因追求简洁而被移除。

# 3. 应用外壳组件

## 3.1 系统窗口栏 `AppTitleBar`

组成：

- 应用单色标识；
- 当前窗口或项目简要标题；
- 可选的全局状态摘要；
- Windows/macOS 原生窗口控制安全区。

规则：

- 标准高度 42px；
- 不放主导航和页面级主操作；
- 不显示账号头像作为入口；
- 标题过长时中间省略，完整标题通过工具提示查看；
- 拖动区域不能覆盖可点击控件；
- macOS 左侧保留交通灯安全区，Windows 右侧保留系统控制区。

## 3.2 工作区上下文栏 `WorkspaceContextBar`

组成：

- 项目切换器；
- 当前项目状态；
- 项目内导航：概览、图片、视频、素材与上下文；
- 当前页面次级操作；
- 抽屉和面板开关。

规则：

- 标准高度 50px；
- 项目切换器与账号工作区样式区分；
- 项目路径失效、只读或外置盘断开时持续显示状态；
- 页面主操作不应远离当前创作区；
- 保护布局中次级操作收入更多菜单，项目状态不可被隐藏。

## 3.3 全局导航 `GlobalNavigation`

固定顺序：

`项目 → 任务 → 作品 → 模型 → 设置`

尺寸：

- 标准宽度 72px；
- 紧凑宽度 56px；
- 图标 18—20px；
- 命中区域至少 40×40px；
- 标签使用 12px / 18px。

状态：

- 默认：中性图标和文字；
- 悬停：轻量表面；
- 选中：强调背景＋强调图标＋清晰标签；
- 焦点：独立焦点环；
- 有需要处理任务：图标旁状态点和数量，不使用持续闪烁；
- 禁用：原则上一级导航不禁用，缺少项目时进入页面后显示空状态。

## 3.4 面板 `Panel`

类型：

- 上下文面板；
- 检查器；
- 活动面板；
- 抽屉模式。

组成：

- 面板标题；
- 可选搜索、筛选和更多操作；
- 可滚动内容；
- 可选底部固定操作；
- 折叠和调整宽度控制。

规则：

- 上下文面板默认 264px；
- 检查器默认 344px；
- 面板分隔线支持拖动；
- 双击分隔线恢复默认宽度；
- 达到最小宽度后继续拖动可折叠；
- 窄窗口下两侧面板为互斥抽屉；
- 面板滚动不带动中央内容舞台；
- 底部主操作固定时，不遮挡最后一项内容。

## 3.5 任务活动条 `TaskActivityBar`

折叠高度 36px，展开约 260px。

必须显示：

- 运行中数量；
- 需要用户处理数量；
- 最近发生变化的任务；
- 进入任务中心；
- 展开和收起。

不得显示：

- 虚假百分比；
- 完整任务详情；
- 隐藏费用未知或状态无法确认；
- 把“停止本地等待”写成“任务已取消”。

# 4. 导航与选择组件

## 4.1 项目切换器 `ProjectSwitcher`

必须显示：

- 项目名称；
- 本地状态摘要；
- 展开指示；
- 路径异常或只读状态。

展开内容：

- 最近项目；
- 打开本地项目；
- 新建项目；
- 项目路径与恢复入口。

不显示账号、组织、云同步营销内容。

## 4.2 项目内导航 `ProjectModeTabs`

用于：概览、图片、视频、素材与上下文。

- 使用平级标签或分段导航；
- 高度 32px；
- 选中态使用强调下划线或强调浅底，不能两者叠加过重；
- 不创建第二条永久侧边栏；
- 切换时保留未提交草稿并提示状态。

## 4.3 创作模式切换 `CreationModeSwitcher`

图片模式：生成、识别、编辑、转提示词、多图参考、批量。  
视频模式：文生视频、图生视频、批量、基础编辑。

规则：

- 使用分段控件、标签页或模式菜单；
- 模式不可用时显示原因；
- 切换模式不会自动发送或创建任务；
- 有未保存草稿时保留草稿或明确确认；
- 不使用聊天机器人“新对话”概念。

## 4.4 面包屑 `Breadcrumb`

仅用于层级较深的任务、作品、模型和设置详情。

- 最多显示 3—4 级；
- 中间层可折叠；
- 当前层不可点击；
- 不替代项目内导航。

## 4.5 标签与筛选芯片 `Tag / FilterChip`

类型：

- 普通标签；
- 可移除标签；
- 筛选标签；
- 状态标签；
- 能力标签；
- 发送范围标签。

规则：

- 高度 20—24px；
- 字号 12px；
- 可点击标签至少具有 32px 命中高度；
- 状态标签使用语义色＋图标/文字；
- 不使用彩虹式标签体系。

# 5. 操作组件

## 5.1 按钮 `Button`

### 变体

| 变体 | 用途 | 限制 |
| --- | --- | --- |
| Primary | 当前上下文唯一主操作 | 同一操作区只出现一个 |
| Secondary | 返回、保存草稿、普通确认 | 不与主按钮争夺权重 |
| Ghost | 工具栏、低频操作 | 必须有悬停和焦点 |
| Text | 查看详情、轻量链接 | 不用于危险和提交 |
| Danger | 删除、撤销不可恢复数据 | 必须配合明确文案 |
| Icon | 缩略图、工具栏 | 需要工具提示和可访问名称 |

### 尺寸

- 小：28px；
- 默认：32px；
- 大：36px；
- 突出：40px，仅首次引导等低频场景；
- 图标按钮默认 32×32px；
- 主按钮最小宽度 72px。

### 加载

- 保留按钮宽度；
- 显示动作文字，如“正在提交”；
- 防止重复执行；
- 长时间异步任务不让按钮持续旋转，应创建任务后进入任务状态。

## 5.2 分裂按钮 `SplitButton`

仅在一个主要动作存在少量明确变体时使用，如“导出”与“导出为”。

- 左侧执行默认动作；
- 右侧打开菜单；
- 外发提交和费用确认不得使用分裂按钮，避免误触默认发送。

## 5.3 工具栏按钮 `ToolbarButton`

- 28—32px；
- 图标为主，必要时显示短标签；
- 当前工具选中时显示背景和图标变化；
- 不能只用颜色区分编辑、擦除、蒙版等工具；
- 工具切换不自动覆盖原图。

## 5.4 危险操作

- 低频危险操作放在菜单末尾并分隔；
- 使用完整动作对象，如“删除本地作品”；
- 删除 Key 时提示“不等于服务商侧 Key 已撤销”；
- 取消任务需区分本地停止等待和远端取消状态；
- 不可恢复操作必须使用确认层，不使用普通 Toast 代替确认。

# 6. 输入与参数组件

## 6.1 单行输入 `TextField`

组成：标签、输入区、前后图标、说明、错误和字符限制。

- 默认高度 32px；
- 重要表单可用 36px；
- 标签不依赖占位符；
- 占位符使用三级文字；
- 错误说明靠近字段；
- 只读状态保留复制能力；
- 密钥输入不允许浏览器式自动回显完整值。

## 6.2 多行输入 `TextArea`

- 默认最小高度 96px；
- 可拖动或按内容扩展，但有最大高度；
- 长提示词编辑支持查找、复制和恢复；
- 不使用聊天输入框造型；
- 提交按钮不固定在输入框内部右下角。

## 6.3 提示词编辑器 `PromptEditor`

需要支持：

- 原始输入；
- 系统补充；
- 最终提示词；
- 字数、语言和来源摘要；
- 复制、编辑、恢复、关闭增强；
- 未保存修改提示。

不得把三层提示词折叠成单一黑盒文本框。

## 6.4 搜索框 `SearchField`

- 默认高度 32px；
- 支持 `Esc` 清空或关闭；
- 显示清除按钮；
- 搜索任务、作品和模型时不自动触发外部网络；
- 无结果时显示当前筛选条件和重置入口。

## 6.5 选择器 `Select / Combobox`

- 模型、服务商、参数和项目选择使用可搜索组合框；
- 当前值必须显示名称、状态和必要来源；
- 不可用项保留在列表中并说明原因；
- 切换模型时明确参数变化，不静默丢弃用户意图；
- 模型选择器不得只显示营销名称。

## 6.6 数字输入 `NumberField`

- 允许键盘输入和步进；
- 显示单位；
- 上下限来自能力声明；
- 未知上限不得使用假值；
- 自动校正前需提示；
- 参数不支持时阻止提交并说明原因。

## 6.7 滑块 `Slider`

只用于连续且容易理解的参数，如强度或相对程度。

- 同时提供数值输入；
- 不能用于精确分辨率、数量或计费关键值；
- 模型不支持时隐藏或禁用并说明；
- 键盘方向键可调整。

## 6.8 复选、单选与开关

- `Checkbox`：多个独立选择；
- `Radio`：互斥选项；
- `Switch`：即时生效的二态设置；
- 外发授权、费用同意、跨境确认不得使用预勾选；
- 会立即产生任务或费用的行为不能只用 Switch。

## 6.9 动态参数组 `DynamicParameterGroup`

组成：

- 基础参数；
- 高级参数；
- 模型专属参数；
- 能力来源和验证状态；
- 参数冲突说明；
- 重置为模型默认。

规则：

- 基础参数优先；
- 高级参数折叠；
- 参数切换后重新校验；
- 费用、接收方或素材范围变化时使原授权失效；
- 不支持参数优先隐藏，需要解释时禁用显示。

# 7. 素材与上下文组件

## 7.1 上传区 `UploadZone`

状态：空闲、悬停、拖入、校验中、上传中、失败、只读。

必须显示：

- 支持的素材类别；
- 当前处理为本地还是会外发；
- 校验结果；
- 文件名和来源；
- 失败原因及重新选择。

拖入不等于立即外发。

## 7.2 素材卡 `AssetCard`

组成：

- 缩略图或文件类型预览；
- 名称；
- 来源；
- 用途；
- 是否选中；
- 是否将发送；
- 文件状态；
- 更多操作。

状态：

- 默认；
- 悬停；
- 选中；
- 多选；
- 校验中；
- 文件丢失；
- 外置盘断开；
- 不支持；
- 只读。

选中描边位于卡片外围，不覆盖图像。

## 7.3 素材用途标签 `AssetRoleBadge`

建议语义：主体、商品、场景、风格、构图、首帧、蒙版、声音参考等。

- 用途来自当前任务能力；
- 每张外发图片必须有明确用途；
- 未指定用途时阻止提交或要求确认；
- 不允许仅靠排序推断用途。

## 7.4 发送范围标记 `SendScopeIndicator`

状态：

- 仅本地；
- 将发送；
- 不发送；
- 发送范围变化；
- 目标未知。

必须用图标＋文字表达。不能只用小云朵图标。

## 7.5 上下文项 `ContextItem`

显示：

- 人物、品牌、场景、脚本等类别；
- 来源；
- 进入提示词的内容摘要；
- 是否发送；
- 移除；
- 查看完整内容。

删除当前草稿中的上下文不等于删除项目素材。

# 8. 提示词透明组件

## 8.1 三层审查器 `PromptReview`

必须同一上下文显示：

1. 用户原始输入；
2. 系统补充内容；
3. 最终提交提示词。

推荐结构：

- 顶部三层导航和状态摘要；
- 中央文本编辑区；
- 系统补充列表；
- 来源与变更说明；
- 恢复原始；
- 进入外发确认。

禁止：聊天气泡、隐藏翻译、隐藏模型格式转换、只展示“优化完成”。

## 8.2 系统补充项 `PromptSupplementItem`

每项显示：

- 类别；
- 具体内容；
- 来源；
- 是否可编辑；
- 移除；
- 与用户输入冲突时的警告。

类别示例：上下文、风格、结构、负面约束、翻译、模型格式转换。

## 8.3 变更对比 `PromptDiff`

- 用增删标记而不是纯颜色；
- 长文本支持按段落查看；
- 默认不显示代码式逐字符噪声；
- 用户修改后标记“用户已修改”；
- 恢复操作可撤销。

# 9. 模型、服务商与能力组件

## 9.1 模型选择器 `ModelSelector`

当前值至少显示：

- 服务商；
- 模型；
- 接入类别；
- 验证状态；
- 关键能力摘要；
- 费用状态。

展开列表分组：

- 国内在线；
- 海外在线；
- 本机；
- 局域网；
- 自定义远程兼容接口。

不得静默切换模型。系统推荐必须解释原因。

## 9.2 服务商标记 `ProviderBadge`

显示真实接收主体或接入渠道，不使用 UniComp 品牌遮蔽实际服务商。

状态：官方、用户声明、自定义、身份待核验、不可用。

## 9.3 能力状态 `CapabilityStatus`

使用 Design System 中七类能力状态。

- 标签必须有可读文字；
- 详细来源在悬浮或详情中查看；
- “连接成功”不能显示成“所有能力已验证”；
- 未知状态不自动当作支持。

## 9.4 限制说明 `CapabilityConstraint`

- 紧邻受影响参数；
- 说明账户、地区、版本或模型限制；
- 提供切换模型或查看详情；
- 不用技术错误码作为唯一说明。

## 9.5 凭据状态 `CredentialStatus`

状态：未配置、已保存、验证中、有效、无效、已删除、无法验证。

- 常态只显示掩码和状态；
- 只允许输入、替换、测试和删除；
- 不提供读取明文；
- 诊断和截图不得显示完整 Key。

# 10. 外发与费用组件

## 10.1 外发摘要 `ExternalSendSummary`

必须显示：

- 服务商和接入渠道；
- 模型与验证状态；
- 发送用途；
- 原始输入、系统补充、最终提示词；
- 上下文和素材范围；
- 参数与批量数量；
- 费用、费用未知或服务商账单提示；
- 数据离开本机；
- 跨境或处理地区未知；
- 自动重试授权范围。

## 10.2 费用状态 `CostStatus`

状态：

- 已知估算；
- 费用未知；
- 以服务商账单为准；
- 可能已计费；
- 批量混合费用；
- 重试可能再次计费。

不得用单纯货币图标替代文字结论。

## 10.3 授权操作条 `AuthorizationBar`

- 返回修改；
- 确认发送；
- 可选保存本次范围偏好，但不得扩大授权；
- 确认按钮为唯一主操作；
- 不预勾选；
- 接收方或素材范围变化后原确认失效。

# 11. 任务组件

## 11.1 任务卡 `TaskCard`

至少显示：

- 任务类型；
- 项目；
- 创建时间；
- 服务商和模型；
- 当前真实阶段；
- 结果数量；
- 费用状态；
- 当前可执行动作。

不使用虚假百分比。若只有粗粒度状态，显示阶段、已等待时间、最近查询时间。

## 11.2 任务状态时间线 `TaskTimeline`

节点示例：等待确认、上传、提交、排队、生成、结果处理、下载、本地保存。

每个节点显示：

- 状态；
- 时间；
- 已成功事实；
- 失败证据；
- 可能计费情况；
- 下一步。

## 11.3 取消状态组件 `CancellationState`

必须区分：

- 已停止本地等待；
- 已请求远端取消；
- 远端确认取消；
- 无法确认远端状态；
- 服务商不支持远端取消；
- 取消后费用未知。

## 11.4 批量任务汇总 `BatchTaskSummary`

显示：总数、等待、进行中、完成、失败、取消、需要处理。

- 汇总可下钻到单个子任务；
- 单个失败不覆盖整个批次事实；
- 支持按状态筛选和逐条重试；
- 重试创建新执行记录。

## 11.5 错误详情 `TaskErrorDetail`

必须回答：

1. 错误发生在哪一步；
2. 哪些内容已成功；
3. 是否可能已计费；
4. 是否可能重复发送；
5. 用户下一步能做什么。

技术错误码位于可展开详情中。

# 12. 媒体预览与作品组件

## 12.1 图片预览 `ImageViewer`

支持：

- 缩放、适应、原始尺寸；
- 舞台背景切换；
- 全屏；
- 前后版本；
- 对比；
- 文件状态。

编辑不得覆盖原图。

## 12.2 视频预览 `VideoViewer`

支持：

- 播放、暂停、拖动、音量、全屏；
- 真实时长和文件状态；
- 结果未完成本地保存时明确标记；
- 预览失败和文件丢失状态。

不把基础视频编辑包装成专业剪辑软件。

## 12.3 版本条 `VersionStrip`

- 显示父子关系和同源并列版本；
- 当前版本清晰；
- 缩略图不被选中蒙层覆盖；
- 支持键盘切换；
- 删除版本不自动删除来源任务和素材。

## 12.4 作品卡 `WorkCard`

显示：

- 缩略图；
- 图片或视频类型；
- 名称；
- 创建时间；
- 来源任务；
- 本地文件状态；
- 收藏；
- 更多操作。

状态：正常、选中、多选、文件丢失、损坏、外置盘断开、预览失败、只读。

## 12.5 对比视图 `CompareView`

模式：左右、滑杆、闪烁切换，仅按媒体类型选择适用方式。

- 不自动缩放导致构图错位；
- 显示版本名称和来源；
- 支持退出后恢复原位置；
- 减少动态效果时禁用闪烁模式。

# 13. 反馈与覆盖层组件

## 13.1 内联消息 `InlineMessage`

用于字段、面板和局部错误。

- 靠近发生位置；
- 显示状态图标、标题、说明和操作；
- 不阻断其他不相关区域。

## 13.2 页面状态条 `PageStatusBar`

用于离线、目录只读、项目路径失效、授权失效等持续状态。

- 位于工作区上下文栏下方；
- 不遮挡主要内容；
- 可包含恢复入口；
- 不自动消失。

## 13.3 Toast 通知

只用于已完成的轻量反馈，如“已复制”“已收藏”。

不得用于：

- 费用未知；
- 外发确认；
- 任务失败；
- 本地保存失败；
- 需要用户处理的持久状态。

## 13.4 工具提示 `Tooltip`

- 300—500ms 后出现；
- 键盘焦点同样可触发；
- 不承载关键授权或错误信息；
- 图标按钮必须有可访问名称和工具提示。

## 13.5 菜单与弹出层 `Menu / Popover`

- 菜单项高度 32px；
- 危险操作分组并放末尾；
- 支持方向键、Enter、Esc；
- 不在菜单内放长篇表单；
- 弹出层不得超出窗口安全区。

## 13.6 抽屉 `Drawer`

用于窄窗口下的上下文面板和检查器。

- 两侧抽屉互斥；
- 保留当前滚动和编辑状态；
- 关闭后焦点回到触发点；
- 不把主操作永久藏在抽屉深处。

## 13.7 聚焦审查层 `ReviewLayer`

用于：提示词最终确认、外发与费用确认。

- 保留全局导航和项目上下文，但弱化非当前操作；
- 不使用小尺寸普通弹窗；
- 长文本和素材摘要可滚动；
- 底部确认条固定；
- 返回修改不丢失草稿。

## 13.8 对话框 `Dialog`

用于短决策、危险确认、命名和简单设置。

- 默认宽度 420—560px；
- 长内容应改用审查层或抽屉；
- 主操作明确；
- `Esc` 对不可逆提交应先确认。

# 14. 加载与等待组件

## 14.1 骨架 `Skeleton`

只用于预计结构明确的本地读取和列表加载。

- 使用中性低对比；
- 不无限闪烁；
- 超过合理时间转换为真实状态和说明；
- 不用于远端生成进度伪装。

## 14.2 进度指示 `ProgressIndicator`

类型：

- 确定进度：仅在真实字节上传、下载或本地处理可计算时；
- 不确定进度：显示阶段、已等待时间和状态文字；
- 步骤进度：提示词审查、外发确认等明确步骤。

不得把排队或生成状态伪造成百分比。

## 14.3 防重复执行

- 提交后立即锁定同一动作；
- 创建本地执行记录；
- 明确显示“正在提交”或任务已创建；
- 网络状态无法确认时不允许盲目重复提交；
- 提供查询或查看任务入口。

---

# 15. 拖拽、排序和多选

## 15.1 拖放

- 拖拽对象显示 `shadow.drag`；
- 原位置保留占位；
- 合法目标使用 2px 拖放边框和文字；
- 非法目标显示禁用图标及原因；
- 拖入素材不会立即外发；
- 键盘用户提供替代操作。

## 15.2 排序

用于镜头、素材和版本顺序。

- 显示拖动手柄；
- 拖动只从手柄触发，避免影响文本选择；
- 支持键盘上移、下移；
- 排序变化可撤销；
- 长文本拆镜不会自动提交。

## 15.3 多选

- 使用明确选择框或多选模式；
- 进入多选后显示选择数量和批量操作条；
- 选中态不遮挡缩略图；
- 批量危险操作明确影响范围；
- 混合状态不能显示成全部成功。

---

# 16. 滚动、缩放与指针

- 面板独立滚动；
- 中央媒体预览优先使用缩放和平移，不与页面滚动冲突；
- `Ctrl/Cmd + 滚轮` 只在媒体舞台聚焦时缩放；
- 滚动条保持低干扰，但悬停和拖动时清晰；
- 触控板双指滚动遵循系统习惯；
- 可拖动分隔线使用调整宽度指针；
- 可点击卡片和按钮使用明确指针；
- 文本区域保持文本选择能力。

# 17. 组件组合规则

## 17.1 工作台组合

`AppTitleBar + WorkspaceContextBar + GlobalNavigation + ContextPanel + ContentStage + Inspector + TaskActivityBar`

图片和视频工作台可按页面隐藏一侧面板，但不得建立新外壳。

## 17.2 提交前组合

`PromptReview → ExternalSendSummary → AuthorizationBar`

提示词增强完成不等于任务提交。外发确认前必须重新检查接收方、素材和费用。

## 17.3 任务组合

`TaskCard + TaskTimeline + CostStatus + CancellationState + TaskErrorDetail`

任务事实不能被后续重试覆盖。

## 17.4 作品组合

`WorkCard + Image/VideoViewer + VersionStrip + FileStatus + SourceTaskLink`

远端结果未完成本地保存时不能进入已完成作品状态。

# 18. 组件命名与交付规则

- 英文组件名用于设计源文件和后续实现映射；
- 中文名称用于产品文档和验收；
- 同一组件不按页面复制命名；
- 变体使用 `Component / Variant / State / Size`；
- 图标、状态和主题由属性控制，不复制整套组件；
- 组件源文件需保留 Auto Layout、约束和可访问名称；
- Codex 实现前由第八阶段输出最终属性和状态映射。

推荐命名示例：

- `Button / Primary / Default / MD`；
- `AssetCard / Image / Selected / Standard`；
- `CapabilityStatus / Unknown / SM`；
- `TaskCard / NeedsAction / Standard`；
- `PromptSupplement / Editable / Default`。

---

# 19. 禁止项

1. 按页面复制和修改基础组件；
2. 同一动作在不同页面使用不同图标和颜色；
3. 用普通弹窗承载长提示词审查；
4. 用 Toast 处理持久错误和费用未知；
5. 用 Switch 执行可能产生费用的发送；
6. 预勾选外发、跨境和费用同意；
7. 将连接成功显示成全部能力已验证；
8. 将停止本地等待显示成远端取消成功；
9. 将远端生成成功显示成作品已完成；
10. 让模型选择器只显示模型营销名称；
11. 隐藏每张外发素材的用途；
12. 用聊天气泡展示提示词三层；
13. 用无限旋转或虚假百分比表示异步生成；
14. 因空间不足缩小正文和命中区域；
15. 让 Codex自行新增组件变体、颜色和页面级控件。

# 20. 第五阶段冻结条件

本组件规范只有满足以下条件才能随第五阶段冻结：

1. 应用外壳组件与第三阶段框架一致；
2. 导航、按钮、输入、参数、素材和上下文组件完整；
3. 提示词三层和外发费用组件完整；
4. 模型、服务商、能力和凭据组件完整；
5. 任务、取消、批量和错误详情组件完整；
6. 图片、视频、版本和作品组件完整；
7. 覆盖层、加载、拖拽、多选和键盘行为明确；
8. 每个适用组件具备默认、悬停、按下、焦点、选中、禁用、加载、错误和只读状态；
9. 组件组合可以支持八类核心页面；
10. 产品负责人批准进入高保真页面设计；
11. 正式业务页面开发仍保持禁入。

本文件在产品负责人确认前保持 V0.9.0“待审核”。
