# UniComp AI｜正式页面结构与业务边界总说明

**版本：** V1.2.0  
**状态：** 最终冻结

## 1. 页面地图

### 全局页面
- 对话
- 项目
- 任务中心
- 作品库
- 模型与服务商
- 本地设置

### 图片创作
- 快速生图
- 专业生图
- 图片识别
- 图片编辑
- 图片转提示词：分析前、处理中、分析后

### 视频创作
- 快速视频
- 文生视频
- 图生视频
- 基础编辑

## 2. 专业创作通用结构

专业生图、文生视频、图生视频：

1. 选择素材与项目上下文；
2. 输入用户原始要求；
3. 可选执行提示词增强；
4. 展示用户原始输入、系统补充、最终提交提示词；
5. 动态显示服务、模型与参数；
6. 检查能力、费用、外发范围和数据离开本机；
7. 用户确认后创建任务；
8. 任务中心记录真实执行阶段；
9. 下载、写入、校验并保存；
10. 登记进入作品库。

## 3. 快速创作

快速生图和快速视频：

- 一句话输入；
- 可选单个参考素材；
- 一个主要生成按钮；
- 单结果为默认；
- 轻量显示接收方、费用与外发状态；
- 不显示专业步骤条；
- 仍不得隐藏实际服务、费用和外发事实。

## 4. 图片识别

结果固定分组：

1. 可见事实
2. 模型推断
3. 不确定
4. 无法识别
5. 用户修改

用户修改独立保存，不覆盖模型原始记录。转入图片编辑、专业生图、提示词草稿或图生视频只创建草稿。

## 5. 图片编辑

- 原图不可覆盖；
- 每次成功生成新版本；
- 支持区域、蒙版、必须保持、必须修改和禁止内容；
- 生成前不展示伪造结果；
- 父子版本和来源必须可追溯。

## 6. 图片转提示词

### 分析前
- 只本地载入和读取基础信息；
- 不自动调用 AI；
- 用户选择用途、区域、补充要求和外发范围；
- 用户主动点击后才创建分析任务。

### 分析后
- 展示可见信息、推断、不确定、系统转换和最终提示词草稿；
- 可编辑、保存和重新分析；
- 更换图片、区域、用途或关键要求后，旧结果过期；
- 进入其他创作功能只建立草稿。

## 7. 图生视频

- 选择图片后仅本地加载；
- 图片槽位与角色由模型能力动态显示；
- 用户描述保持、变化、动作、运镜、节奏和景深；
- 不默认先调用识图；
- 提交前完成提示词、费用和外发确认；
- 结果可创建基础编辑草稿，不自动执行编辑。

## 8. 视频基础编辑

- 本地优先、非破坏式、轻量单轨；
- 视频主轨、文字轨、单条背景音乐轨；
- 裁剪、分割、排序、删除、复制、基础变速、画面适配、文字和音乐；
- 不做专业多轨、复杂关键帧、自动字幕、AI 配音和高级特效；
- 自动保存只保存编辑草稿；
- 导出进入任务中心；
- 编码、写入和校验成功后才完成；
- 每次导出形成新文件。

## 9. 模型与服务商

- 服务商、连接、模型三层分离；
- 凭证存入本机安全存储；
- 连接验证与能力验证分开；
- 未验证能力不能标记为已验证；
- 自动路由不能绕过费用与外发确认；
- 删除连接不删除历史任务、作品或来源记录。

## 10. 本地设置

10 个分类页面已冻结。普通设置自动保存；目录迁移、代理、并发、硬件加速、清理、重置和清除数据必须明确确认。

## 11. 适用状态

页面必须覆盖适用的：

- 空白；
- 已加载未执行；
- 草稿保存中/失败；
- 检查中/通过/过期；
- 待授权；
- 费用未知；
- 服务不可用；
- 排队、处理中、远端完成、下载、校验、本地完成；
- 失败、取消状态未知、可重试、不可恢复；
- 源文件丢失、目录不可写、外接磁盘断开。
