# UniComp AI｜视觉系统与 Design Tokens 最终说明

**版本：** V1.2.0  
**结论：** 不改变已确认 UI 的任何视觉值。

## 1. 视觉方向

固定为：

> A｜深空专业（Deep Space Professional）

特征：

- 专业、沉静、可信；
- 内容优先；
- 工具后退；
- 默认深色；
- 完整浅色语义主题；
- Windows/macOS 共用语义和组件结构。

## 2. 本轮明确撤销

“把业务流程与交互说明板统一改为亮色背景”的尝试全部作废，不纳入设计、实现、验收或资源包。

## 3. Token 规则

- 页面只使用语义 Token 和组件 Token；
- 不从截图取色生成页面私有颜色；
- 浅色主题不是简单反色；
- 状态不能只靠颜色表达；
- 焦点、错误、禁用原因、只读可读性必须保留；
- 导航和页面范围不写入视觉 Token，由信息架构管理。
