# UniComp AI｜Codex 实现与验收说明

**版本：** V1.2.1  
**状态：** 可交付执行

## 1. 实现优先级

1. 产品负责人最新决策；
2. 本包 V1.2.0 文档；
3. `resource-manifest.json` 中的权威设计图；
4. 上游冻结文档；
5. 旧归档和候选图只作审计参考。

用户重传覆盖图优先于同页默认确认版本；未重传页面继续使用此前确认默认版本。

## 2. 不允许修改设计

- 不重绘；
- 不改变页面布局；
- 不替换视觉风格；
- 不因实现方便删减区域；
- 不把流程说明板改为亮色；
- 不用生成式方式“修复”截图。

旧菜单只在代码中按新信息架构纠正，不修改图片文件。

## 3. 导航

一级：

`对话 → 项目 → 图片创作 → 视频创作 → 任务中心 → 作品库 → 模型与服务商 → 本地设置`

图片二级：

`快速生图 → 专业生图 → 图片识别 → 图片编辑 → 图片转提示词`

视频二级：

`快速视频 → 文生视频 → 图生视频 → 基础编辑`

不得实现：

- 首页；
- 多图参考；
- 图片批量创作；
- 视频批量创作；
- 账号头像、登录、会员、Pro、充值和云同步。

## 4. 动态能力

不得写死：

- 服务商、连接和模型；
- 价格、费用和耗时；
- 比例、分辨率、时长、帧率和数量；
- 参考素材数量；
- 取消、恢复、重试和重新下载能力；
- 进度百分比和排队时间。

建议统一能力状态：

`verified_supported / declared_supported / user_confirmed / unknown / unsupported / verification_failed / restricted`

## 5. 提示词

必须区分：

- 用户原始输入；
- 系统补充内容；
- 最终提交提示词。

系统补充支持查看、删除、恢复与来源追溯。

## 6. 草稿、任务和作品

- 保存草稿不创建任务；
- 提示词增强不创建生成任务；
- 跨页面进入只创建草稿；
- 最终确认后创建任务；
- 重试建立新执行记录；
- 远端完成后继续下载、写入和校验；
- 本地完成后才登记作品；
- 原始文件和历史版本不得覆盖。

## 7. 外发与凭证

提交前展示服务、连接、模型、文本、素材范围、费用、外发和授权。

API Key、Token、代理密码：

- 存入系统安全存储；
- 不写入项目、任务、日志和导出文件；
- 页面不回显完整值。

## 8. 视频基础编辑

正式实现前，必须先阅读并执行：

`docs/09-视频基础编辑技术架构与能力边界-V1.2.1.md`

该文档是视频基础编辑的独立强制实现依据，至少覆盖：

- 非破坏式编辑草稿和 Schema；
- 单轨时间线与编辑命令；
- 预览与正式导出分层；
- 代理文件；
- 本地媒体引擎适配层；
- 导出计划快照；
- 任务中心状态机；
- 临时文件、原子保存和文件校验；
- 硬件加速失败回退软件处理；
- 源文件重定位；
- 取消、失败、重试和重启恢复；
- Windows 与 macOS 差异边界；
- V1.0 明确不实现范围。

Codex 在输出技术架构、媒体引擎接口、任务状态机、文件策略和测试计划并经确认前，不得直接开发该页面。

## 9. 本地设置

- 最左侧全局导航固定；
- 第二列固定 10 个分类；
- Windows/macOS 不支持的设置动态隐藏；
- 不展示未实现能力；
- 高风险操作必须确认。

## 10. 对话页

权威高保真资源：

`resources/高保真页面/全局页面/00-对话.png`

实现必须遵守：

- 对话用于问答、分析和项目上下文整理；
- 对话不能直接创建图片或视频任务；
- 附件默认只服务当前对话；
- 未保存对话不能被创作页自动读取；
- 用户明确选择内容后生成上下文草稿；
- 用户检查后才能保存到项目；
- 保存到项目后，创作页仍需用户主动选择引用；
- 对话历史和项目、任务、作品分别管理；
- 不加入直接生成图片、生成视频或提交创作任务按钮。

页面结构和视觉必须以权威设计图为准，不得改成普通聊天产品。

## 11. 验收硬条件

1. 导航名称、顺序和展开规则一致；
2. 无已取消模块和账号商业元素；
3. 页面结构符合权威设计图；
4. 未验证能力不写死；
5. 提示词三层可区分和编辑；
6. 外发与费用可见；
7. 不显示虚假进度；
8. 草稿、任务、作品和文件边界正确；
9. 失败、取消、过期、恢复和文件丢失状态真实可处理；
10. Windows/macOS 核心 IA 与视觉一致；
11. 所有权威图片 SHA-256 与清单一致。
