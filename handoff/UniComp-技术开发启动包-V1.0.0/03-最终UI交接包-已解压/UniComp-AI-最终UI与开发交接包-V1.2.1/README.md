# UniComp AI｜最终 UI 与开发交接包 V1.2.1

本包用于交给 Codex、前端、桌面端和测试团队执行。

## 重要结论

- 不再修改任何已确认 UI；
- 用户本轮重传的页面覆盖同页旧版本；
- 未重传但此前已确认的页面继续使用默认确认版本；
- 亮色流程板方案和所有测试改色图已废止；
- 多图参考、图片批量创作、视频批量创作已删除；
- 最终一级导航为：对话、项目、图片创作、视频创作、任务中心、作品库、模型与服务商、本地设置。

## 目录

- `docs/`：最终产品、IA、页面、组件、视觉、Codex 与废止清单；
- `tokens/`：Design Tokens V1.2.0（本次未改动）；
- `resources/`：权威视觉系统与高保真页面；
- `manifests/`：资源清单和 SHA-256；
- `reference/`：上游冻结资料，仅供审计。

## Codex 使用顺序

1. 阅读 `docs/00-唯一事实基线与文档优先级-V1.2.0.md`
2. 阅读 `docs/01-信息架构与左侧导航最终规范-V1.2.0.md`
3. 阅读 `docs/02-正式页面结构与业务边界总说明-V1.2.0.md`
4. 载入 Tokens 与组件规范
5. 按 `docs/08-页面与资源映射表-V1.2.1.md` 对照实现
6. 按 `docs/05-Codex实现与验收说明-V1.2.1.md` 验收
7. 开发视频基础编辑前，必须阅读 `docs/09-视频基础编辑技术架构与能力边界-V1.2.1.md`
