## 🔧 详细修复方案

### 修复 1：时间线不显示 ✅

**问题**：时间线被压缩到高度 0

**原因**：
```css
.uc-generation-history {
  grid-template-rows: minmax(0, 1fr) auto;  /* auto 可被压缩到 0 */
}
```

**修复**：
```css
.uc-generation-history {
  grid-template-rows: minmax(0, 1fr) minmax(192px, auto);  /* 最小 192px */
}
```

**文件**：`src/styles/pages.css` 第 1080 行

---

### 修复 2：图生视频和文生视频布局统一 ✅

**问题**：图生视频右侧有"第二步·生成过程与作品"标题头，文生视频没有

**修复**：移除图生视频的标题头，统一布局结构

**文件**：`src/pages/creation/video/VideoImageWorkspace.tsx` 第 560-578 行

**修改前**：
```tsx
<section className="uc-generation-two-pane__output">
  <header>
    <h2>第二步 · 生成过程与作品</h2>
  </header>
  <Card>
    <GenerationHistory />
  </Card>
</section>
```

**修改后**：
```tsx
<Card className="uc-generation-two-pane__result">
  <GenerationHistory />
</Card>
```

---

### 修复 3：视频缩略图显示封面 ✅

**问题**：视频缩略图是空白的

**原因**：
```tsx
<video preload="none" />  /* 不加载封面帧 */
```

**修复**：
```tsx
<video preload="metadata" />  /* 加载封面帧 */
```

**文件**：`src/components/GenerationHistory.tsx` 第 552 行

---

### 修复 4：卡片尺寸统一 ✅

**问题**："生成中"卡片比其他卡片大

**原因**：
```css
.uc-generation-history__work,
.uc-generation-history__status {
  min-width: 88px;
  max-width: 140px;  /* 最大宽度过大 */
}
```

**修复**：
```css
.uc-generation-history__work,
.uc-generation-history__status {
  width: 88px;       /* 固定宽度 */
  height: 86px;
  min-width: 88px;
  max-width: 88px;   /* 统一为 88px */
}
```

**文件**：`src/styles/pages.css` 第 1264-1275 行

---

### 修复 5：播放视频时抖动 ✅

**问题**：点击播放后，页面布局跳动

**原因**：
```css
video {
  width: 100%;   /* 强制填满，加载后重新计算高度 */
  height: 100%;
}
```

**修复**：
```css
video {
  width: auto;   /* 保持原始比例 */
  height: auto;
  max-width: 100%;
  max-height: 100%;
}
```

**文件**：`src/styles/pages.css` 第 1179-1188 行

---

### 修复 6：全屏按钮可用 ✅

**问题**：全屏按钮点击无效

**原因**：
```css
.uc-generation-history__preview {
  overflow: hidden;  /* 裁剪了视频控件 */
}
```

**修复**：
```css
.uc-generation-history__preview {
  overflow: visible;  /* 控件完整显示 */
}
```

**文件**：`src/styles/pages.css` 第 1144-1150 行

---

### 修复 7：时间线改为项目级历史 ✅

**问题**：新建草稿后，时间线消失（之前的作品看不到了）

**原因**：时间线使用草稿级查询
```tsx
// 旧实现
await storage.listGenerationHistory({
  projectId,
  draftId,    // 只查询当前草稿的历史
  mediaKind
});
```

**修复**：改为项目级查询
```tsx
// 新实现
const result = await storage.listWorks();  // 查询所有作品

// 筛选当前项目和媒体类型，取最近 10 个
const filteredWorks = result.value.items
  .filter((work) => 
    work.projectId === projectId && 
    work.mediaKind === mediaKind
  )
  .sort((a, b) => b.createdAt.localeCompare(a.createdAt))
  .slice(0, 10);
```

**文件**：`src/components/GenerationHistory.tsx` 第 123-156 行、383-416 行

## ⚠️ 注意事项

### 1. 性能考虑
- 当前实现适用于作品数 < 500 的场景
- 如果作品数 > 1000，可能需要后端支持分页查询

### 2. 向后兼容
- 所有修改都是前端的，不影响后端数据
- 已生成的作品数据不受影响
- 用户可以在"作品库"看到所有历史作品

### 3. 未来优化方向
- 可以添加时间线的筛选功能（按日期、按草稿）
- 可以增加"加载更多"支持超过10个作品
- 可以优化缩略图加载性能（懒加载、缓存）
