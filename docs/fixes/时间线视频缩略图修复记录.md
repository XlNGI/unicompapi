# 时间线视频缩略图修复记录

## 问题描述

用户验收时发现时间线存在两个问题：

### 问题 1：视频缩略图没有封面
- **现象**：时间线上的视频缩略图是空白的，看不到视频的第一帧画面
- **影响**：用户无法直观识别历史记录中的视频内容

### 问题 2：卡片尺寸不统一
- **现象**："生成中"状态卡片比其他卡片大，视觉上不协调
- **影响**：时间线排列不整齐，影响美观度

---

## 根本原因分析

### 原因 1：视频预加载设置不当

**代码位置**：`src/components/GenerationHistory.tsx` 第 552 行

```tsx
<video
  preload="none"  // ⚠️ 不加载任何数据，包括封面帧
  src={visible ? localUrl : undefined}
/>
```

`preload="none"` 告诉浏览器不要预加载任何视频数据，包括元数据和第一帧，导致视频缩略图显示为空白。

### 原因 2：卡片最大宽度设置过大

**代码位置**：`src/styles/pages.css` 第 1269 行

```css
.uc-generation-history__work,
.uc-generation-history__status {
  min-width: 88px;
  max-width: 140px;  /* ⚠️ 最大宽度过大，导致卡片尺寸不一致 */
}
```

状态卡片（生成中、失败）的最大宽度设置为 140px，而实际内容较少时会自动收缩，但某些状态下可能撑开到更宽，导致尺寸不统一。

---

## 修复方案

### 修复 1：启用视频元数据预加载

**文件**：`src/components/GenerationHistory.tsx` 第 552 行

```diff
  <video
    aria-label={`${work.name} 视频缩略图`}
    muted
    playsInline
-   preload="none"
+   preload="metadata"
    ref={elementRef as RefObject<HTMLVideoElement>}
    src={visible ? localUrl : undefined}
  />
```

**效果**：
- `preload="metadata"` 让浏览器预加载视频的元数据（时长、尺寸）和第一帧
- 视频缩略图会显示第一帧画面作为封面
- 不会完全加载视频文件，只加载必要的元数据，性能影响很小

---

### 修复 2：统一卡片尺寸为固定 88x86px

**文件**：`src/styles/pages.css` 第 1264-1275 行

```diff
 .uc-generation-history__work,
 .uc-generation-history__status {
   display: grid;
+  width: 88px;
   height: 86px;
   min-width: 88px;
-  max-width: 140px;
+  max-width: 88px;
   place-items: center;
   overflow: hidden;
   border: 1px solid var(--uc-color-border-default);
   border-radius: var(--uc-radius-6);
   background: var(--uc-color-surface-base);
 }
```

**效果**：
- 所有卡片固定为 88px 宽 × 86px 高
- 生成中、失败、成功状态的卡片尺寸完全一致
- 时间线排列整齐美观

---

### 修复 3：优化视频/图片显示方式

**文件**：`src/styles/pages.css` 第 1297-1305 行

```diff
 .uc-generation-history__work img,
 .uc-generation-history__work video {
   display: block;
-  width: auto;
-  min-width: 0;
-  max-width: 138px;
-  height: 84px;
-  object-fit: contain;
+  width: 100%;
+  height: 100%;
+  object-fit: cover;
 }
```

**效果**：
- 视频/图片填满整个 88x86px 卡片
- 使用 `object-fit: cover` 保持画面比例，裁剪溢出部分
- 缩略图更加饱满，视觉效果更好

## 技术细节

### video preload 属性说明

| 值 | 行为 | 性能影响 | 适用场景 |
|---|------|----------|----------|
| `none` | 不预加载任何数据 | 最轻 | 不需要显示封面的场景 |
| `metadata` | 预加载元数据和第一帧 | 轻 | **缩略图显示（推荐）** |
| `auto` | 预加载尽可能多的数据 | 重 | 即将播放的视频 |

我们选择 `metadata` 是最优方案：
- ✅ 可以显示视频封面
- ✅ 性能影响小（只加载几 KB 的元数据）
- ✅ 不会预加载整个视频文件

### object-fit 说明

| 值 | 行为 |
|---|------|
| `contain` | 完整显示，可能留白 |
| `cover` | 填满容器，可能裁剪 |
| `fill` | 拉伸填满，可能变形 |

我们选择 `cover`：
- ✅ 缩略图填满卡片，视觉效果好
- ✅ 保持画面比例，不变形
- ✅ 裁剪溢出部分，适合缩略图展示
