# 视频/图片生成时间线不显示问题修复记录

## 问题描述

在文生视频和图生视频页面，用户生成视频时，右侧的**生成历史时间线**完全不显示，用户无法看到：
- 历史生成记录
- 当前生成状态（生成中、失败等）
- 时间戳标记

对比截图显示，图片生成页面的时间线可以正常显示。

## 根本原因分析

### 问题定位

在 commit `82b0c4c` (fix: refine generation UI layout and parameters) 中，为了优化生成页面的布局，在 `src/styles/pages.css` 中添加了：

```css
.uc-generation-two-pane {
  grid-template-columns: minmax(340px, 0.9fr) minmax(520px, 1.35fr);
  grid-template-rows: minmax(0, 1fr);  /* ⚠️ 问题根源 */
  min-height: 0;
  height: clamp(600px, calc(100dvh - 260px), 840px);
}
```

### 问题链条

1. **外层容器限制**：`.uc-generation-two-pane` 的 `grid-template-rows: minmax(0, 1fr)` 强制整个两栏布局只有 1 行
2. **内部组件布局**：`GenerationHistory` 组件的内部布局为：
   ```css
   .uc-generation-history {
     grid-template-rows: minmax(0, 1fr) auto;
     /* 上方：作品预览区（自适应）
        下方：时间线区域（auto 高度） */
   }
   ```
3. **CSS Grid 收缩行为**：当外层容器高度受限时，`auto` 高度的时间线区域被 CSS Grid 优先压缩，最终高度变为 **0**，完全不可见

### 为什么图片生成正常

图片生成页面（ImageProfessionalWorkspace）使用不同的容器类名 `.uc-image-professional__workspace`，没有受到同样的样式影响。

## 修复方案

### 修改内容

**文件**：`src/styles/pages.css`  
**位置**：第 1080 行  
**修改**：

```diff
 .uc-generation-history {
   display: grid;
   width: 100%;
   height: 100%;
   min-width: 0;
   min-height: 0;
-  grid-template-rows: minmax(0, 1fr) auto;
+  grid-template-rows: minmax(0, 1fr) minmax(192px, auto);
 }
```

### 修复原理

- **修改前**：`auto` 高度的时间线可以被压缩到 0
- **修改后**：时间线区域最小高度 **192px**，确保始终可见
  - 时间线标题：48px
  - 时间线滚动区：140px（最小高度）
  - 边距：约 4px

## 技术细节

### CSS Grid 行高分配规则

1. **`minmax(0, 1fr)`**：可伸缩行，占据可用空间，最小为 0
2. **`auto`**：根据内容自动调整，但可以被压缩到 0
3. **`minmax(192px, auto)`**：最小 192px，有内容时可扩展

### 优先级

当空间不足时，Grid 收缩优先级：
1. 首先压缩 `auto` 行（可以到 0）
2. 然后压缩 `minmax(0, 1fr)` 行
3. 最后才会压缩 `minmax(192px, auto)` 行（但不会低于 192px）
