# 统一视频生成布局修复方案

## 问题描述

根据截图对比发现两个问题：

### 问题 1：时间线不显示（已修复）
文生视频和图生视频页面，生成时右侧的**生成历史时间线**完全不显示。

### 问题 2：图生视频布局不一致
图生视频和文生视频的右侧布局结构不同：

**文生视频**（VideoTextWorkspace）:
```
右侧面板
└── GenerationHistory 组件（无外层标题）
    ├── 作品预览
    └── 生成历史时间线
```

**图生视频**（VideoImageWorkspace）:
```
右侧面板
├── "第二步·生成过程与作品" 标题头  ← 多了这一层
└── Card 容器
    └── GenerationHistory 组件
        ├── 作品预览
        └── 生成历史时间线
```

## 根本原因分析

### 原因 1：CSS Grid 行压缩（问题1）

在 commit `82b0c4c` 中，添加了：
```css
.uc-generation-two-pane {
  grid-template-rows: minmax(0, 1fr);  /* 限制垂直空间 */
}

.uc-generation-history {
  grid-template-rows: minmax(0, 1fr) auto;  /* 时间线auto高度可被压缩到0 */
}
```

### 原因 2：布局结构差异（问题2）

**代码对比**：

**文生视频** (VideoTextWorkspace.tsx:253-265)：
```tsx
<Card className="uc-generation-two-pane__result">
  <GenerationHistory
    draftId={draft.draftId}
    mediaKind="video"
    projectId={draft.projectId}
    refreshKey={historyRefreshKey}
    submissionProgress={submissionProgress}
  />
</Card>
```

**图生视频** (VideoImageWorkspace.tsx:560-578)：
```tsx
<section className="uc-generation-two-pane__result uc-generation-two-pane__output">
  <header className="uc-image-professional__pane-heading">
    <span aria-hidden="true">2</span>
    <div>
      <h2>第二步 · 生成过程与作品</h2>
      <p>提交状态与通过本地校验的作品会保留在这里。</p>
    </div>
  </header>
  <Card className="uc-image-workbench__panel uc-image-workbench__canvas">
    <GenerationHistory ... />
  </Card>
</section>
```

**CSS 影响**：
```css
.uc-generation-two-pane__output {
  grid-template-rows: auto minmax(0, 1fr);  /* 标题auto + 内容区1fr */
}
```

图生视频多了一层标题头，导致：
1. 视觉上不统一（文生视频没有"第二步"标题）
2. 布局层级更复杂
3. 样式类叠加（同时有 `__result` 和 `__output`）

## 统一修复方案

### 方案 A：移除图生视频的标题头（推荐）

**优点**：
- 与文生视频布局完全一致
- 减少冗余的视觉层级
- 代码更简洁统一

**修改**：

**1. 修复时间线压缩问题** (已完成)
```css
/* src/styles/pages.css */
.uc-generation-history {
  grid-template-rows: minmax(0, 1fr) minmax(192px, auto);  /* 时间线最小192px */
}
```

**2. 统一图生视频布局结构**

修改 `src/pages/creation/video/VideoImageWorkspace.tsx` 第 560-578 行：

```diff
-        <section aria-label="生成过程与作品区域" className="uc-generation-two-pane__result uc-generation-two-pane__output">
-          <header className="uc-image-professional__pane-heading">
-            <span aria-hidden="true">2</span>
-            <div>
-              <h2>第二步 · 生成过程与作品</h2>
-              <p>提交状态与通过本地校验的作品会保留在这里。</p>
-            </div>
-          </header>
-          <Card className="uc-image-workbench__panel uc-image-workbench__canvas uc-video-image__canvas">
-            <GenerationHistory
-              draftId={draft.draftId}
-              key={draft.draftId}
-              mediaKind="video"
-              projectId={draft.projectId}
-              refreshKey={historyRefreshKey}
-              submissionProgress={submissionProgress}
-            />
-          </Card>
-        </section>
+        <Card
+          aria-label="生成过程与作品区域"
+          className="uc-generation-two-pane__result uc-image-professional__after-pane"
+        >
+          <GenerationHistory
+            draftId={draft.draftId}
+            key={draft.draftId}
+            mediaKind="video"
+            projectId={draft.projectId}
+            refreshKey={historyRefreshKey}
+            submissionProgress={submissionProgress}
+          />
+        </Card>
```

**修改说明**：
- 移除 `<section>` 和 `<header>` 层级
- 移除"第二步"标题头
- 直接使用 `Card` + `GenerationHistory`，与文生视频一致
- 保留 `uc-image-professional__after-pane` 类以保持样式兼容

### 方案 B：为文生视频添加标题头

**优点**：
- 保持"第一步/第二步"的步骤引导一致性

**缺点**：
- 增加视觉冗余（用户主要关注作品，不需要额外标题）
- 需要修改两个文件
- 布局更复杂

**不推荐原因**：
实际使用中，右侧的"作品预览"和"生成历史"已经有明确的标题，外层的"第二步"标题是冗余的。

### CSS 类名对比

```html
<section class="uc-generation-two-pane__result uc-generation-two-pane__output">
  <header class="uc-image-professional__pane-heading">...</header>
  <Card class="uc-image-workbench__panel uc-image-workbench__canvas uc-video-image__canvas">
    <GenerationHistory />
  </Card>
</section>
```

**修改后（图生视频）**：
```html
<Card class="uc-generation-two-pane__result uc-image-professional__after-pane">
  <GenerationHistory />
</Card>
```

**文生视频（已有）**：
```html
<Card class="uc-generation-two-pane__result uc-image-professional__after-pane">
  <GenerationHistory />
</Card>
```

### Grid 布局修复

```css
/* 外层容器 */
.uc-generation-two-pane {
  grid-template-rows: minmax(0, 1fr);  /* 单行布局 */
}

/* GenerationHistory 内部 */
.uc-generation-history {
  grid-template-rows: minmax(0, 1fr) minmax(192px, auto);
  /* ↑ 预览区自适应         ↑ 时间线最小192px */
}
```
