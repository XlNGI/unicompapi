## 交互验收合同

1. Markdown 按有限时间批次更新，结束时不等待下一批；未闭合代码块在继续输出时允许重新排版，不得丢字或把原始 Markdown 留到终态。生成中图片只显示替代文字，防止未完整输出的图片 URL 发起请求；结束后的图片行为沿用既有组件。
2. 有真实思考内容才显示可展开的思考；无思考的普通模型只显示等待状态，不编造思考文本。
3. 未手动操作时，纯思考默认展开、正文开始后收起。用户主动打开或关闭后，本轮后续增量和终态尊重选择；重启不承诺记住展开偏好。
4. 点击停止即进入等待确认状态；迟到增量不能清掉“正在停止回复…”。取消成功、自然完成或失败均以实际结果收口，不能提前显示已取消。
5. 回看历史时保持阅读位置；点击“回到最新消息”才恢复跟随。输入区与侧栏不因每批输出一起重建。
6. 生成中展开执行记录后，正文仍按独立批次更新，不因执行列表的出现改为整页重绘。
7. 离开项目/对话再返回时，不重新挂载对话页，不显示读取中，不重置当前滚动位置和已展开的执行记录。
