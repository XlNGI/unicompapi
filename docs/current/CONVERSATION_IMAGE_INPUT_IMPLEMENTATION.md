# 对话图片输入实施记录

日期：2026-09-10。当前为维护优化，以负责人直接实施指令、AGENTS.md 顶部维护事实和 PLANS.md 为依据。范围为现有对话输入、附件校验、受控请求及聊天适配器，不新增业务页面。

## 根因与修改

附图分析仍回复“当前会话没有读取其图像内容”，原因是旧链路仅提供图片附件元信息，聊天适配器只发送文本；调整提示词或输入框不能解决传输缺失。

- 单输入框支持粘贴图片、预览和现有拖入附件，发送记录显示附件名；语义工作流和持久化只保存引用，不保存图片 Base64。
- 明确图片问答或选中单图时，普通聊天进入图片输入路径；明确忽略图片则不发送。Office 和已登记 PPT 实际页问答保留原受控路径。
- 主进程校验项目、文件引用、固定 Hash、格式、大小和尺寸，执行前重读并复核授权材料与 Hash。允许单张 PNG/JPEG/WebP/GIF，上限 8 MiB、4000 万像素；拒绝多图、不明、变更和损坏输入。
- OpenAI 兼容适配器把校验过的图片作为临时 image_url data URI 随最后一条用户文本发送；图片请求使用有界传输上限。已发送图片移除旧“未读取”占位，图片及内嵌文字作为不可信参考资料。
- 不兼容通道或最新能力证据明确不支持图片时本地提示。未知模型能力不宣称支持：兼容协议可传输，是否理解取决于服务商与模型；不按名称猜测、不自动换模型。
