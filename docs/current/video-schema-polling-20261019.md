## 实际修改

- H3 合同升级 revision 2。编译器校验缓存文档 SHA-256，从 generate 报价示例提取参数名称和基本类型，不再手工将 regenerate 的 2K/音频开启限制或 understand 的时长限制用于 generate。文档没有完整参数枚举，示例值不作为完整枚举；本地验证基本类型与白名单，实际可用组合必须通过网关实时报价/closed_reasons 校验。不把 MiniMax 原生接口字段混入 WWW 网关，不宣称全量覆盖官网所有动作。
- 保留原 revision 1 的完整合同和指纹，仅供原任务 attach/query/download；新提交拒绝旧版本。新候选使用 revision 2，既有受理路由无需改写或重新生成。
- `maximum_cost_cny` 保持为本地费用授权门禁，带独立 group，在页面移出“模型参数”；H3 显示五个网关参数。费用说明不再只显示未知。报价校验通过后，由 Host 原生窗口展示精确金额，用户确认才提交；默认取消、120 秒超时取消，无确认端口则阻止收费请求。此字段发送前仍移除。两块表单在同一时刻编辑、未失焦就生成时，分别 flush 后只合并已提交字段，避免旧值互相覆盖。
- 有界轮询接受各适配器可重试的查询错误，并允许 network_error 的 GET 传输歧义恢复；尊重有界 Retry-After，传递取消信号。未知收费 POST 保持不重试。每次状态观测直接入库并刷新心跳；不再等轮询结束才额外 GET 一次，避免本已完成却因下一次查询失败丢失结果。
- WWW 已验证成功的私有结果描述在当前原任务上下文中复用。getCompletion/listResults/openDownload 不再重复询问已验证成功状态；重复 attach 保留结果与费用观测状态。待审核保持处理中，显式拒绝/非视频/外站/其他任务 URL 仍阻止接收；待结算不自动结算。
- 私有内容下载对暂时故障最多重试三次，只 GET 固定原任务内容；耗尽后保留 retryable 下载恢复能力。真实文件仍经本地结构、元数据、Hash、原子落盘和正式 Work 登记。
- 恢复流程构造候选服务时不再立即迁移注册表：视频候选初始化延迟到实际 list 时执行，原结果恢复不触发无关写入。
