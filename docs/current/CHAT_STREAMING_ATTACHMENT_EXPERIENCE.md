## 实际改动

- 回答显示：原后端以约 120 ms 合并流式增量，界面直接整批追加。新增仅用于显示的短缓冲，在约 100 ms 内逐帧展开收到的文字，限制重绘频率；完成、停止和减少动态效果偏好下立即显示完整已接收内容。持久化、服务商请求和后台批量写入不变。窗口内容尺寸变化时跟随底部，用户向上浏览时保留滚动位置。
- 文档制作：按实际状态显示“生成内容 → 检查结构 → 排版与保存 → 完成交付”以及简短文字说明。生成本地文件期间串行读取状态，750 ms 间隔、最多 600 次，结束或离开即停止；失败/取消不显示虚假的完成步骤。文档原始结构数据不作为普通回复展示。
- 图片附件：输入框显示 88 px 缩略图与移除按钮；已发送图片显示缩略图，点击打开完整图片预览，可关闭。历史消息重新打开仍通过文件引用获取预览，替代长文件名列表；其他附件改为紧凑文件卡片与省略显示。
- 预览只使用本地受控短时媒体句柄：限定当前项目和已登记 attachments 文件，安全解析路径、检查实际图片格式/大小/尺寸以及已有 Hash，拒绝跨项目或额外路径参数。最大 8 MiB、4000 万像素，未向界面返回绝对路径，不上传文件。

文档过程展示曾向负责人询问“阶段说明或实时正文”，未收到回复时按已告知的阶段说明方案实施。此处是可观察的制作进展，不是模型内部推理或逐字正文预览。
