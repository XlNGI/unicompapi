# 会话语义入口统一与旧业务路由删除（2026-10-17）

本轮属于维护重构。负责人明确要求：LLM 自主判断意图，系统只做边界；删除旧逻辑，不保留两套意图判断。此决定覆盖旧工程记录中“明确请求本地规则处理”“local_compat”“agent_first 可切换”等实现约定。项目级文件、凭证、权限、预算、取消、版本和正式作品门禁继续生效。

范围为会话发送、语义计划、文档工具准入、既有本地草稿恢复入口和相应回归。沿用实际启动目录与当前功能分支，保留原有未提交改动；不覆盖交接包，不合并、提交、推送或发布。

## 实际改动

- 普通输入和后续追问统一进入 Agent 入口。Thread 与 Legacy 仅有存储差异，采用相同语义规划与受控工具执行。删除 Renderer 的独立 Office 发送、模型大纲生成、配图生成和关键词分流入口；旧待处理 Workflow 的文字回复也进入同一个 Agent 入口。
- 语义编排器只消费 LLM 返回的结构化计划；移除本地意图分类、兼容开关、本地取消词、讨论禁写词继承、隐式创建/修改识别及自然语言目标范围解析。模型已返回 ready 时，系统不再因缺少单独的 topic 字段合成业务追问；追问来自模型返回的缺失项。规划不可用、超时或格式错误时明确失败，不在本地猜测并继续执行。取消按钮仍通过 AbortSignal 立即停止；文字取消由 LLM 返回 cancel 计划。
- 模型读取有角色的对话历史、现有任务、已登记文件清单和附件名称。资料以不可信参考数据边界传入；应用仅按固定数量、顺序和字符预算裁剪上下文，不按业务关键词打分。用户委托主题选择、讨论后明确开始等情形由模型理解；系统不拼接历史文字覆盖模型返回的 requirements。
- 文档工具只接受已通过应用校验的 ready 计划，根据结构化 action、documentKind、targetHint 和参数绑定能力。精确文件身份、页/章节范围、内容重组参数和页数要求均从结构化字段取得，不再扫描原句二次判断。
- 删除原本地 Office 意图/大纲规划器、页面数语言解析器、视觉关键词执行器、章节清空捷径、按“面向管理者”替换正文的业务改写，以及自然语言物理页预读取链。旧本地文件恢复只负责新建草稿的编译与保存；文档修改必须走受控工具会话，不再调用旧本地 Revision Agent。保留底层显式补丁类型、真实文件读取和范围验证。
- PPT 的原子修改与视觉修订共用同一受控工具会话，由模型选择工具。真实文件读回统一结构字段；视觉修订成功后撤销该次写能力，模型返回相同设计时保留原 Work，不发布重复版本。Word/Excel 保留具体受控修改工具。
- 保留 Schema、实体范围、项目归属、授权、版本/Hash、幂等、租约、取消和有界预算检查。修复预派发拒绝后过早结算父任务的问题；未知结果仍冻结核对，不自动重发。正式作品仍经过本地文件校验、登记及实际读回。

## 发送时发生什么

1. Host 保存用户消息并校验项目、输入与任务身份。
2. 选定模型进行一次有界语义规划，返回聊天、文档操作、追问/确认或取消等结构化值。
3. Host 校验返回结构、文件实体、授权、版本、范围与预算，绑定本次允许的工具。
4. 执行模型通过受控工具完成计划；文件操作回传真实结果。文字流结束不代表文件已交付。
5. Host 持久化实际文件/Work 与读回收据，再结算任务。不得根据模型口头承诺标记交付。

规划和执行是两种模型调用用途；不再存在本地规则和模型分别判断业务意图的双路由。执行端可继续进行有界工具调用，Host 不替模型挑选业务操作。

## 验证口径与记录

验收使用注入的模型响应和真实本地 Office 文件，不访问真实 Provider、不读取真实凭证、不发送负责人原会话、不修改原项目，也不产生模型费用。固定模型响应夹具用于验证协议与执行边界，不代表对真实 LLM 理解能力的评测。原 73 条语言语料保留，未宣称其为本轮真实模型通过率。

旧关键词规则及旧接口对应测试随实现退役；仍有效的取消、租约、预算、Hash、目标范围、幂等、真实文件和作品登记测试迁移到显式模型计划输入。测试数量减少不能当作旧功能覆盖率等价证明。中间失败与修复后的结果分别记录，不将定向回归重复计入总数。
