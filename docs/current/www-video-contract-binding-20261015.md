## 链路与使用

在现有视频创作页面使用：文生视频选择相应 WWW 型号；图生视频选择本地受控图片、对应模式及型号。视频编辑复用图生视频页面：先清空参考图片，再选择“选择视频进行编辑”，选入一段视频后显示编辑型号；删除视频会恢复图生视频模式。每次只生成一段视频，不新增一级页面。

候选选择固定连接、凭证、模型、适配器、合同指纹和参数版本。Host 在外发素材/询价前检查授权；受控素材通过本地文件与 Hash 校验。图片本轮仅接受 PNG/JPEG；编辑视频必须为真实、已登记 MP4。上传只发送受控字节及合同要求的 X-Model-Id / Profile，不接受模型指定的任意 URL。

流程为受控导入 → 选择精确合同 → 参数和数量校验 → 原 Key 上传/报价 → 校验价格版本及金额 → 单次幂等提交 → 有界原单查询 → 审核/结算状态检查 → 原 Key 私有下载 → 本地 MP4/元数据/Hash 校验 → 原子发布并唯一登记作品。

HappyHorse 1.1 使用价格版本与金额绑定，公开协议和真实报价都不提供 input_digest；其他型号校验摘要、版本及金额。报价后保持原输入和素材不变，提交前重新核对本地 Hash。首尾帧必须正好两张且顺序固定，多参考图按各合同数量限制；不映射为批量任务。

真实 WWW 返回同源绝对私有结果 URL，文档示例使用相对路径；两者均须与原任务、asset_id、本站路径完全匹配，下载地址仍由 Host 构造。第一次 WanAli 文生实测发现这一差异，已修复并通过原任务恢复完成本地登记，没有第二次收费提交。恢复也覆盖已经受理且远端 ID 已固定、因跟踪失败进入失败态的任务；必须重新确认原任务已完成才能恢复本地接收。
