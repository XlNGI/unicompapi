## 执行策略

1. 新 Art Direction 始终要求每页 `designTree`，不因允许模板兜底而接受旧的标签方案作为自主设计成功。有效树经过 constraints/layout/Render Plan/PPTX writer 执行。
2. 初次模型规划失败，只有明确白名单中的设计失败可选择本地基础模板；内容快照冲突、授权、预算、取消、计划完整性与修正范围不属于该白名单。已有父作品或局部修订、明确提供的设计计划不能被这种新建兜底扩大修改范围。
3. 自主编译和渲染修正共用最多两次模型修正。仍有可兜底的渲染问题时，最多再创建一个模板候选；不额外调用模型，不再修正该模板以形成循环。模板也必须通过原结构、页数约束、Office/PDF QA、Hash、原子发布和登记门禁。
4. 候选编号允许 0..3（初次 + 两次模型修正 + 一次模板），最后一个槽位仅接受基础模板计划，不能塞入另一个模型设计或 Layout IR。写前重新解析验证计划；保留每个失败收据、原内容 hash 和连续父链。已登记读回和幂等返回保留真实设计交付模式。
5. 未接入 Art Direction 的旧受控修正流程仍保留原两次上限；不以本次兜底策略取消旧修正能力。
6. 安全进度事实保留 `designPath` 和原因；模型工具响应使用 `designMode=autonomous/template-fallback`，避免通用脱敏器把含 Path 的键删除。提供明确 warning，模型不能将兜底描述为自主设计完成。用户可在详细记录之外看到原因和“已切换为基础模板兜底”，不因此声称文件已经保存。
