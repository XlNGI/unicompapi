2026-10-20，维护修复。沿用从 develop@1142611 建立的 feature/video-h3-audit-20261020。依据负责人本轮审计、参数核对、使用 MiniMax 官方文档补足网关资料以及完成后上传分支的要求、AGENTS.md、PLANS.md 顶部维护事实、当前源码、九份 WWW 网关公开文档和 MiniMax H3 V2 官方文档。范围限于视频合同、参数表单、Application/Host 校验、素材读取、任务快照和对应验收；未覆盖权威交接原件。前两份审计记录及其“待修复/未修改”表述是修复前快照，以本记录说明后续处理。

## 根因和处理

H3 generate 文档只公开五字段示例，未公开完整必填、枚举或范围。旧 Schema 把 required=null 当成可省略且有服务商默认值，允许 parameters={}。前轮使用同一连接的受限实时报价已证明：空参 HTTP 400 / invalid_h3_parameters，完整公开示例 HTTP 200、closed_reasons=[]、报价 7.04 元。这不能证明示例中每个字段都必填，也不能证明只填写其中一项就能生成。截图中只填写时长的组合也没有足够协议证据保证有效。

已按负责人最新要求找到 MiniMax H3 官方 V2 创建接口与指南，将同模型的共享参数约束补入合同。UI、Application/Host 和适配器使用同一 Schema，缺字段、错类型、错误枚举和范围越界在请求报价前拒绝。当前 H3 入口仅支持文生视频，因此采用该场景 ratio 条件必填规则。完整参数仍经网关报价校验，Host 确认原报价后才能收费提交。

| 参数 | 当前合同与来源 |
| --- | --- |
| 提示词 | 必填、非空、最多 7000 字符，按 Unicode 码点计数；来自官方 V2 text 说明与指南 |
| resolution | 必填字符串，768P / 2K；H3-Max 的 480P 不属于 H3 |
| duration | 必填整数，4–15 秒；负数、小数和字符串数值均拒绝 |
| ratio | 文生视频必填字符串，21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16；禁止 adaptive |
| generate_audio / watermark | 网关示例公开的布尔字段，必填性仍 unknown；官方字段名称不同，不擅自映射或套用默认值 |

保留 required / optional / unknown 三种来源事实，H3 未填布尔值显示“未填”，清除后不再称为“服务商默认”。快速与专业入口均提示填写已标记必填项，并提供“填入官方示例”按钮；只有用户点击才填写网关公开示例 resolution=2K、ratio=16:9、duration=4、generate_audio=true、watermark=false。示例不是默认值或完整枚举。官方补充规则已覆盖实际 H3 时长范围，负时长在三层均拒绝；通用校验也不再给其他约束未知的字段凭空添加负时长限制。

| 审计问题 | 实际改动 |
| --- | --- |
| H3 参数未知被误作默认 | 三态要求、显式示例，按官方 H3 V2 补充分辨率/比例/时长必填、类型、枚举和范围；提示词 7000 字符 |
| 报价诊断丢失 | WWW catch 保留已有脱敏 failureDiagnostic；原生运行时、IPC 回执和执行历史保留 HTTP 400 的安全失败原因；删除“检查报价上限”旧提示 |
| 动态参数与历史来源不一致 | Task 新增兼容旧记录的 featureParameters，冻结已校验值及 Schema ID/revision；发送使用该快照，准备后提示词/参数变化会被拒绝 |
| Seedance 提示词错误上限/UTF-16 计数 | 从公开说明取得 20,000 Unicode 字符上限，表单计数与两层请求校验共用；不再由输入框旧 maxLength 截断 emoji |
| 条件规则只在适配器 | 新增有界声明式 requestRules，UI、候选准备和适配器共用帧数/时长选用策略、模式与图片数量规则 |
| Wan 阿里图片透明通道 | 外发前检查 PNG alpha 与 tRNS；拒绝透明通道及截断结构，提示显式转换再导入，不修改原素材 |
| 固定 15 MiB 读取限制 | 适配器向受控读取器传合同单图上限；两个原生组合入口均设置来自现行合同的 Host 上界，其他图片路径保留原默认限制 |

frames 与 duration_seconds 的单选仍是客户端既有策略，现在提前给出一致反馈；不把官网“frames 留空使用 duration_seconds”扩写成已经实测的服务端严格互斥。素材数量按当前生成模式要求一张或首尾两张；产品仍每次仅生成一段视频。

九个现行合同升级为 H3 revision 4、其余 revision 3，新增保留 2026-10-19 合同，既有更早版本也保留，仅供原任务查询/下载。新文档 Seedance MOV、last_frame/first_frame_audio 不会自动进入表单：输出与现有 MP4 接收能力取交集，图片模式与受控支持集合取交集。官网单尾帧表格与说明冲突仍记录为外部合同缺口。其他原有数值类型、枚举、上下界和 frames 29+4k 校验继续保留。
