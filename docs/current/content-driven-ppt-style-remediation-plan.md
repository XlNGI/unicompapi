# 内容驱动的 PPT 样式修补方案

日期：2026-10-06。负责人明确选择目标“按内容设计，每页有变化”。本文件为工程方案，本轮没有修改业务代码或开启新的模型调用；D-01/D-03/D-05 的验收记录保持。

## 目标与当前缺口

目标是模型先理解每页要表达的结论、关系和重点，再决定合适的表达结构，最后由受控渲染器生成可编辑 PPT。整份主题协调，页面随内容变化；结构相同的页面允许相近布局，不按页码轮换模板，也不要求每页为了不同而不同。

最近的 4 页真实文件走 `design-aware`、修正 0 次；每页为 `F7F7F5` 背景、深灰文字、不同字号，没有装饰图形。当前生产元素仅 text/table/chart，普通文本没有填充；背景直接取主题色，设计里的风格语言没有全部落实为实际样式。缺口在设计到可见页面的转换能力，暂停审美 QA 不要求停止样式生成。

## 第一批：把已有设计意图落实为样式

复用 `globalDesign` 的 visualTone/colorDirection/typographyDirection/visualRhythm，以及每页 pageRole/hierarchy/emphasis、contentRoles；补确定性的 Style Compiler，把这些决策解析成字体层级、字重、前景/强调色、背景/表面、留白、表头与图表样式。已有 RenderPlanStyle 的 color/fill/tableHeaderFill/chartColors 和页面 backgroundColor 可复用。

用户明确的品牌色和风格要求优先。模型可提出受控的调色和表达建议，Host 校验支持范围并固化最终主题。主题提供字体、配色和间距规则，页面结构由内容关系决定，不把主题做成固定的整页模板。

首批覆盖封面、观点、证据、指标、表格、对比与流程的已有语义角色。例如指标内容突出数值和单位，对比内容突出两侧对应关系，流程突出顺序，结论突出行动。每个对外支持的风格字段必须有实际作用或明确报告不支持，避免只通过 Schema 就宣称已落实。

## 第二批：让分组和关系形成可见结构

首先利用现有 contentRefs、hierarchy、contentRoles 和已解决区域推导语义分组；需要更细表达时，版本化扩展 Design IR 的 groups/relationships，由模型建议结论组、证据组、对比两侧、顺序步骤等。成员只能引用当前 canonical 内容，Host 校验引用、覆盖、重复、关系与预算；不能让模型增加或改写事实。

在同一个版本化 Layout IR 中增加有界 page.chrome，先支持卡片底板、强调色块/色条、分隔线、流程连接线和节点。它们由 Host 按分组及 solver 结果生成，绑定稳定 page/group/content 归属，并纳入同一个布局 Hash。Render Plan 只作投影，Renderer 按允许的图元确定性写入；不让模型执行代码、加载字体 URL、指定文件路径或提交任意最终坐标。

Chrome 与正文库存区分：正文仍完整且恰好覆盖已有 canonical 来源，系统页码仍恰好一个；背景底板不能冒充正文。承载背景只在已绑定区域、正确 zIndex 和包含关系下允许与其正文叠放，文本互相遮挡、前景意外覆盖与画布越界继续检查。不能为卡片关闭全局重叠检查。

## 第三批：执行策略、设计保持与真实验收

结合 D-02 补 Host 的设计执行策略及能力覆盖记录。用户明确要求的新设计在生成前检查支持范围；不支持时给出具体原因与可用替代。旧模板作为明确的兼容选择，不能以没有落实设计的文件冒充已执行该设计。

风格的实际输出、主题/合同版本与分组/装饰关系进入原有私有候选计划；复用 Layout/Render 的 Hash 和父候选关系，不另建第二份可独立修改的几何。QA 有限修正、后续文本修改和整篇重生成分别明确继承规则；保持已确认主题与设计，避免这些路径又回到纯文字或统一旧模板。精确修改继续维护 physical identity、原文件与版本 pin。

沿用同一个父任务预算、白名单、取消、最大修正次数和原子发布/Work 门禁，不新增 Agent Loop 或无界视觉修正。模型仍负责语义计划，Application/Host 负责校验与权限，Platform 负责受控渲染。

## 验收以文件事实为准

1. 使用包含观点、数据、对比、流程与结论的同一份真实 fixture，验证对应结构与可见元素符合该页设计；不用固定“至少几种版式”或审美分数代替验收。
2. 从实际 PPTX 读回指定颜色、字重、字号、背景、卡片、连接关系、zIndex 与几何；完成本地 Office/PDF 渲染，核对内容完整与既有结构/可读/越界检查。人工可检查实际效果，但不增加模型审美 QA。
3. 修改指定页文字并触发一次受控布局修正，确认相关风格与归属保持、未授权页面和旧文件保留；明确验证整篇重生成的设计继承。
4. 兼容、不支持、写入失败、Hash/版本不符、取消及预算耗尽按原门禁处理，正式作品必须真实核验，不静默交付缺失的设计。

首批聚焦已有文字、表格、图表与受控背景/线条。图片资源和复杂自由构图按 D-04 后续能力单独推进，逐页预览与审美评分保持暂停；不继承真实服务商付费或外发授权。
