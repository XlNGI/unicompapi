## 已证实的核对缺口

1. 旧路由继续保留既有网关 Schema；新绑定路由由明确合同和兼容声明决定参数，不按模型名称推断。旧版/别名模型未按本轮新合同重写。
2. 新增有界本地 JSON Schema 校验支持嵌套、联合类型、必填、枚举、范围和数值精度；官方与动态 UI 共用同一校验器。Kimi 温度/思考及 DeepSeek 工具强制等跨字段条件在绑定参数外发前校验。仅支持已实现 Schema 子集，未知正则规则拒绝，不执行任意代码或远端引用。
3. 官方允许范围和单结果产品投影分开记录。文本会话在外发前拒绝 `n != 1`；不修改官方合同的合法范围。
4. 26 个官方合同已有来源 URL、取得时间和正文 Hash；Qwen Chat 保留为端点级合同，Seedream 与 Seedance 已绑定官方精确模型 ID。`sourceDocumentRevision` 仍只标识工程依据版本，不能替代负责人决定暂缓的旧版/别名模型资料比对。
5. 旧 legacy Gemini/Vidu 图片别名、网关别名和动态 Endpoint ID 的型号归属，需要官方或网关公开资料说明；不能把名字相似视为请求格式一致。

## 官方核对完成标准

每个实际开放的模型/功能应有可追溯的官方来源版本，逐字段比对请求名称、类型、必填、默认、范围、枚举、嵌套/联合类型、输入含义与数量，以及响应、用量、工具续轮和异步生命周期。官方合同、网关自身协议及产品功能投影分别保留。没有来源支持的字段、型号或模式标为待核对；不复制相邻型号，不做付费试错。

资料获取只读取已授权的公开官方 URL，失败不自动重试，不发送企业资料。OpenAI 官方页面返回 HTTP 403；若官方资料不可取得，合同保留未验证状态。核对完成后再修改对应合同及生产请求代码，并用来自已保留官方来源的正负样例验证；真实服务商外部验收另行记账，本轮没有调用生成接口。
