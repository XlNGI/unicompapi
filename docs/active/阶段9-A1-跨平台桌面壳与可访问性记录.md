## 二、B1 依赖修正

Windows 工作区启用 `core.autocrlf=true` 时，Git 索引保存 LF，而工作树可能使用 CRLF。B1 的交接校验此前直接对工作树字节计算 Hash，会把未被篡改的文本误报为失败。

A1 对共享校验器做了最小修正：原始字节 Hash 仍优先匹配；仅对 `.json`、`.md`、`.txt` 文本追加 CRLF 转 LF 后的兼容校验，二进制文件不做任何归一化。B1 自身工具测试和完整交接校验均已重新通过。
