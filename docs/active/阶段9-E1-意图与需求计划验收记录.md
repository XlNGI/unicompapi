# 阶段 9 E1｜LLM 意图与需求计划验收记录

日期：2026-09-01

分支：`feature/phase9-document-intent-plan`

基线：`develop@16772d9`

状态：E1 已完成本地实现与自动化验收；E2-E6 仍为 `planned/not_started`。

## 一、实际修改

- 新增 `DocumentIntentPlan` 严格 Schema，覆盖 `chat/create/revise`、Word/Excel/PPT、主题、受众、目的、页数、风格、资料策略、置信度、缺失项和歧义项。
- 新增 `DocumentRevisionPlan` 严格 Schema，覆盖文档类型、目标提示、页面/章节/表格/单元格范围、白名单补丁操作、保留条件和修正反馈。
- 新增统一解析器，拒绝未知字段、非法枚举、空文本、超长文本、超限列表、非法页码、空操作列表和不受控执行字段。
- 新增 `assessDocumentIntentPlan`，将计划分为 `ready`、`needs_confirmation` 和 `needs_clarification`；外部资料策略没有用户授权时不能直接进入执行。
- 新增 Application 层本地规则快速路径 `buildLocalDocumentIntentPlan`/`assessLocalDocumentIntent`；普通聊天继续走 chat，明确请求不依赖 LLM 即可生成候选计划，内部消息 ID 不进入计划结果。
- 未修改现有 Office 生成链路、IPC、联网搜索、向量检索、工具注册表或 Agent 调度器；完整智能文档扩展仍未完成。
