# 阶段 5 A3｜图片编辑页面记录

日期：2026-07-23

分支：`feature/image-editing-ui`

基线：`cad83dc Merge image understanding workspace`

## 一、任务范围

本次只实现阶段 5 A3 的图片编辑页面，不实现图片转提示词页面，也不新增真实 HTTP 图片编辑适配器。

## 二、实际修改

- 复用 A1 公共 `ImageWorkbenchPage`，为图片编辑增加独立 `ImageEditingWorkspace`。
- 接入 B2 `selectInput/getInput/createInputPreview`，只允许一张受控原图；选择图片不会上传、编辑或创建任务。
- 接入原始编辑要求，以及必须保留、必须修改、禁止出现三类逐行清单。
- 抽出识别和编辑共用的归一化区域控件；预览中的虚线框只来自草稿真实区域数据。
- 蒙版 Asset 可以读取现有 DTO，但 B2 尚未提供受控蒙版选择接口，因此新增选择保持禁用并解释原因。
- 扩展现有图片模型控件，使图片生成和图片编辑按各自用途筛选路由、能力证据和动态参数 Schema。
- 接入 B3 能力预检和接收方、外发范围、费用、最终编辑要求、模型五项确认。
- 分别展示源 Asset、父草稿、父作品和当前结果状态，保证版本关系可追溯。
- 当前没有真实图片编辑适配器，因此提交、保存新版本和继续编辑新分支保持禁用；原图不会被覆盖。
- 转为提示词草稿或进入专业生图时，只调用 B1 `derive` 创建派生草稿，不创建任务。
- 未新增依赖。
