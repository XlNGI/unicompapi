# 阶段 3｜受控本地媒体记录

日期：2026-07-22
分支：`feature/controlled-local-media`
负责人：开发者 B｜本地领域与平台

## 一、本次实现

- 新增按 `workId` 解析已登记作品及其 `FileReference` 的主进程服务。
- 新增五分钟有效的随机媒体句柄，renderer 仅获得 `unicomp-media://local/<token>` URL。
- 句柄注册表在主进程保存真实目标路径，过期后自动失效。
- Electron 注册受控 `unicomp-media` 协议，通过随机令牌读取本地媒体，不把 `file://` 或绝对路径交给 renderer。
- 新增按 `workId` 调用系统文件定位；路径只传给 Electron `shell.showItemInFolder`。
- 只有文件状态为 `available` 且目标为普通文件时才提供媒体句柄。
- 预览句柄当前只支持图片、视频和音频；文档和其他类型不伪装成可预览媒体。

## 二、新增受控 API

```text
createWorkMediaHandle(workId)
revealWorkFile(workId)
```

媒体句柄 DTO 只包含：

- 短期自定义协议 URL；
- 过期时间；
- 媒体类型。

明确不包含项目根目录、文件绝对路径、locator、原始 Hash 或文件系统对象。

## 三、安全边界

- renderer 不能自行把任意本地路径转换成媒体 URL。
- 句柄使用随机 UUID，且过期后返回 404。
- 作品不存在返回 `work_not_found`。
- 文件缺失、断盘、非普通文件或非 `available` 状态返回 `media_unavailable`。
- 系统文件定位不向 renderer 回传目标路径。

## 五、交付给开发者 A

- 作品库缩略图或详情预览先调用 `createWorkMediaHandle(workId)`，不要拼接本地路径。
- “在文件夹中显示”调用 `revealWorkFile(workId)`。
- `media_unavailable` 必须展示真实文件恢复状态，不替换成空白缩略图并假装文件正常。
