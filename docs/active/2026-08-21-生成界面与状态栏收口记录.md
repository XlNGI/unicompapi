日期：2026-08-21

## 实际修改

- 将应用级项目状态栏升级为多任务生产状态栏，使用现有受控任务读模型汇总生成、结果接收、等待处理、需处理和最近完成状态；展开后点击组件外区域自动收起。
- 图片与视频生成生命周期不再创建或显示全局浮层通知，页面进度、底部状态栏、展开面板、作品预览和任务中心继续承载真实状态。
- 文生视频删除镜头新增、编辑、删除和镜头列表 UI；领域层 `shots`、`storyboard` 字段继续保留以兼容存量草稿。
- 图生视频删除主体动作、镜头运动、节奏、景深、必须保持、允许变化和禁止变化等独立控件；原始需求与唯一图片改为图生图同款组合输入，项目上下文和提示词增强使用相同紧凑工具栏，增强后才显示最终提示词卡。
- 生成双栏工作台填满底部项目状态栏上方空间；移除快速视频和图生视频重复的调用记录提示卡。
- 专业生图支持把当前草稿已校验、已登记的本地图片作品拖回参考图槽；仍需重新校验本地文件后才可作为正式输入。
- Qwen Image 尺寸选项由星号分隔改为上游要求的 `<width>x<height>`；文本生图参数模式升至 revision 2，NewAPI 图片适配器接受任意正整数参数模式版本并保持模式 ID 校验。
