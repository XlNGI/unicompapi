## 三、Windows Electron 可见窗口

使用生产构建在 Windows 启动真实 Electron 主窗口，默认窗口为 `1280×820`，检查结果：

- 快速生图、专业生图、图片识别、图片编辑和图片转提示词五个入口均可切换，标题和二级导航状态正确；
- 未打开项目时，五个模式均明确显示项目门禁，不能创建或保存草稿；
- 通过主进程原生文件夹选择器打开已登记本地项目，renderer 未显示项目绝对路径；
- 在真实项目中创建并保存快速生图本地草稿，草稿写入项目受控 JSON 仓储；
- 从快速生图进入专业生图只创建派生草稿，派生来源保留父草稿与父模式，不创建任务；
- 项目负责人统一手工验收确认受控选图、本地预览、草稿保存及派生草稿切换通过；
- 未配置动态模型和真实图片适配器时，页面显示真实未知/不可用状态，提交、重新生成和保存结果保持禁用；
- 任务中心没有出现草稿记录，作品库没有出现未校验结果；
- 联调创建的草稿和临时图片在验收后已清理，未保留测试作品或任务。

负责人手工验收结论记录在 `docs/active/阶段5-开发者A图片页面统一验收记录.md`。单图内容签名、尺寸、字节、SHA-256、Asset/FileReference 登记、短期 `unicomp-media` 预览和异常状态同时由 `image-local-media-controller` 的 5 项平台测试覆盖。

## 四、安全与真实边界

- 只存在五个图片模式，没有恢复多图参考或图片批量创作；
- 选择图片不自动上传、分析、编辑、生成或创建任务；
- 模型、参数、格式、数量、费用和限制均来自动态事实，未知状态保持未知；
- renderer DTO 不包含绝对路径、原始 Hash、凭证、endpoint、远端 operation ID 或内部错误堆栈；
- 没有真实适配器时返回 `adapter_unavailable`，不显示假结果、假进度或假费用；
- 未完成本地下载、类型/字节/Hash 校验和原子落盘的远端结果不能登记为作品；
- 图片编辑不覆盖原图，识别修订不覆盖模型原始记录，重试不覆盖原失败 Execution。

## 五、后置阻断与后续项

- 后台尚未提供图片生成、识别、编辑和图片转提示词的 Base URL、鉴权、接口、错误码、限流、重试、取消、幂等和媒体限制契约；
- 真实 HTTP 适配器必须在后台契约齐备后按用途拆分为小 PR，单独实现和验收；
- 项目素材、项目上下文和已保存对话上下文的候选列表端口继续后置；
- 图片编辑蒙版选择端口和识别结果登记为项目上下文的端口继续后置；
- macOS 文件选择、安全存储、媒体协议和可见窗口实机验证进入阶段 9。

## 六、结论

阶段 5 的本地领域、平台端口、受控 IPC、五个图片页面和 Windows 真实离线联调门禁通过，可以正式收口。该结论只覆盖本地/离线能力，不代表远端图片生成、识别、编辑或图片转提示词服务已经可用。

阶段 6 启动前必须先形成并批准视频创作任务拆分，不直接开始大规模视频业务实现。
