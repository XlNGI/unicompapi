# UniComp 会话意图离线评测报告 V1.0.1

日期：2026-09-04

状态：`passed/offline_baseline`

## 一、评测对象与边界

本报告对应 `conversation-intent-offline-golden@1.0.1`，评测对象为 Application 层本地快速路径 `analyzeLocalConversationIntent`。本次保留 V1.0.0 的 45 条样本，并将真实反馈“帮我只做一个关于龙的ppt”加入版本化回归。

评测未调用真实 Provider、LLM 分类器、联网搜索、向量数据库或收费接口，也未读取真实企业资料和凭证。结果只证明当前 46 条离线样本没有回归，不代表真实用户流量上的总体准确率。

## 二、变更覆盖

- 创建请求允许在礼貌前缀与创建动词之间使用“只、就、先、再、直接、简单地、尽量、最好”等受控副词。
- 精确回归验证“帮我只做一个关于龙的ppt”识别为 `document/create/ppt/ready`。
- Application 工作流回归验证 unknown 状态下，上一轮主题与本轮“制作ppt”能够合并恢复为可执行 PPT 计划。
- 否定句、多交付冲突、多文档目标歧义和破坏性确认沿用既有门禁。

## 四、残余风险

- 当前修复是高置信度本地快速路径增强，不等同于真实 LLM 分类器接入。
- 多轮合并只使用有界的最近消息和受控 Schema，复杂省略、错别字、方言及多语言表达仍需扩大脱敏样本集。
- 真实 Electron 到 Provider 再到 PowerPoint 的端到端人工验收尚未执行。
- 联网搜索仍未配置真实服务商；本次没有 HTTP 外发或费用。
