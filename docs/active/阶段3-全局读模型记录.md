# 阶段 3｜全局任务与作品读模型记录

日期：2026-07-22
分支：`feature/global-read-models`
负责人：开发者 B｜本地领域与平台

## 一、本次实现

- 新增跨最近项目的任务摘要、任务详情、作品摘要和作品详情只读服务。
- 每个项目独立读取 JSON 仓储；单个项目目录不可用或仓储损坏时记录真实问题，不阻断其他健康项目。
- 任务摘要只统计任务明确关联的执行记录，展示最新真实执行状态、时间和重试性。
- 任务详情返回用户原始输入和最终提示词，不返回路径、原始 Hash 或未脱敏内部错误。
- 作品摘要只来自已登记 `Work`，同时读取对应 `FileReference` 的当前文件状态。
- 作品详情返回来源任务、来源执行、父作品、已验证大小和校验时间，不返回文件 locator。
- 任务和作品按创建时间倒序返回，不写死进度、排队时间、费用或远端能力。

## 二、受控 IPC

preload 新增：

```text
listTasks()
getTaskDetails(taskId)
listWorks()
getWorkDetails(workId)
```

所有详情查询只接受领域 ID。renderer 不提交或接收项目根目录、文件绝对路径、原始 Hash 或通用文件系统对象。

## 三、问题隔离

列表响应包含项目级问题：

- `unavailable`：项目目录不存在、外置存储断开或不再是目录；
- `invalid_data`：项目仓储损坏、版本不支持或实体引用不完整。

问题 DTO 仅返回项目 ID、名称和问题类别，不返回内部路径或异常堆栈。
