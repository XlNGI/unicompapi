# 生成历史与任务中心性能优化 PR3｜共享任务 Store 记录

日期：2026-08-28

分支：`feature/shared-task-read-store`

## 实际修改

- 新增 renderer 共享任务只读 Store；全局状态监控、底部任务活动条和任务中心订阅同一 snapshot 与同一个 in-flight `listTasks()` 请求。
- 项目存储通知在 100ms 窗口内合并刷新，focus 与项目会话切换复用同一请求；原有两个独立 5 秒轮询移除，只保留全应用唯一的 60 秒低频健康检查。
- 任务中心恢复结果后主动刷新共享 Store，不再单独发起第三份任务列表请求。
- 消费汇总在主进程按查询周期缓存并合并并发请求；项目事实变更时与其他读快照同步失效。图表请求延后 150ms 发起，不阻塞任务列表首屏。
- 本地容量摘要的周期兜底从 5 秒降为 60 秒，事件驱动刷新保持不变。

## 验收结果

- UI 合同确认两个常驻组件和任务中心均不直接调用 `listTasks()`，唯一调用点位于共享 Store；通知合并、单 in-flight 与 60 秒兜底均有合同门禁。
- 消费汇总测试确认相同并发与后续相同查询复用缓存，显式失效后重新读取项目事实。
- 平台定向测试、UI 合同、TypeScript 与定向 ESLint 通过；完整工程门禁在提交前执行。
- 未调用真实服务商、未读取凭证、未产生收费请求；未启动阶段 10 或 macOS 实机工作。
