日期：2026-09-04
状态：`implemented/contract_only`

## 范围

本记录只覆盖 provider-neutral transport、Application 本地优先编排和 IPC/preload/UI 合同。真实搜索服务商、真实凭证、真实 HTTP 和收费请求不在本次范围内。

## 已实现

- `conversation.web.preview`：校验 workflow、会话 revision，先执行本地 BM25；本地命中足够时联网调用为 0；
- `conversation.web.authorize`：授权绑定 workflow revision、会话 revision 和 `planHash`，只接受 `confirmed: true`；
- `conversation.web.cancel` / `conversation.web.getStatus`：可取消、可查询，过期和 revision 不匹配 fail-closed；
- 主进程默认注入 `UnconfiguredWebSearchTransport`，未配置服务商时返回 `web_provider_unconfigured`，不生成、不登记 Work；
- 外部参考资料以受控引用 DTO 进入会话，包含标题、摘要、来源域名、发布时间和 Hash，不暴露 Key、绝对路径或完整网页。
