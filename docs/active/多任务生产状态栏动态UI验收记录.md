# 多任务生产状态栏动态 UI 验收记录

日期：2026-08-21

开发分支：`feature/remove-text-video-shot-ui`

## 一、实现范围

- 保留应用级唯一项目状态栏，不新增一级页面，也不改变模型选择、生成提交、结果接收或作品登记流程。
- 状态栏读取现有受控 `storage.listTasks()` 任务投影，并监听本地存储变化、项目切换、窗口聚焦及 5 秒兜底刷新。
- 存在生产任务时，底栏汇总真实的处理中与需处理数量；使用不确定进度动画，不展示无法证实的百分比。
- 展开面板最多展示 4 条任务，顺序固定为：需要用户处理、失败、接收并校验、生成中、等待处理、最近完成。
- 生成中展示真实已用时间；接收态覆盖下载、写入、校验与作品登记阶段；完成态仅接受领域层 `completed` 终态，并提示结果已下载、校验和登记到本地作品库。
- 最近完成、普通失败和过期终态仅在 10 分钟内保留于快捷面板；其他运行、等待、恢复或未知提交状态仅在最近 1 小时有活动时显示。最近创建的 Execution 以“等待处理”进入状态栏，完全没有 Execution 的 Task 和取消任务不属于正在生产；完整历史继续由任务中心承载。
- 左侧“最近任务活动”和底部生产状态栏复用同一投影口径，不再把全部历史失败永久累计为“需处理”。
- 图片与视频生成的提交中、生成中、成功、失败、状态待确认和结果待接收均不再创建或渲染全局浮层通知，状态统一由页面进度、底部状态栏、展开面板、作品预览和任务中心承载。全局通知层移除生成任务轮询升级逻辑，并对 `image-generation:*` / `video-generation:*` ID 做兜底拒绝；普通非生成通知不受影响。
- 失败或异常任务提供“去处理/查看详情”入口，已完成任务提供“查看作品”入口；未伪造当前后端不存在的通用重试操作。
- 面板支持展开/收起；展开后点击面板与底栏以外的页面区域会自动收起，面板内部按钮与底栏操作不误触关闭；同时保留键盘焦点、窄宽响应式布局和减少动态效果偏好。

## 二、验证结果

- 多任务排序、计数、终态与活跃窗口、未执行任务排除及未知状态失败关闭单元测试 5 项通过。
- 生成通知目标契约测试覆盖提交面板零通知依赖、全状态生成通知拒绝、任务轮询升级移除、页面状态保留与普通应用通知不受影响。
- 完整 UI 契约测试 277 项通过，0 失败、0 跳过。
- TypeScript、全量 ESLint 与生产构建通过；构建仅保留既有 Vite 大分块提示。
- 浏览器真实 React 渲染覆盖 `1280×720` 与项目最小支持宽度 `800×720`：展开面板均在视口内，页面和任务行无横向溢出；收起后只保留 48px 汇总栏。

## 三、边界

- 未调用真实服务商、未读取凭证、未产生收费请求。
- 未改变 Task、Execution、Work 的领域状态与本地正式作品门禁。
- 阶段 10 未启动；macOS 仍为延期目标，不声明已支持。
