# 多服务商功能路由 M5｜UI 验收收口记录

日期：2026-08-04

分支：`feature/ui-provider-acceptance-closeout`

来源：`develop@61fe3c1`

实现提交：`5a29edd`

## 一、范围与边界

本支只完成 M5 第六支可见 UI 验收与收口：复核模型与服务商、对话、图片五页、视频四页、任务与调用记录的响应式、主题、主操作层级、安全禁用状态、键盘可达基础和生产 Electron 窗口。

本支没有新增业务一级页面、后台合同、IPC、路由或适配器能力；没有读取或验证真实凭证，没有发起真实服务商 HTTP/DNS 或收费调用，没有启动阶段 10、macOS 实机与媒体工具链专项。阶段 9 权威方案原件保持未跟踪、只读。

## 二、实际修正

- 将服务商空状态“添加连接”、对话“创建项目对话”、图片工作区“保存本地草稿”和基础编辑“保存草稿”调整为次级操作，保留官方连接、保存消息、生成提交和视频导出为当前页面唯一主操作。
- 修正快速生图与快速视频的旧空状态说明，明确两者都只接收文字需求，不再引导选择参考图、参考视频或其他参考素材。
- 新增 UI 收口静态合同测试，锁定上述主操作层级和快速页纯文本产品决策。

## 三、可见验收

浏览器生产预览覆盖深色、浅色两种主题和五档权威窗口：

- `800x720`；
- `960x720`；
- `1280x820`；
- `1440x900`；
- `1920x1080`。

每种主题和窗口逐页覆盖模型与服务商、对话、快速生图、专业生图、图片识别、图片编辑、图片转提示词、快速视频、文生视频、图生视频、基础编辑、任务和调用记录，共 130 个页面/主题/窗口组合。

验收结果：页面与根节点无横向溢出；主区域、表单、卡片、操作区和面板无内部宽度溢出；无按钮重叠、单行文字裁切或零尺寸可用控件；每页可见主操作不超过一个；任务与调用记录分段可切换，深浅主题事实正确。浏览器无 Electron preload 时，所有依赖桌面端口的动作保持真实禁用，不伪造正常、费用、进度或结果。
