# 阶段 3｜项目目录与新建项目记录

日期：2026-07-22
分支：`feature/project-catalog-create`
负责人：开发者 B｜本地领域与平台

## 一、本次实现

- 新增主进程项目目录目录服务，保存最近项目的绝对路径，仅在主进程内部持有。
- 新增 `storage:list-projects`，返回项目 ID、名称、可用状态和最后打开时间，不返回路径。
- 新增 `storage:create-project`，renderer 仅提交项目名称，目录由主进程原生选择器产生。
- 新建项目要求目标目录为空；成功后原子写入 `project.json`、建立 `entities`、`index`、`files`、`tmp` 固定目录并设置活动 Session。
- 取消、名称非法、目录非空或创建失败均不替换现有 Session。
- 打开已有项目成功后自动更新最近项目目录；最多保留 50 条最近记录。

## 二、共享契约

preload 暴露：

```text
createProject(name)
listProjects()
```

DTO 不包含：

- 项目根目录；
- 任意绝对路径；
- 文件内容或原始 Hash；
- 通用文件系统对象。
