日期：2026-07-23

## 一、任务范围

本次只实现阶段 5 A3 的图片转提示词页面，不新增真实 HTTP 图片分析适配器。至此开发者 A 的阶段 5 图片页面任务全部完成。

## 二、实际修改

- 复用 A1 公共 `ImageWorkbenchPage`，为图片转提示词增加独立 `ImageToPromptWorkspace`。
- 同时覆盖 `not_analyzed`、`current` 和 `stale` 三种冻结状态。
- 接入 B2 `selectInput/getInput/createInputPreview`，只允许一张受控源图片；选择图片不会上传、分析或创建任务。
- 支持目标用途、逐行补充要求和共用归一化分析区域控件。
- 接入 B3 能力预检，动态候选模型、接收方、外发范围和费用状态只来自真实能力事实。
- 分别展示图片可见事实、模型推断、不确定、无法识别、系统补充和最终提示词草稿。
- 最终提示词草稿可编辑，但不会覆盖观察集合或系统补充。
- 图片、区域、目标用途或补充要求变化后，旧结果保留并分别显示 `input_changed`、`region_changed`、`purpose_changed` 或 `requirements_changed`。
- 当前没有真实图片转提示词适配器，因此分析按钮保持禁用，不显示演示提示词或假进度。
- 转入专业生图或图片编辑时，只调用 B1 `derive` 创建派生草稿，不创建任务。
- 未新增依赖。

## 四、当前真实边界

- 仓库尚未配置真实图片转提示词操作端口，预检会显示 `adapter_unavailable` 等真实阻断。
- 没有真实分析结果时，页面不创建示例观察、系统补充或提示词草稿。
- 提示词草稿不是作品，也不会自动触发图片生成。
- 后台契约齐备后，应另建小型 HTTP 适配器分支，不在本页面分支中预留虚构实现。
