# 图片结果接收优化 PR2｜生成历史状态记录

日期：2026-08-28

分支：`feature/image-history-receipt-status`

## 范围与边界

- 当前阶段仍为阶段 9 正式收口后专项，阶段 10 未启动。
- 仅调整专业生图、文生视频与图生视频共用生成历史的状态投影和样式，不修改领域事实、生成提交、结果接收、作品登记或全局任务摘要的一小时活动窗口。
- 不新增一级页面，不使用远端 URL 作为作品，不调用真实服务商。

## 实际修改

1. 生成历史把真实服务商生成阶段与本地结果接收阶段拆开：
   - `submitting/queued/processing/validating_sources/preparing_media/encoding/cancel_requested` 显示“生成中”；
   - `remote_completed` 显示“结果待接收”；
   - `downloading/writing/verifying/writing_file/verifying_file/registering_work` 显示“正在接收”。
2. “结果待接收”使用警示语义与下载图标；“正在接收”使用信息语义与不确定旋转图标，不展示虚假百分比。
3. 生成历史作品数量仍只计算已经通过本地文件验证并登记的 Work，远端完成节点不冒充正式作品。
4. 减少动态效果偏好下同时关闭生成中与接收中旋转动画。

- TypeScript 应用与测试类型检查：通过。
- 变更文件定向 ESLint：通过。
- 本地真实 CSS 渲染核验：`1280x720` 与最小支持宽度 `800x720` 下，“结果待接收”和“正在接收”均可见，状态卡为 `90x88`，页面横向溢出为 0；警示色与信息色边框/文字语义正确。
