# 生成历史通用组件验收记录

## 范围与决策

- 分支：`feature/professional-image-history-timeline`
- 当前阶段：阶段 9 已收口，阶段 10 未启动。
- 权威依据：项目负责人 2026-08-20 确认的 UI 稿、最终 UI 与开发交接包 V1.2.1、`AGENTS.md` 与 `PLANS.md`。
- 修改范围：专业生图工作台右侧结果区、页面样式、UI 契约测试与工程记录；未修改权威交接原件、服务商协议、计费、凭证或发布流程。

## 实际修改

1. 新增专业生图生成历史组件，上方为当前作品大图，下方为固定高度横向时间线。
2. 精简可见文案为“生成历史 / N 张作品 / 最新在右侧”；成功节点显示缩略图与时间，生成中、失败、待确认显示图标与短标签。
3. 成功作品按真实创建时间从左到右排列，最新项在右侧；点击缩略图通过 `workId` 切换上方大图，当前项有可访问的选中状态。
4. 新一轮生成不会清空已选作品。没有历史作品时才在大图区展示真实生成状态；已有作品时，生成中或失败状态留在时间线，不覆盖当前作品。
5. 时间线只读取当前项目的图片生成任务，并通过任务详情 `sourceDraftId` 绑定当前草稿；作品必须关联这些任务、文件状态为 `available`、存在 `verifiedAt`，且 `createWorkMediaHandle` 成功后才能显示。
6. 历史正式作品不使用远端 URL 回退，不显示未完成本地校验或未登记的远端结果。
7. 没有订阅宽泛的本地存储变化事件，避免草稿自动保存时反复扫描任务与作品；仅在草稿切换和真实提交完成后刷新历史。
8. 时间线使用稳定缩略图高度、保留媒体比例、水平滚动与减少动态效果策略；大图预览的画布、结果列表与结果项均使用可收缩的固定高度链，媒体盒占满画布后通过 `object-fit: contain` 等比缩放并完整居中显示，避免固有尺寸撑高后被父层裁切；未新增业务一级页面。
9. 鼠标位于生成历史区域时，纵向滚轮与触控板手势会驱动时间线横向滚动；同时兼容原生横向滚动，并换算行、页滚动单位。时间线没有溢出或已到达对应边界时不拦截事件，外层页面仍可继续滚动。
10. 将专业生图页面内的历史实现提升为 `src/components/GenerationHistory.tsx` 通用组件；专业生图、文生视频和图生视频统一传入草稿、项目、媒体类型与真实提交阶段，不再各自维护结果预览与历史选择状态。
11. 通用组件按 `mediaKind` 区分图片与视频任务、作品及受控媒体句柄；视频大画面使用本地视频控件，时间线使用固定尺寸的静音元数据缩略预览。三个入口都只展示当前草稿关联、文件可用且已校验登记的本地作品，不使用远端 URL 回退。
12. 提交返回后由工作台递增刷新标记，通用组件重新读取历史并选中最新登记作品；没有新提交时，用户手动切换的历史选择保持不变。
