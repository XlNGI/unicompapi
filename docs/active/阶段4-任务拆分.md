## 二、强制业务边界

- 服务商、连接、模型三层分离。
- 连接成功不等于模型能力已验证。
- 未验证能力不能标记为已验证支持。
- 自定义兼容接口不得冒充官方服务商。
- 自动路由不得绕过费用、外发范围和用户确认。
- 删除或停用连接不删除历史任务、作品或来源记录。
- API Key、Token 和代理密码只存本机安全存储，不进入项目、任务、日志或仓库。
- 页面不回显完整凭证，不提供读取明文能力。
- 不写死服务商、模型、价格、限制、时长、分辨率或数量。

统一能力状态：

```text
verified_supported
declared_supported
user_confirmed
unknown
unsupported
verification_failed
restricted
```

## 三、当前外部阻断项

后台团队尚未提供：

1. Base URL；
2. 鉴权方式；
3. 接口路径和 HTTP 方法；
4. 请求/响应示例；
5. 错误码、限流和重试规则；
6. 代理、超时、证书和日志脱敏要求；
7. 服务商/模型目录及能力验证来源。

在上述契约齐备前：

- 可以实现领域类型、本地持久化、安全凭证存储端口、连接验证端口、能力验证端口和离线 UI；
- 不得实现伪造的在线请求、固定模型目录、假费用、假连接成功或假能力验证。

## 四、开发者 B｜领域、凭证与连接平台

建议分支：

```text
feature/provider-domain-contracts
feature/secure-credential-vault
feature/provider-capability-services
```

### B1｜服务商领域契约

- 定义 Provider、Connection、Model、CapabilityEvidence、RoutingPreference 实体。
- 区分在线、本机、局域网和自定义远程接入类别，不预置具体厂商。
- 定义连接状态、身份验证状态、能力来源、验证时间和错误边界。
- 建立版本化本地仓储和运行时校验。
- DTO 不返回完整 endpoint 凭证、Key、Token 或内部错误堆栈。

### B2｜本机安全凭证库

- 定义只写入、替换、测试、删除和状态查询能力，不提供明文读取 API。
- Electron 适配 Windows DPAPI/macOS Keychain 语义；加密载荷只保存在应用用户目录。
- 日志、错误和测试夹具不得包含真实凭证。
- 删除连接时明确区分删除本地凭证和撤销服务商侧凭证。

### B3｜连接与能力服务端口

- 连接验证与能力验证分开。
- 定义模型目录同步、手工模型登记和能力证据更新端口。
- 费用、隐私、地区和能力未知时保持 `unknown`，不得自动推断支持。
- 定义默认用途、备选顺序、降级和升级规则；自动路由仍需提交前确认。
- 真实 HTTP 适配器等待后台契约后单独实现。

## 五、开发者 A｜模型与服务商页面

建议分支：

```text
feature/provider-management-ui
```

- 按权威设计图实现服务连接列表、模型目录、连接信息、凭证与安全、历史验证和默认设置区域。
- 支持添加服务、添加自定义兼容接口、选择连接、启用/停用模型和状态筛选。
- 未配置或后台契约缺失时展示真实离线/不可验证状态。
- 连接可用、身份已验证、模型目录已同步和具体能力已验证必须分别展示。
- 凭证只允许输入、替换、测试和删除，常态显示掩码，不回显完整值。
- 不展示固定费用、固定能力或虚构的服务商列表。

## 六、合并顺序

1. B 提交领域类型、状态和仓储契约。
2. B 提交安全凭证库端口与 Electron 适配。

## 七、阶段 4 验收门禁

- 服务商、连接和模型事实边界清晰，状态不能互相冒充。
- 凭证不进入仓库、项目、任务、日志、DTO 或截图。
- 未验证能力保持未知/声明/失败等真实状态。
- 页面与权威设计图结构一致，不使用硬编码示例冒充真实数据。
- 连接验证、能力验证、目录同步和默认用途分别可测试。
- 删除连接不删除历史任务和作品记录。
- 自动路由不能绕过费用与外发确认。
- 自动化测试、TypeScript、ESLint、生产构建和差异检查通过。
- Windows 可见窗口通过；macOS 安全存储与实机验证进入阶段 9。
- 后台契约缺失项继续记录为阻断，不虚假宣称在线能力完成。
