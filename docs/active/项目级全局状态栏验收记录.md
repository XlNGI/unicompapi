# 项目级全局状态栏验收记录

日期：2026-08-20

开发分支：`feature/professional-image-history-timeline`

## 一、实现范围

- 将底部状态区域提升为应用级唯一项目状态栏，固定在主工作区底部，不随页面组件重复创建。
- `FloatingStatusBar` 改为状态注册适配器；图片、视频和调用记录页面的既有状态消息继续复用，不改变业务状态来源。
- AppLayout 注册当前场景默认状态，具体页面状态以更高优先级覆盖；场景切换或页面卸载后自动清理，避免残留上一页面消息。
- 项目、对话、图片创作、视频创作、任务中心、作品库、模型与服务商、本地设置，以及各图片/视频子模式均有明确场景文案。
- 2026-08-21 最新交互决策：图片与视频生成的提交中、生成中、成功、失败、状态待确认和结果待接收均不再显示全局浮层通知，统一由页面进度、底部状态栏、展开面板、作品预览和任务中心承载。
- 按界面反馈将状态栏压缩为紧凑单行样式：最小高度 44px、减少上下留白与内容间距，长状态仍允许自然换行。
- 修复状态栏使用浮动定位遮挡对话输入框的问题：状态栏改为应用工作区第二行，布局为其预留高度；主页面位于第一行独立滚动，侧边栏跨越两行保持整高。

## 二、验证结果

- 全局状态栏、场景默认状态与页面状态覆盖契约测试通过。
- 通过 TypeScript 类型检查；未改变服务商调用、授权门禁、任务和作品登记逻辑。

## 三、边界

- 未新增一级页面，不恢复首页、多图参考或批量创作。
- 未调用真实服务商、未读取凭证、未产生收费请求；阶段 10 未启动。
