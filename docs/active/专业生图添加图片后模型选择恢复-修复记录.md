# 专业生图添加图片后模型选择恢复｜修复记录

日期：2026-08-26

当前阶段：阶段 9 已收口后的缺陷修复；阶段 10 未启动。

## 问题与根因

专业生图切换为图生图并添加参考图片后，模型选择器不能操作，底部持续显示“正在保存当前配置”。

受控选图、拖入图片、引用本地作品与清除图片都已经在主进程的图片修改协调器内完成本地校验、事实登记和草稿持久化。专业生图草稿却仍以 `editing` 返回，renderer 又把该返回值当作新的未保存修改排入自动保存。模型候选读取要求草稿保存完成，因此被这次冗余保存阻塞；界面状态也可能长期停留在保存提示。

## 实际修改

- 专业生图的本地图片添加与清除在主进程成功落盘后返回 `saved`；其他图片工作区继续保留原有 `editing` / `stale` 语义。
- 专业生图页面对选图、拖入、本地作品引用和清除结果统一使用已持久化回调，不再触发第二次自动保存。
- 保留原有单图约束、图片字节签名检查、SHA-256 校验、受控预览、项目内 Asset/FileReference 登记、串行修订协调和候选/提交门禁。
- 新增平台回归，验证专业生图添加与清除图片后返回和仓储状态均为 `saved`；更新 UI 合同，覆盖四条本地媒体路径必须走已持久化回调。
