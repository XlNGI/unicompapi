## 一、官方核对

本次以 Vidu 官方平台当前文档为准：

- 文生视频：`https://platform.vidu.cn/docs/text-to-video`
- 参考生视频：`https://platform.vidu.cn/docs/reference-to-video`
- 图片生成：`https://platform.vidu.cn/docs/reference-to-image`

官方必填字段为 `model`、`prompt`，参考生视频非主体调用还必填 `images`；这些字段继续由产品功能约束和适配器层强制，未放进动态参数字段。

## 二、差异与修复

1. 文生视频与参考生视频新增 `seed` 可选整数参数，范围 `0–2147483647`；`0` 或省略时继续由服务商随机。
2. 参考生视频 q3 系列 `audio` 默认值修正为 `true`；文生视频 q3 默认仍为 `true`。
3. 参考生视频时长范围按当前官方文档修正：`viduq3-turbo`、`viduq3-mix`、`viduq3` 为 `3–16` 秒；`viduq3-ad` 保持 `3–15` 秒；`viduq3-drama` 保持 `2–15` 秒。
4. `resolution`、`aspect_ratio` 从自由字符串改为官方枚举，模型不同的合法选项分别声明；适配器在 HTTP 前拒绝枚举外值。
5. 官方参考生图 `viduq2/viduq1` 的 `aspect_ratio`、`resolution` 同步为官方枚举。
6. 涉及以上变更的参数 Schema revision 升级为 2，旧 revision 路由不再解析，需重新同步目录或建立新路由。
7. Vidu 路由解析器移除 `parameterSchemaRevision === 1` 的全局硬编码，精确版本改由参数 Schema 解析器校验，revision 1 与 2 的契约按各自 schema 精确匹配。
