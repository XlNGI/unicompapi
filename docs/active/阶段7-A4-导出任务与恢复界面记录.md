## 实现范围

- 复用 B4 的 `preflightExport`、`startExport`、`getExport`、`cancelExport` 和 `retryExport`，不建立 renderer 侧任务仓储。
- 导出确认展示真实来源、目标、容器、编解码器、质量说明、软件编码能力和空间校验时机。
- 文件名与同名冲突策略必须先保存；存在未保存修改时不允许预检或开始导出。
- 展示后台任务阶段、真实进度、取消中、失败、需要用户处理、中断和恢复状态。
- 重试创建新 attempt，旧 attempt 继续保留在任务中心。
- 只有 `completed` 且存在已登记 `workId` 时，才创建受控媒体预览并开放文件定位与作品库入口。

## 边界

- 页面不接收文件路径、Hash、引擎命令或进程句柄。
- 不把进程退出、临时文件存在或进度到达 100% 当作导出成功。
- B4 当前只声明 `software_only`，A4 不伪造硬件编码或硬件失败回退 attempt。
- 预计输出体积来自预检；真实目标可写空间由 B4 在执行开始时检查。
- `.tools/`、FFmpeg 二进制和下载归档不进入 Git 或生产构建。
