## 一、批准边界

项目负责人批准“阶段 9 C1｜对话与项目上下文应用层契约”作为阶段 9 的业务范围例外。本分支只实现对话领域与应用级本地仓储，不修改 React 页面、最终冻结 UI、Electron 主进程、preload 或 IPC，不实现真实 AI、HTTP、供应商适配器、示例回复、项目上下文登记或图片/视频任务创建。

Conversation 采用应用级全局存储，允许 `projectId` 为 `null` 或显式项目 ID；本分支不根据当前打开项目自动绑定。未绑定项目的 Conversation 只能保存纯文本消息，不能持久化 Asset 或 FileReference 引用。

## 二、实际修改

- 新增 `ConversationId` 与 `MessageId` 强类型 ID；
- 新增 Conversation 聚合，包含单调 revision、可选项目归属、标题、消息历史、创建/更新时间和 `active | archived | deleted` 严格状态；
- 普通删除使用墓碑软删除，保留全部消息事实；普通列表默认只返回 active Conversation，归档和删除记录必须显式请求；
- archived Conversation 必须恢复为 active 后才能继续追加或修改消息；deleted Conversation 为终态，不允许重命名、恢复或追加消息；
- 新增 user/assistant Message 严格判别联合，支持 `pending | streaming | completed | failed | cancelled`；
- 用户消息创建后直接成为不可变 completed 事实；assistant 消息只允许 `pending -> streaming -> completed`，并允许 pending/streaming 转为 failed 或 cancelled；
- 每次消息状态变化或流片段追加都会递增 Message revision 和 Conversation revision；终态消息不能继续追加片段；
- 受控附件只允许持久化同一项目的 `AssetId` 或 `FileReferenceId`，严格校验会拒绝绝对路径、Hash、endpoint 和其他未知字段；
- 新增 Conversation repository 端口与按状态/项目过滤的列表契约；
- 新增应用级版本化 JSON 仓储，文档包含 Schema version、文档 revision、更新时间和 Conversation 集合；
- 新增显式连续 Schema 迁移注册入口，拒绝缺失迁移、跳跃迁移、重复迁移和未来版本；
- 新增聚合 revision 乐观并发，创建冲突、缺失记录、旧 revision 和跳跃 revision 均失败关闭；
- 同一仓储路径的多个实例共享进程内串行写入队列；
- 写入使用同目录唯一临时文件、文件 `fsync`、原子替换和目录同步；临时文件无论成功或失败均清理；
- 只有经过完整解析校验的当前主文件才能更新备份；主文件损坏时读取最后有效备份，不在读取阶段覆盖损坏证据；主文件和备份均无效时失败关闭。

新增 14 项领域与仓储测试，覆盖：

- Conversation 创建、重命名、归档、恢复和软删除；
- archived/deleted 写入阻断；
- Message pending、streaming、completed、failed、cancelled 生命周期；
- 流片段顺序、Message revision、Conversation revision 和终态不可变；
- 用户消息不可变与非法状态捷径拒绝；
- 未绑定项目附件拒绝、跨项目附件拒绝和严格字段白名单；
- 版本化文档读写、默认列表、归档列表和墓碑读取；
- 同路径多仓储实例并发写入和 stale revision 冲突；
- 最后有效备份回退、双损坏失败关闭和临时文件清理；
- 显式 Schema 迁移、缺失迁移和未来版本拒绝；
- 持久化文本不包含绝对路径、Hash、API Key、endpoint 或 URL 字段。
