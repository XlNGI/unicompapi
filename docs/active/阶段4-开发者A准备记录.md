## 一、实现边界

本分支只负责“模型与服务商”页面，不定义服务商领域实体、不实现凭证存储和真实 HTTP 适配器。

开始页面实现的前置条件：开发者 B 的 Provider、Connection、Model、CapabilityEvidence、RoutingPreference DTO 已合入最新 `develop`，且 renderer 可通过受控接口读取真实本地状态。

后台契约未齐备期间，页面只展示真实离线、未配置、未知或不可验证状态，不使用固定服务商、模型、费用和能力数据。

## 三、DTO 接入检查

B1 合入后先核对 DTO 是否能直接表达以下事实；字段名完全以 B 的共享契约为准，页面不得自行推断：

- 服务商、连接和模型的稳定标识及三层关联关系；
- 在线、本机、局域网和自定义远程接入类别；
- 连接可用状态与身份验证状态；
- 凭证是否已配置、是否需要替换及最后测试结果，不包含明文；
- 模型目录同步状态及时间；
- 能力状态、证据来源、验证时间和失败边界；
- 模型启用状态；
- 默认用途、备用顺序、降级和升级规则；
- 费用、隐私、地区和外发范围的已知或未知状态；
- 历史引用所需的稳定标识，删除连接不级联删除历史任务和作品。

若 DTO 缺失上述事实，先反馈 B 补充共享契约，不在页面创建第二套业务状态。

## 四、页面状态映射

能力状态严格使用统一枚举：

```text
verified_supported  -> 已验证支持
declared_supported  -> 服务声明支持
user_confirmed      -> 用户确认
unknown             -> 状态未知
unsupported         -> 不支持
verification_failed -> 验证失败
restricted          -> 受限
```

以下状态必须分开展示：

- 连接可用不等于身份已验证；
- 身份已验证不等于模型目录已同步；
- 模型目录已同步不等于具体能力已验证；
- 模型已启用不等于已设为默认用途；
- 声明支持和用户确认不得显示为已验证支持。

无连接时显示真实空状态；后台契约缺失时禁用在线验证与同步入口，并说明阻断原因。

## 五、凭证与危险操作

- 凭证只允许输入、替换、测试和删除，常态显示掩码。
- 页面、DTO、错误、日志、测试夹具和截图不得出现完整凭证。
- 不提供复制、查看或读取明文入口。
- 删除本地凭证时提示“不等于服务商侧凭证已撤销”。
- 删除或停用连接前明确说明历史任务、作品和来源记录会保留。
- 自动路由和默认设置不得绕过费用、隐私、外发范围及提交前确认。
