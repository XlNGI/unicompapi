## 一、批准边界

本支只实现项目所属新会话、ConversationResponseDraft、项目级 JSON 仓储、ProjectContext 固定选择和实际外发内容快照。未修改 React、preload、Electron 页面、提交编排、协议适配器、历史数据、阶段 10 或 macOS 实机目标。

本支禁止真实服务商 HTTP、真实凭证读取/验证和收费调用。Vidu 两项已用尽预算继续封存，Image V1 未验证事实不变。

## 二、实际实现

- 新增 `createProjectConversation` 和项目归属断言；优化后的新会话必须绑定项目，既有 `projectId=null` 会话仍由旧应用级仓储保留，不自动归属或跨项目读取。
- 新增项目级会话仓储，使用项目目录内独立 JSON、revision/CAS、共享写入协调、原子变更和有效备份；拒绝 legacy/null 与跨项目会话进入项目仓储。
- 新增 `ConversationResponseDraftV1`，固定 `text_chat | text_reasoning`、conversation revision、用户消息 revision 和显式 ProjectContext 选择；上下文选择按 context ID 唯一，未知字段和媒体 ProductFeature 均拒绝。
- 新增项目级回复草稿仓储，提供独立 document revision、实体 revision、并发 mutation、备份恢复和精确冲突判定，不与媒体 Draft 混用。
- 新增 `PinnedProjectContextSelectionV1` 与 `ProjectContextOutboundSnapshotV1`，固定 context revision、SHA-256 contentHash、是否用于本次外发和实际外发内容快照。
- “查看但未勾选”的上下文不外发；旧选择继续读取固定旧 revision，不随当前 revision 漂移；hash 篡改、重复选择、跨项目、已删除和缺失 revision 均拒绝。
- 快速页继续禁止消费项目上下文；专业页只可把显式勾选且校验通过的 ProjectContext revision 冻结为外发快照。
