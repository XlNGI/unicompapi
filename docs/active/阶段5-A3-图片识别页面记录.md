# 阶段 5 A3｜图片识别页面记录

日期：2026-07-23

分支：`feature/image-understanding-ui`

基线：`70bc588 Merge professional image workspace`

## 一、任务范围

本次只实现阶段 5 A3 的图片识别页面，不实现图片编辑或图片转提示词页面，也不新增真实 HTTP 图片识别适配器。

## 二、实际修改

- 复用 A1 公共 `ImageWorkbenchPage`，为图片识别增加独立 `ImageUnderstandingWorkspace`。
- 接入 B2 `selectInput/getInput/createInputPreview`，只允许一张受控源图片；选择图片不会上传、分析或创建任务。
- 支持填写识别目的或自定义问题，并通过百分比输入保存可选归一化识别区域；预览中的区域框只来自草稿真实数据。
- 接入 B3 能力预检，候选模型、接收方、外发范围和费用状态来自真实动态事实。
- 可见事实、模型推断、不确定、无法识别和用户修改五类结果分别展示。
- 用户修订追加为独立记录并保留目标观察 ID，不覆盖模型原始结果。
- 图片、区域或目的变化后，领域层继续保留旧结果并标记 `input_changed`、`region_changed` 或 `purpose_changed`。
- 修复公共保存逻辑：分析结果已经过期时，保存草稿继续保持 `stale` 状态，避免把过期结果错误改为已保存有效状态。
- 结果保存范围可以记录为仅草稿或项目上下文；项目上下文登记端口尚未提供，因此不虚假宣称已写入上下文。
- 转为提示词草稿、进入图片编辑或进入专业生图时，只调用 B1 `derive` 创建派生草稿，不创建任务。
- 当前没有真实识别适配器，因此“开始识别”保持禁用，不显示示例结果、假进度或虚构模型。

## 四、当前真实边界

- 仓库尚未配置真实图片识别操作端口，能力预检会显示 `adapter_unavailable` 等真实阻断，不能开始远端分析。
- 当前没有远端识别结果写入来源；页面只展示草稿中真实存在的五类结果，不生成演示数据。
- 项目上下文登记端口尚未提供，`saveScope` 只保存范围意图，不虚假登记项目上下文。
- 图片编辑和图片转提示词继续按独立小分支推进。
- 本分支等待项目负责人完成 Windows Electron 手工验收；验收通过后才提交、推送并合并。
