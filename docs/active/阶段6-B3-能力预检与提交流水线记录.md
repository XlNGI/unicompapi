# 阶段 6 B3｜能力预检与提交流水线记录

日期：2026-07-23

分支：`feature/video-submission-pipeline`

基线：`a44244a Merge controlled video reference media`

## 一、范围

本任务实现视频生成的本地能力预检、确认快照、Task/Execution 分层和远端提交端口。

本任务不提供具体服务商 HTTP 实现，不上传素材，不伪造排队或进度，不轮询远端，不接收或下载视频结果，不登记 Work，也不实现阶段 7 时间线、媒体引擎或导出。

## 二、视频能力证据 Schema

`ModelCapabilityEvidence` 新增可选 `videoGenerationSchema`，Schema 版本为 1。它只能来自 Provider 能力验证端口、经过验证的注册表数据或用户明确确认的工程事实，不能根据模型名称或界面示例推断。

Schema 按模式判别：

- `quick_video`：可选声明单参考素材接受的媒体类型；
- `text_to_video`：动态素材槽位及镜头方案约束；
- `image_to_video`：动态素材槽位。

每个动态素材槽位声明 ID、角色、是否必需和接受的图片/视频类型。文生视频镜头方案声明是否支持、是否必需和可选的最小/最大镜头数量；这些数值由能力证据提供，生产代码没有固定默认值。

Provider 注册表加载、保存、只读 DTO 和能力验证端口均支持该 Schema。无 Schema、Schema 无当前模式或 Schema 语义无效时预检阻断。

## 三、严格预检

视频预检用途固定为 `video_generation`，只考虑：

1. 已启用的对应路由偏好；
2. 已启用模型；
3. 状态为 available 的连接；
4. 存在的 Provider；
5. 最新 `verified_supported` 或 `user_confirmed` 能力证据；
6. 存在的动态参数 Schema；
7. 存在且支持当前草稿模式的视频模式 Schema。

草稿级检查包括：

- 状态只能是 editing 或 saved；
- 最终提示词非空；
- 草稿模型/参数能力证据快照没有过期；
- 动态参数键、类型、必填、枚举和范围满足当前 Schema；
- 专业模式素材槽位快照与候选证据 ID、槽位顺序、角色、必填和媒体类型完全一致；
- 必需素材已经选择；
- Asset、FileReference、本地 available 状态、媒体元数据、媒体类型和角色真实匹配；
- 图生视频模式 Schema 至少有一个必需图片槽位；
- 文生视频镜头方案满足候选 Schema 的动态约束，且已存在镜头描述非空。

候选模型返回独立 blockers，使页面后续可以展示真实 Schema 并指导用户修正草稿；没有路由、能力、参数 Schema 或模式 Schema时返回全局阻断。

## 四、显式确认快照

创建 Task 前必须同时确认：

- 接收方；
- 外发范围；
- 素材范围；
- 费用、隐私和地区状态；
- 最终提示词；
- 模型。

确认快照冻结：

- 模式和 `video_generation` 用途；
- 模型、能力证据、Provider、连接和接收方展示名；
- Provider 访问类型与外发范围；
- 费用、隐私和地区的真实 unknown 状态；
- 动态参数值；
- 每项素材的 Asset ID、媒体类型、角色和 quick/slot 目标；
- 显式上下文引用；
- 快速视频、文生视频或图生视频的模式特有输入。

Task 的通用 `assetIds` 去重，同一素材可以在能力允许时绑定多个不同槽位；完整槽位目标和角色仍保存在视频确认快照中。适配器提交只能读取 Task 冻结事实，不能在调用时重新读取可变草稿。

## 五、Task、Execution 与调用端口

新增受控操作：

- `preflight(draftId)`；
- `createTask(draftId, draftUpdatedAt, modelId, confirmations)`；
- `createExecution(taskId)`；
- `invokeExecution(executionId)`。

保存草稿和预检不会创建 Task；创建 Task 不会创建 Execution；创建 Execution 初始状态为 created；只有显式调用才进入 submitting。

视频生成端口返回真实 remote operation ID 和真实 queued/processing 初始状态。remote operation ID 只持久化在主进程 Execution，renderer DTO 不包含该字段。端口失败时 Execution 记录 failed、失败阶段和适配器声明的可重试性；重试创建新的 Execution 和递增 attempt，不覆盖历史执行。

默认应用没有视频生成端口，因此预检包含 `adapter_unavailable`，调用 created Execution 也返回 `adapter_unavailable` 且不改变执行状态。

## 六、安全边界

- renderer 不接收路径、Hash、凭证、endpoint、远端 operation ID、内部命令或堆栈；
- 没有 `receiveResult`、下载、上传、轮询、进度或取消 IPC；
- 没有固定服务商、模型、参数、费用、时长、比例、分辨率、帧率或镜头数量；
- 素材文件事实仍由 B2 主进程实体提供；
- 没有真实适配器时不创建可提交 Task，不伪造远端成功；
- 远端完成到本地视频校验与 Work 登记继续属于 B4。
