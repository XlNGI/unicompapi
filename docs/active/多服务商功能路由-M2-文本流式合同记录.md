## 一、批准边界

本支只实现文本候选执行快照、ConversationResponseExecution、项目级事件仓储、受控流式投影、取消、中断、恢复、背压和应用退出语义。未修改 React、preload、Electron 页面、公开候选、routeSelectionToken、提交编排、真实协议适配器、历史数据、阶段 10 或 macOS 实机目标。

本支禁止真实服务商 HTTP、真实凭证读取/验证和收费调用。Vidu 两项已用尽预算继续封存，Image V1 未验证事实不变。

## 二、实际实现

- 新增不可变 `ConversationResponseExecutionSnapshotV1`，固定回复草稿、Conversation/Message revision、显式文本 ProductFeature、路由快照、Provider/Connection/Model/Profile/Binding 候选事实、`official_direct | newapi_gateway` 运行来源、实际外发用户文本和已勾选 ProjectContext 内容快照。
- 新增 `ConversationResponseExecutionV1`、连续单调 `ConversationResponseStreamEventV1` 和六态执行状态机，覆盖创建、开始、增量、完成、失败、取消请求、取消完成、中断和显式恢复；空完成、非法跳转、重复/断裂序列和超限内容全部拒绝。
- 新增项目级 JSON 仓储，原子持久化 execution 与事件，更新可恢复状态，拒绝跨项目、身份复用和非终态重试；用户重试必须创建新的 execution、assistant message 和 ProviderInvocationAttempt，并引用同一主题的失败、取消或中断前序执行。
- 新增受控 renderer 流事件 DTO，只公开会话、assistant message、序列、事件类型、增量和安全状态，不公开路由快照、外发用户文本、Context Hash、Profile、Binding、凭证、endpoint 或远端流对象。
- 新增主进程流生命周期和有界订阅通道。未确认事件达到上限时只断开滞后的 renderer 订阅，不丢弃已持久化流事件或中断服务商执行；renderer 可按 sequence 重放。应用退出会把 `pending | streaming` 执行持久化为 `interrupted/application_shutdown`，恢复必须显式追加 `stream_resumed`。
