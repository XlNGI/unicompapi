## 范围

- 将任务中心费用计算从单一“官方单价 × 积分数”调整为策略式计算。
- 调用详情 DTO 增加本地只读 `officialPricingRule`，任务中心根据已持久化的用量事实计算费用。
- 价格规则集中在平台只读规则表，带来源 URL 与核对日期；未确认价格或缺少用量的成功调用不进入消费图表。
- 任务中心空消费图表显示未计入原因拆分，区分缺官方价格规则、缺响应体计费用量和格式异常。
- Vidu 图片调用从响应体 `credits`、`credit`、`credit_amount` 或 `usage.*` 提取积分并持久化为 `credit_amount` 用量事实；历史未采集积分的调用不回填费用。
- 图片与视频业务提交流程接入真实 `ProviderUsageObservation` 仓库，避免适配器已解析的用量被空写入器丢弃。
- UniCompAPI/NewAPI 图片响应支持从顶层、顶层 `usage`、`data[0]` 或 `data[0].usage` 中提取 `credits`、`credit`、`credit_amount`、`credits_used`、`used_credits`、`point_amount`、`points`、`point`；官方单价未核准前仍不计算金额。
- 消费图表优先展示已核准官方单价换算后的金额；当没有金额但存在响应体积分用量时，退化展示“积分消耗”柱状图与供应商积分占比，不把积分伪装成费用。
- 未新增真实服务商 HTTP、凭证读取、账单同步、原始响应保存、阶段 10 发布或安装包工作。

## 计费策略

- `credit`：积分或点数用量乘官方 credit 单价。
- `provider_billing`：优先使用响应体现金扣费；没有现金扣费时按资源包单位规则估算。
- `provider_unit`：资源包单位乘官方单位价格。
- `token_split`：输入、输出、缓存、推理等 token 分项计费。
- `video_token`：视频生成 token 计费。
- `image_count`：输出图片张数计费。
- `video_second`：输出视频秒数计费。
