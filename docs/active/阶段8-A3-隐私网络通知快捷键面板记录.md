# 阶段 8 A3｜隐私网络通知快捷键面板记录

日期：2026-07-27

分支：`feature/local-settings-user-controls`

基线：`origin/develop@916b4eb`（已包含 A1、A2、B3）

状态：工程实现与本地门禁已通过，等待项目负责人 Windows Electron 手工验收。

## 实现范围

- “隐私与权限”接入 B3 最小授权、系统权限状态和系统设置入口，展示禁止主目录扫描、禁止后台剪贴板读取、强制外发与未知费用确认。
- 隐私策略变更通过 `update_privacy_permissions` 的两阶段确认执行；项目上下文、已保存对话和外接盘策略不绕过影响计划。
- “网络与代理”接入系统默认、系统代理、直连和自定义 HTTP/HTTPS/SOCKS5。自定义代理先走隔离测试，再展示确认计划。
- 代理认证值只通过 `stageProxyCredential` 暂存为一次性句柄；页面不回显认证值，不把代理密码写入设置 JSON、DOM 文案、状态摘要或日志。
- “通知”接入应用内、系统和声音渠道状态，可发送真实测试通知；系统通知拒绝或失败时应用内提醒仍保留，测试结果不修改 Task/Execution。
- “快捷键”接入 B3 版本化动作注册表、Windows/macOS 平台切换、可编辑绑定、不可修改标记、恢复本平台默认和保存前冲突检查。
- 右侧状态摘要补充隐私、代理、通知和快捷键真实事实；未接入的 B4 日志诊断和应用更新仍保持不可用。

## 真实能力与安全边界

- renderer 不接收绝对路径、代理明文、凭证引用、平台句柄、日志原文或系统代理原始细节。
- 代理测试说明固定为最小隔离请求，不携带项目内容、提示词、请求正文或服务商凭证；代理切换只影响后续请求，活动请求不重试。
- 通知失败只影响通知渠道结果，不改变业务状态；任务失败、需要确认等关键提醒不能被完全隐藏。
- 快捷键保存前由 B3 检查未知动作、不可修改动作、非法 accelerator、重复键、系统保留键和真实注册失败；一个平台的保存不覆盖另一个平台。
- A3 不实现 B4 的诊断、导入执行、恢复全部默认、清除本机数据或应用更新能力。

## 项目负责人手工验收建议

1. 在 Windows Electron 中进入“本地设置”，依次打开“隐私与权限”“网络与代理”“通知”“快捷键”。
2. 核对“隐私与权限”：文件访问应显示仅用户选择/授权目录，主目录扫描和后台剪贴板读取应显示禁止。这样测是为了确认页面没有提供全盘扫描或后台读取剪贴板的危险入口。
3. 点击“打开系统设置”，确认只打开系统设置入口，不在页面里伪造已授权状态。这样测是为了确认权限事实来自操作系统，不靠 UI 猜测。
4. 打开“网络与代理”，切换系统默认、系统代理或直连时，应先出现影响确认框；取消后设置不应改变。这样测是为了确认代理属于高风险操作，不能绕过 plan/confirm。
5. 在自定义代理里输入一个明显不可达的主机，例如 `127.0.0.1` 和未监听端口，点“测试并确认”。页面应显示真实失败或阻断，不应直接显示已保存。这样测是为了确认代理失败保留旧配置。
6. 在代理认证值输入框输入内容，确认输入框是密码框，页面其他位置不显示该认证值。这样测是为了确认代理秘密不会回显到状态区或确认文案。
7. 打开“通知”，点击“发送测试通知”，确认应用内结果保留，系统/声音按平台真实结果显示；即使系统通知被拒绝，也不影响任务状态说明。这样测是为了确认通知降级不破坏业务状态。
8. 打开“快捷键”，选择 Windows 平台，把两个可编辑动作临时改成同一个快捷键，再点“检查并确认保存”。确认框应阻止执行或显示冲突原因。这样测是为了确认冲突快捷键不能保存。
9. 切换到 macOS 平台，确认 macOS 按键单独显示；不要把 Windows 的修改覆盖过去。这样测是为了确认跨平台绑定隔离。
10. 缩放窗口到应用最小宽度，用 Tab/Shift+Tab 走一遍四个面板，确认没有横向滚动、焦点可见、按钮和输入框能依次访问。这样测是为了确认小窗口和键盘操作仍可用。
