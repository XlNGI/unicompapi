## 一、评测对象与边界

本报告对应 `conversation-intent-offline-golden@1.0.0`，评测对象为 Application 层本地快速路径 `analyzeLocalConversationIntent`。评测未调用真实 Provider、联网搜索、向量数据库或收费接口，也未读取真实企业资料和真实凭证。

该结果只证明当前 45 条版本化离线样本没有回归，不代表真实用户流量上的误路由率已经达到生产指标。真实 LLM 分类兜底、脱敏线上样本和更大规模统计评测仍为后续阶段。

## 四、误判与残余风险

V1.0.0 当前误判样本为 0。仍存在以下未覆盖或证据不足：

- 样本量不足以统计证明总体误路由率不高于 1%。
- 多轮合并仅覆盖代表性参数和目标补充，尚不能证明真实口语分布下达到 95%。
- 尚未覆盖方言、错别字、超长输入、多语言混输和真实企业术语分布。
- `web/mixed` 当前只识别资料策略，不执行联网；联网仍需显式授权与后续独立门禁。
- 复杂或低置信度请求只验证了受控 classifier port 的超时、不可用和 Schema 拒绝，未接真实 LLM 分类器。

后续新增失败样本时必须先加入黄金集形成回归用例，并提升 suite 版本；不得直接覆盖本报告中的 V1.0.0 结果。
