# 阶段 7｜视频基础编辑任务拆分

日期：2026-07-24
状态：规划已批准，B1、B2 已完成
基线：5127ab3 Merge phase 6 integration closeout

## 一、阶段目标

按“本地优先、非破坏式、轻量单轨”交付视频基础编辑 V1.0。阶段完成时，用户可以在项目内建立编辑草稿，导入多个视频顺序编辑，添加基础文字和一条背景音乐，保存与恢复草稿，并通过后台任务导出经过本地校验的独立新作品。

本阶段不调用图片或视频生成模型，不恢复视频批量创作，不扩展为专业剪辑器。

技术架构以以下文件为强制依据：

    docs/active/阶段7-技术架构.md

项目负责人已于 2026-07-24 通过“继续”指令批准本规划并启动 B1。

## 二、现有基线与缺口

可复用：

- 项目 Session、项目目录、版本化 JSON 仓储和原子 JSON 写入；
- Asset、FileReference、Draft、Task、Execution、Work 与来源关系；
- SHA-256、文件状态、relink、索引重建、受控媒体句柄；
- ISO BMFF MP4/MOV 基础可信探测；
- 阶段 6 视频 Work 与“进入基础编辑”的受控来源意图；
- 任务中心、作品库、视频播放和 Electron 受控 IPC。

缺口：

- 没有 EditDraft、编辑命令、时间线和撤销/重做；
- 没有预览计划、代理、缩略图或波形缓存；
- 没有获准的本地媒体引擎、能力探测或导出适配器；
- 现有 Execution 状态偏远端生成语义，没有本地导出详细阶段；
- 没有导出计划快照、取消、恢复、硬件回退和本地导出 Work 登记；
- 基础编辑页面仍是阶段 7 准入阻断状态。

## 三、分支原则

- 所有分支从最新 develop 创建。
- A 负责页面、时间线交互和真实状态展示；B 负责领域、平台、媒体端口、任务和文件边界。
- 每个功能分支合并后保留本地与远程分支。
- 媒体引擎选型和二进制集成必须单独审批、单独小 PR，不得藏在领域或 UI 分支。
- A/B 不得在共享大文件中同时重写；先合并 DTO/领域契约，再接 UI。

建议分支：

范围：

- 实现版本化 EditDraft 严格判别联合、时间微秒整数和运行时校验；
- 实现单视频轨、removedClips、基础转场、多个文字层、一条背景音乐、封面、画布和输出偏好；

不包含：

- 页面时间线；
- 媒体引擎、代理或正式导出；

验收：

- 保存草稿不创建 Task、Execution 或 Work；
- 源文件和历史作品不被修改。

## 七、阶段验收门禁

- 只有视频主轨、多个基础文字层和一条背景音乐，不出现专业多轨或画中画；
- 所有编辑非破坏式，源文件和旧作品不被覆盖；
- 草稿保存、复制、撤销/重做和重开一致；
- 源丢失保留草稿，重定位不静默接受同名不同文件；
- 预览和正式导出共享领域语义，代理不进入作品库；
- 输出选项、格式、编码和硬件能力来自真实探测；
- 导出创建后台 Task 和冻结 ExportPlan；
- 取消、失败、重试、中断和恢复状态真实；
- 硬件失败自动或经确认创建软件新尝试；
- 临时输出通过探测、Hash、fsync 和正式发布后才登记 Work；
- 每次导出产生独立文件与版本，不覆盖已有结果；
- renderer 不接收路径、Hash、引擎命令、凭证、进程句柄或内部堆栈；
- 基础编辑页不调用生成模型，不恢复废止入口；
- 第三方引擎许可、来源、版本和分发审查有正式记录；
- 自动化测试、TypeScript、ESLint、生产构建和差异检查通过；
- Windows Electron 真实流程验收通过，macOS 差异未被写死。
