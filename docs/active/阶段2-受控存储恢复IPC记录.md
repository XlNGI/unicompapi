# 阶段 2｜受控存储恢复 IPC 记录

日期：2026-07-22
分支：`feature/storage-recovery-ipc`

## 实现

- 仅暴露文件探测、校验、确认 relink 和文件索引重建四个 IPC。
- 渲染进程只提交项目 ID、文件 ID 和确认状态，不能提交项目根目录。
- 项目目录由主进程在应用数据目录内按项目 ID 哈希映射。
- relink 候选路径只来自 Electron 主进程文件选择框，渲染进程不能提交候选路径。
- IPC 复用现有文件仓储、状态探测、校验持久化和索引重建服务，没有复制业务规则。
- preload 未暴露读取、写入、删除、枚举目录或其他通用文件系统能力。

## 验证

- 完整测试：UI 11 项、领域与平台 42 项，共 53 项通过。
- 平台专项：6 个文件、24 项通过；新增 IPC 测试 3 项。
- IPC 测试覆盖探测、持久化校验、拒绝 `projectRoot`、主进程选择 relink 文件和索引重建。
- TypeScript、ESLint、生产构建和 `git diff --check` 通过。
- Windows 生产构建 Electron 成功启动，`UniComp` 主窗口响应正常。
