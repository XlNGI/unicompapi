# 任务中心失败诊断与最终提示词

2026-09-10，当前分支 feature/h3-video-ui-optimization。负责人已批准实施，Windows 人工验收待完成。

## 已实施

- 确认输入只展示最终提示词，复用 ExpandableText，溢出时展开/收起。
- 任务中心与调用记录复用 FailureDiagnostic，显示现有诊断字段并支持复制。
- 历史节点按事件状态展示，不再全部套用调用最终失败状态。
- 调用事件新增可选 failureDiagnostic，经事件解析器、JSON 持久化和读模型传到 UI。旧记录兼容，不回填历史错误。
- NewAPI/UniCompAPI 共享运行时保留非成功 HTTP 响应的状态码、安全消息、错误码及请求 ID；图片和视频提交链路传递诊断。NewAPI 视频异步失败保存错误消息，视频轮询异常保持结果未知。
- 不改变自动重试、计费、授权和正式作品门禁。

## 边界

并非所有服务商都已新增原始错误消息采集。未提供诊断的链路使用既有安全码说明；无记录时明确提示未提供具体失败原因。原始响应、凭证、路径和堆栈不作为诊断对象存储。新增文本经过有界脱敏，但不能据此声称覆盖任意自由文本中的所有敏感形式。
