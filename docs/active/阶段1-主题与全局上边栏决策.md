# 阶段 1｜主题与全局上边栏工程决策

日期：2026-07-20
决策人：项目负责人

## 一、负责人决策

- Windows 与 macOS 统一提供三种主题偏好：跟随系统、深色、浅色。
- 默认主题偏好为跟随系统。
- 全局上边栏不显示面包屑。
- 全局上边栏仅保留品牌、主题切换和平台对应的窗口控制。
- 通知、帮助和快捷设置在真实能力完成前不展示。

## 二、工程实现

- 主题偏好通过 `localStorage` 的 `unicomp.theme` 键保存在本机。
- `system` 偏好通过 `prefers-color-scheme` 解析，并监听系统主题变化。
- HTML 根元素仅应用最终视觉主题：`data-theme="dark"` 或 `data-theme="light"`。
- 主题在 React 首次渲染前初始化，降低启动时主题闪烁。
- 全局上边栏不包含页面或项目面包屑。
- Windows 使用自定义最小化、最大化/还原和关闭按钮，通过受控 preload IPC 调用主进程。
- macOS 使用隐藏式系统标题栏和系统交通灯安全区，不渲染 Windows 窗口按钮。
- 标题栏拖拽区域与交互控件分别使用 `drag` 和 `no-drag` 区域。

## 三、验证结果

- `pnpm run typecheck`：通过。
- `pnpm run lint`：通过。
- `pnpm run build`：通过，Vite 转换 60 个模块，Electron TypeScript 构建完成。
- Windows Electron：通过 `pnpm run dev` 实际启动，并枚举到标题为 `UniComp` 的可见主窗口。
- 测试进程和 5173 端口占用已清理。

## 五、图标规范

- UI 功能图标统一使用 Lucide，通过 `react-icons/lu` 按图标名称导入。
- 第三方品牌图标仅在必要时使用 Simple Icons，通过 `react-icons/si` 导入，并核对对应品牌使用要求。
- UniComp 品牌 Logo 必须使用项目正式品牌资源；当前交接包未发现独立正式 Logo 文件，上边栏的 `U` 仅为明确标注的工程占位。
- Windows 最小化、最大化、还原和关闭按钮使用 `Segoe Fluent Icons` 系统标题栏字形，不使用 React Icons。
- 同一界面不得无理由混用 Lucide、Font Awesome、Material 等不同视觉体系。
- 功能图标默认继承文字颜色，通过 Design Tokens 控制状态颜色。
- 常用功能图标尺寸限定为 16px、20px、24px。
