## 三、统一可见页面检查

在 1080×720 与 1280×720 两种视口下依次打开：

1. 快速生图；
2. 专业生图；
3. 图片识别；
4. 图片编辑；
5. 图片转提示词。

两种尺寸下五个入口均满足：

- 二级导航入口唯一且标题正确；
- 未打开项目时不能创建或保存草稿；
- 页面宽度等于视口宽度，无横向溢出；
- 不显示示例结果、假进度、假费用或虚构模型。

浏览器环境不能注入 Electron 主进程 API，因此项目创建、受控文件选择、本地预览、草稿持久化和派生草稿切换由项目负责人在 Windows Electron 中统一手工验收。

## 四、统一真实边界

- 保存草稿不会自动创建任务。
- 选择图片不会自动上传、分析、编辑或生成。
- 模型、参数、能力、接收方、外发范围和费用状态只来自真实动态事实。
- 没有真实适配器时，提交、分析、编辑、重新生成和保存结果保持禁用。
- 图片识别的模型原始结果与用户修改记录分开保存。
- 图片编辑不覆盖原图，父草稿、父 Asset 和父作品关系可追溯。
- 图片转提示词保留分析前、当前和过期状态，输入变化不会删除旧结果。
- 上下文候选、蒙版选择、真实生成、识别、编辑和提示词分析仍等待对应受控端口或后台契约，不在 UI 中伪造。
