## 一、范围与边界

B3 只整改进程、媒体、代理、通知、快捷键、外链、电源和应用退出生命周期，不新增业务一级页面、登录、会员、充值、云同步、生产更新或发布能力。

Windows 继续使用已批准的 FFmpeg `8.1.2` LGPL-only 本地开发/测试工具链。macOS 媒体工具链没有获得版本、来源、架构、SHA-256 和许可批准，因此没有修改媒体清单、下载安装二进制或伪造 macOS 结果。`.tools/` 与二进制未进入 Git、生产构建或发布物。

## 二、实际修改

### 受控进程

- 新增统一 `ManagedProcessSupervisor`，只接受结构化命令与参数数组，固定 `shell: false`；
- 为能力探测、ffprobe、预览、缩略图、波形和软件导出设置明确超时与有界输出；
- Windows 使用 `taskkill /T /F`，macOS/POSIX 使用独立进程组、`SIGTERM` 和超时 `SIGKILL` 回退；
- 取消、超时与应用退出具有不同终止原因，超时或异常信号不再被误记为用户取消；
- 退出时等待受控进程结束并撤销短期媒体句柄。

### Task/Execution 与电源生命周期

- 视频导出控制器追踪真实活动 Execution 数量；
- 休眠、锁屏、禁止后台处理和应用退出会中断活动导出；
- 生命周期中断统一落到 `interrupted -> recovery_required`，不创建 Work、不重复完成；
- 用户主动取消仍保持 `cancel_requested -> cancelled`，不被生命周期事件覆盖；
- 活动导出可按设置启用 Electron `powerSaveBlocker`，结束或退出后释放。

### 系统集成与安全

- Electron 退出改为异步收口：先停止媒体与导出，再释放快捷键、目录授权、代理运行时和休眠阻止器；
- macOS 关闭最后一个窗口时遵守 `continueInBackground`，禁用后台处理则中断活动导出；
- renderer 发起的外链只允许无用户名/密码的 HTTPS URL，拒绝 HTTP、file、data 和 javascript；
- 新增 Electron 运行时验证入口，检查原生快捷键注册/释放、direct/system 代理解析、通知能力、电源状态和批准媒体工具链；
- 代理失败回滚、凭证隔离、通知不改变业务状态和快捷键注册回滚继续由既有 B3 设置服务测试覆盖。
