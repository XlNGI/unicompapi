## 一、实际修改

### 对话页

- 接入应用级已保存对话列表、创建、显式项目绑定、读取、重命名、归档、恢复和墓碑删除；
- 用户消息通过受控应用服务持久化，随后才请求真实回复；没有适配器时显示 `adapter_unavailable`，不创建 assistant Message、假片段、进度、费用或成功状态；
- 消息按 pending、streaming、completed、failed、cancelled 真实状态显示；归档或删除的对话不能追加消息；
- 普通删除只隐藏对话墓碑，页面明确告知已登记项目上下文不会被级联删除；
- 原生受控附件端口尚未批准，因此附件按钮保持禁用，不使用浏览器文件输入保存任意文件。

### 项目上下文登记

- 只允许从当前已保存 Conversation 的 completed Message 中选择内容；
- 当前 UI 支持选择同一 Conversation 的多个整段消息，整段选择仍保存明确 UTF-16 起止范围、消息 revision、角色、顺序和内容快照；
- 草稿创建、片段增删、预览、标签更新和显式确认登记分别调用命名 preload 方法；
- 未打开项目、未保存对话、未完成消息、空草稿和未确认预览均不能登记；
- 保存对话与登记上下文保持两个独立操作，登记结果属于当前受控项目。

### 创作工作区候选

- 专业生图和文生视频复用 `WorkspaceContextSelector`，不在页面复制供应商或模型判断；
- 选择器先读取 `readProjectContext` 与 `readSavedProjectChats`，关闭时隐藏并禁止相应候选操作；
- 候选只在用户点击后读取，不在页面加载时自动读取内容；
- 项目上下文候选只保存 contextId；已保存对话候选只保存显式绑定当前项目的 conversationId；
- 新增 `ConversationCandidateDto`，只返回 ID、projectId、标题、active/archived、消息计数、completed 计数和更新时间，不返回 MessageDto、正文、附件、路径、Hash、凭证或 endpoint；
- 工作区草稿只保存 `kind + referenceId`。当前不读取已保存对话正文；后续真实提交前仍需消息级明确选择和外发确认。

## 二、安全边界

- renderer 不传 projectId、文件路径、仓储位置、远端 operation ID、凭证或 endpoint；
- 安全对话候选由主进程按当前项目过滤，未打开项目返回 `project_not_open`；
- 项目上下文设置关闭时页面不查询候选；真正路由和外发时仍须在主进程再次执行策略检查；
- 页面不创建图片/视频 Task、Execution 或 Work，不实现供应商、模型、HTTP 或收费调用；
- 对话 candidate ID 只是人工选择来源，不表示允许读取全部消息，也不是外发授权。
