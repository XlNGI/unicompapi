## 一、完成范围

- 多文字层：新增、选择、修改、删除，以及开始/结束时间、字体、字号、对齐、位置、透明度、颜色、淡入和淡出；
- 字体：提交前使用浏览器原生 `document.fonts.check` 检查本机字体，不可用时拒绝保存并要求替换；
- 原声：按当前视频片段保存静音和 0% 至 100% 音量；
- 背景音乐：通过主进程原生选择器建立或替换唯一一条音乐，支持源裁剪、时间线范围、音量、淡入、淡出和移除；
- 封面：支持视频有效源时间选帧、经过内容校验的本机图片，以及当前项目已登记图片作品；
- `prependToVideo`：页面明确提供“仅作为封面”和“拼接到视频开头”两个选择，默认仅作为封面；
- 时间约束：文字和音乐提交前检查项目总时长，音乐同时检查源时长及淡入淡出总长。

## 二、受控媒体边界

背景音乐和本机封面不接收 renderer 路径：

- renderer 只提交 `draftId`、`expectedRevision`、受控 `workId` 和显式封面选项；
- 文件路径只由 Electron 主进程原生选择器持有；
- 本机封面复用现有图片头检查、流式 SHA-256 和稳定性复查；
- 项目图片必须属于当前项目、类型为图片、文件可用且内容检查通过；
- 背景音乐进行 RIFF/WAVE 结构、编码、数据长度、时长、稳定性和 SHA-256 校验；
- 成功后由主进程建立 `FileReference`、`Asset` 和可撤销领域命令，renderer DTO 不返回路径、原始 Hash 或修改时间。

媒体引擎版本、来源与许可尚未批准，因此本阶段没有安装或绑定引擎。背景音乐只声明并接受本机可安全解析的 PCM/浮点 WAV；MP3、M4A 等格式继续等待获批媒体引擎，不显示假能力。

## 三、验收约束

- 草稿只有一个 `backgroundMusic` 字段；再次选择音乐执行替换，不可能从 UI 叠加第二条；
- 文字与音乐时间越过项目总时长时不提交；
- 音乐源范围不能越过真实 WAV 时长；
- 淡入与淡出之和不能超过音乐时间线时长；
- 视频封面选帧必须位于对应片段有效源范围；
- 封面默认 `prependToVideo: false`，不会改变视频内容；
- 所有成功修改继续使用 revision、自动保存、撤销和重做。
