## 权威依据

- 最终 UI 与开发交接包 V1.2.1：图片、视频和作品预览拥有最高视觉权重；生成中必须表达真实阶段，不使用虚假进度。
- 项目规则：远端结果只有经过本地校验后才能登记为正式作品；等待态不得阻断软件导出或改变执行状态机。

## 实际修改

- `GenerationResultPreview` 等待画布改为细线双环、中心星芒图标、标题和说明，去除粗重呼吸光、扫描线与大面积强调背景。
- 图片专业/快速生图及快速/文生/图生视频工作区接入已有真实提交阶段：准备、提交、服务商处理中。
- 视频提交面板新增只读 `onProgressChange`，仅将真实阶段投影给预览，不改变提交、轮询、下载、校验或作品登记逻辑。
- `provider_accepted` 保留当前画布等待态；仅在真实 `completed` 后执行原有新草稿清空 UI 行为。
- 增加跨图片/视频工作区等待态契约测试，并保留 `prefers-reduced-motion` 降级。
