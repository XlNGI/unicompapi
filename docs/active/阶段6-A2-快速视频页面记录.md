# 阶段 6 A2｜快速视频页面记录

日期：2026-07-24

分支：`feature/quick-video-ui`

基线：`0d9f451 Merge video submission pipeline`

## 一、范围

本任务只实现快速视频页面，并复用 A1 公共视频工作区、B2 受控参考媒体及 B3 能力预检与提交流水线。

本任务不实现具体视频服务商适配器、上传、轮询、进度、取消、远端结果接收、下载、Work 登记、示例视频、批量视频或阶段 7 基础编辑。

## 二、一句话草稿

- 原始输入与最终提示词同步编辑，快速模式不自动执行提示词增强；
- 输入变化只修改当前项目内草稿，不自动预检或创建任务；
- 有未保存变化时，素材选择和预检保持禁用并提示先保存；
- 新建草稿、保存草稿和派生文生视频草稿互相独立。

## 三、单个可选参考素材

- 快速视频继续只使用 B1 定义的 `quick_reference` 单素材目标；
- 可接受图片、视频或不接受素材，只由所选能力证据的快速视频模式 Schema 决定；
- 图片与视频均通过 B2 原生文件选择、可信探测、FileReference/Asset 登记和短期 `unicomp-media` 预览；
- 选择素材不上传、不识别、不分析、不增强、不预检，也不创建 Task、Execution 或 Work；
- 移除素材只解除当前草稿绑定，不删除历史素材和文件引用；
- 页面不显示绝对路径、项目相对路径或原始 Hash。

## 四、动态能力与提交边界

- 模型只来自已启用的 `video_generation` 路由和本地注册表事实；
- 模型必须具备已验证或用户确认的能力证据、参数 Schema 和快速视频模式 Schema；
- 参数字段、枚举和数值范围按能力 Schema 动态显示；
- 预检同时展示全局和候选模型阻断，不推测模型、比例、时长、分辨率、帧率、数量或费用；
- 接收方、外发范围、素材范围、费用/隐私/地区、最终提示词和模型必须逐项确认；
- `createTask`、`createExecution` 和 `invokeExecution` 使用三个独立按钮，任何前一步都不会隐式触发下一步；
- 默认没有真实视频适配器，因此 `adapter_unavailable` 会阻止 Task 创建，不伪造远端状态。

## 五、结果与页面派生

- 页面不固定“默认一个结果”，结果数量只接受动态能力事实；
- B4 尚未合并时，不显示示例视频或假结果；
- “重新生成”和“保存结果”保持禁用并明确说明真实依赖；
- “进入文生视频”只调用 B1 `derive` 创建派生草稿并切换页面，不创建视频任务；
- 生成结果不会自动进入阶段 7 基础编辑。
