## 五、安全与真实能力边界

- 设置只保存在当前设备，不进入项目，不同步到云端；
- 高风险操作执行前重新校验计划、revision 和当前事实，失败不静默覆盖旧设置或有效目录；
- renderer 不接收绝对路径、原始 Hash、代理凭证、日志原文、更新 URL 或平台句柄；
- 诊断包只在本地生成、默认脱敏且不自动上传；
- 没有获批生产更新源时只返回真实 `unavailable`，不宣称最新、可安装、可修复或可回退；
- 硬件能力不可用或失败不得阻止已批准的软件导出；
- `.tools/`、FFmpeg 二进制和下载包继续由 Git 忽略，只限本地开发/测试，不进入生产构建或发布物。
