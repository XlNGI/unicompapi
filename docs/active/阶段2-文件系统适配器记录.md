# 阶段 2｜文件系统适配器记录

日期：2026-07-21
分支：`feature/local-filesystem-adapter`
负责人：开发者 B｜本地领域与平台

## 一、本次实现

- 建立 `NodeProjectStorage`，实现 `ProjectStorageAdapter`。
- 所有访问都使用已校验的项目相对路径，并再次确认解析结果位于项目根目录内。
- JSON 文件不存在时返回 `undefined`，其他读取或解析错误保持抛出。
- JSON 写入使用目标同目录临时文件，写入后执行 `fsync`，再通过 `rename` 替换目标。
- 替换失败时不先删除旧目标；临时文件在成功或失败后统一清理。
- 删除操作保持幂等；目录创建支持递归。
- 新增独立 `test:platform` 命令，并将平台测试纳入完整 `test` 命令。

## 二、安全边界

- 适配器只接受 `ProjectRelativePath`，不接受渲染进程传入的任意绝对路径。
- 领域层未导入 `node:fs`、Electron 或平台实现。
- 测试只使用操作系统临时目录，并在每个用例后递归清理。
- 未记录用户项目根目录、绝对文件路径、凭证或文件内容。
