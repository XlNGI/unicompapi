## 一、范围与边界

B2 只整改项目文件、仓储、目录授权、安全存储和敏感产物边界，没有新增业务页面、依赖、媒体二进制或发布能力。renderer 继续只接收 FileReference/目录等受控 ID，不接收绝对路径、Hash、凭证、书签或原生平台句柄。

本次在 Windows 真实工作区执行自动化和 Electron `safeStorage`。macOS 实机不可用，因此 macOS 结果全部保持 `not_run`，不得使用 Windows 结果替代。

## 二、实际修改

### 可移植路径与符号链接防护

新增统一路径安全策略：

- Unicode 文件名转换为 NFC；
- 支持名称中的普通空格、中文和深层长路径；
- 统一接受 `/` 与 `\\` 输入分隔符；
- 拒绝绝对路径、盘符、空段、`.`、`..`、NUL 和控制字符；
- 拒绝 Windows 保留名、非法字符、尾随点和尾随空格，避免项目在另一平台无法打开；
- 在读、写、删除、建目录、Hash、状态探测、恢复和受控媒体使用前检查项目根及每个已存在路径段；
- 项目内符号链接或 Windows 目录联接一律拒绝，不能把访问导向项目根外。

项目仓储仍使用同目录排他临时文件、文件同步、原子替换和目录同步；写入失败不会把临时内容当作正式事实。

### 目录授权与迁移

目录注册表升级为 Schema v2：

- 旧 Schema v1 自动迁移为 `native_picker` 授权；
- 注册路径在主进程验证为真实目录并规范到实际路径；
- 符号链接目录不能注册；
- 注册表写入前保留最后一个有效备份，主文件损坏时只读取备份，不覆盖损坏证据；
- 同一路径重新选择时保留受控 ID 并更新授权，可用于撤销后的重新授权；
- macOS 沙盒选择器返回安全作用域书签时只保存在主进程注册表；激活失败映射为 `permission_required + directory_authorization_revoked`；
- Windows 和未返回书签的非沙盒选择器继续通过实际读写权限确定状态。

目录迁移覆盖 Unicode、空格和深层路径，继续在复制前冻结文件大小与 SHA-256，逐文件复制后复验，失败保留源和旧事实。

### 安全存储与回滚

安全凭证仓储新增：

- 新密文写入前执行保护/解保护闭环，结果不一致或解密异常时不触碰旧凭证；
- 替换前保存最后一个有效密文备份；
- 主文件损坏时只读取有效备份，不覆盖损坏证据；
- 新进程实例可以恢复并使用旧凭证；
- 解密失败保持 `unreadable`，不返回明文；
- 清除本机凭证或目录授权时同步删除主文件和 `.bak`，避免旧密文或书签残留。

新增 `npm.cmd run verify:secure-storage`，在真实 Electron 主进程调用操作系统 `safeStorage`。Windows 结果为：可用、加密/解密闭环成功、密文字节不包含明文。

### 敏感产物

日志和诊断包在既有凭证、Cookie、Token 和提示词脱敏基础上，新增：

- SHA-256 摘要；
- 主机名、设备 ID、机器 ID 和序列号；
- Windows、macOS、Linux 用户路径；
- `file://` 本地 URI。

便携设置、renderer DTO、项目、任务和作品仍不包含凭证、目录书签、绝对路径或原始 Hash。
