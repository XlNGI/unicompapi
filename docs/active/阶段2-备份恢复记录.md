# 阶段 2｜备份恢复执行器记录

日期：2026-07-22
分支：`feature/project-storage-session`
负责人：开发者 B｜本地领域与平台

## 一、本次实现

- 新增 `NodeBackupRestoreExecutor`，执行用户确认后的本地备份恢复。
- 恢复目标只允许项目托管的安全相对路径，不覆盖外部源文件。
- 必须存在目标文件已记录的 SHA-256 证据；没有证据时拒绝恢复。
- 备份先复制到目标同目录临时文件，执行 `fsync` 和 SHA-256 校验，通过后才原子替换目标。
- 校验失败时删除临时文件，保留原目标文件不变。
- 接入受控主进程恢复流程：renderer 只提交 `fileId`，备份文件由主进程原生选择器产生。
- 恢复成功后重新探测目标，并持久化 `FileReference` 状态、校验证据和派生索引。

## 二、安全边界

- 未经明确确认不执行恢复。
- 不接受渲染进程提交备份路径或任意目标路径。
- 不把外部文件作为可覆盖目标。
- 不因文件名或来源相同而跳过 Hash 校验。
- 不接后台，不实现重新下载。

## 三、验证结果

- 成功恢复缺失的项目文件并返回匹配的校验证据。
- 错误备份不会覆盖现有目标文件。
- 未确认、缺少 Hash 证据或目标为外部文件时明确拒绝。
- Windows 临时目录执行器测试 3 项通过。
- 受控 IPC 控制器覆盖成功、取消和 Hash 不匹配，共 5 项通过。
- preload 与共享契约新增 `restoreBackup(fileId)`，未暴露路径或原始 Hash。
