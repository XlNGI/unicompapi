# 阶段 9 E5.1/E5.2｜工具注册与 Agent 循环验收记录

日期：2026-09-01
分支：`feature/phase9-document-intent-plan`
状态：E5.1/E5.2 本地合同与自动化验收完成；E5.3-E5.6、E6 尚未启动

## 一、实际修改

- 新增受控 `DocumentToolDefinition` 注册表，仅允许资料提取、数据汇总、图表、素材、结构读取、结构化补丁、渲染和布局诊断八类工具。
- 新增 `parseDocumentToolRequest`：严格校验工具 ID、标量参数、理由和字段名，拒绝绝对路径、URL、Token/Secret/Password/Credential 等受保护值。
- 新增 `runDocumentAgentLoop`：Application 层控制最大步数、预算、总超时、取消、允许工具集和连续相同诊断熔断；每轮只执行一个已注册工具。
- 工具结果转为脱敏、限长的结构化观察 DTO；观察结果不携带路径、URL、凭证或任意代码。
- 工具执行器、LLM 决策器均通过依赖注入提供，本轮不连接真实 Word/Excel/PPT 工具、IPC、网络、Provider 或收费服务。
