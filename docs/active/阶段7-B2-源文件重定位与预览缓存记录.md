## 二、实际修改

### 2.1 三类源视频登记

新增 `VideoEditorMediaController`，提供：

- `external_reference`：主进程原生选择后保存明确授权的外部文件引用；
- `managed_project_copy`：复制到项目临时目录，完成内容探测、流式 SHA-256、临时文件 `fsync` 和二次校验后，同卷原子发布到 `files/editor-sources/`；
- `managed_work`：复用当前项目已经登记且本地可验证的视频 Work/FileReference，不复制或覆盖历史作品。

所有新源均通过既有 ISO BMFF MP4/MOV 内容探测读取真实容器、MIME、时长、宽高和字节数，不信任扩展名。检查前后文件大小、修改时间和媒体元数据必须稳定，流式 SHA-256 作为主内容身份依据。

导入成功后创建 FileReference 与 Asset，并通过 B1 内部 `insert_clip` 命令追加到单视频主轨。保存草稿仍不创建 Task、Execution 或 Work。

### 2.2 可撤销重定位

EditDraft 命令联合新增内部 `set_clip_source` 命令。命令记录替换前后的 `VideoClipSource`，进入相同 revision、undo/redo 和有界历史流程；renderer 不能直接提交该内部命令。

重定位采用两阶段流程：

1. 主进程原生选择候选，重新探测并计算内容身份；
2. renderer 只接收短期确认句柄、安全候选元数据和内容/大小/时长/容器/尺寸差异布尔值；
3. 完全匹配可直接确认；
4. 不匹配必须显式传入 `acceptMismatch: true`；
5. 候选短于当前片段源范围时拒绝确认；
6. 草稿 revision 或片段源在确认前变化时返回冲突；
7. 确认时创建新的 FileReference/Asset，不静默改写旧文件记录，因此撤销后仍能恢复旧源关系。

没有按同名文件自动替换，也没有向 renderer 返回候选路径或原始 Hash。

### 2.3 文件状态与原片预览

新增源状态检查：

- 文件丢失返回 `missing`；
- 外部存储不可达沿用 `disconnected` 状态；
- 内容 Hash 不匹配返回 `corrupted` 和 `matchesIdentity: false`；
- 仅修改时间变化但内容一致时保留可用状态并报告 `metadata_changed`；
- 状态异常不会删除片段或草稿。

补齐文件从“内容已变化”到“随后丢失”的持久化状态路径，避免恢复检查因状态机转换失败中断。

原片预览前必须重新执行本地文件和内容身份检查。通过后只返回短期 `unicomp-media` 句柄、MIME 和过期时间；路径、项目相对位置和 Hash 继续留在主进程。

### 2.4 PreviewPlan 与缓存端口

新增版本化 `VideoEditorPreviewPlan`，冻结草稿 revision、片段、源身份、源范围、速度、画面变换和原声设置。新增：

- `proxy_video`；
- `thumbnail_strip`；
- `audio_waveform`；
- `VideoEditorPreviewArtifactAdapter`；
- `NodeVideoEditorPreviewCache`；
- 按源身份、预览参数、产物类型、适配器 ID 和版本计算的 SHA-256 缓存键。

缓存位于项目 `cache/video-editor-preview/`，不进入 `files/`、FileReference、Asset 或作品库，可整体删除和重建；删除缓存不修改 EditDraft。

具体媒体引擎尚未审批，因此 Electron 默认注入 `UnavailableVideoEditorPreviewAdapter`。代理、缩略图和波形请求真实返回 `adapter_unavailable`，没有伪造文件、进度、能力或结果。

### 2.5 安全 IPC

新增受控 IPC：

- `selectSource`；
- `attachWork`；
- `getSourceStatus`；
- `prepareRelink`；
- `confirmRelink`；
- `createSourcePreview`；
- `requestPreviewArtifact`；
- `clearPreviewCache`。

选择请求不接受 renderer 注入的路径。DTO 不包含绝对路径、项目相对路径、原始 Hash、修改时间指纹、命令历史、缓存位置、媒体引擎命令、进程句柄或内部堆栈。
