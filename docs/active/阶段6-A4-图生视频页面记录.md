# 阶段 6 A4｜图生视频页面记录

日期：2026-07-24

分支：`feature/image-to-video-ui`

基线：`37f1905 Merge text to video workspace`

## 一、范围

本任务只实现图生视频页面，复用公共视频工作区、B2 受控参考媒体、B3 动态能力预检与提交流水线，以及既有视频动态模型、参数和确认控件。

本任务不实现图片识别、提示词增强、具体视频服务商适配器、结果接收、下载、B4 正式 Work 登记或阶段 7 视频编辑。

## 二、动态素材槽位

- 只有选择具有图生视频模式 Schema 的模型后才建立素材槽位；
- 槽位 ID、角色、数量、必填状态和可接受图片/视频类型全部来自能力证据；
- 页面不写死首帧、尾帧、主体参考或任何服务商特有槽位；
- 更换模型时只保留 ID、角色和媒体类型仍兼容的既有选择；
- 素材只能通过 B2 主进程原生选择、可信探测、Asset/FileReference 登记和短期预览；
- 选择或移除素材不上传、不识图、不增强，也不创建 Task、Execution 或 Work。

## 三、保持、变化与运动要求

- 必须保持、允许变化和必须避免使用三个独立字段，每行保存一项；
- 用户原始输入、主体动作、运镜、节奏和景深分别编辑；
- 页面不会根据图片自动推断上述内容；
- 修改草稿后，旧预检、确认、Task 和 Execution 页面状态立即清除，避免误用旧事实。

## 四、提示词与过期状态

- 用户原始输入、系统补充内容和最终提交提示词分三层展示；
- 最终提交提示词允许用户显式编辑；
- 页面展示增强结果与草稿预检的 `not_created/current/stale` 状态；
- 旧内容过期时同时展示具体过期原因；
- 缺少真实增强端口时按钮保持禁用，不伪造系统补充内容。

## 五、动态能力、提交与编辑边界

- 模型、参数和图生视频模式能力只来自本机注册表及能力证据；
- 预检展示全局与候选模型的真实阻断；
- 接收方、外发范围、素材范围、费用/隐私/地区、最终提示词和模型必须逐项确认；
- 预检、Task、Execution 和远端调用是四个显式且相互独立的操作；
- 默认没有真实适配器，`adapter_unavailable` 阻止 Task 创建；
- 页面不显示假费用、假进度、示例视频或假成功状态；
- 没有 B4 正式 Work 与阶段 7 编辑能力时，“进入基础编辑”保持禁用并解释原因。

## 六、布局

- 1—4 区按素材、变化要求、动作镜头、提示词顺序连续排列；
- 第 5 区在宽屏作为独立提交侧栏，1500px 以下接到主流程下方；
- 动态槽位空状态只占实际内容高度，不产生等高网格空白；
- 760px 以下保持/变化字段与动作/镜头字段改为单列；
- 宽屏布局夹具确认相邻主卡片间距连续，卡片无内部横向溢出；
- 1500px 以下响应式实测 `documentElement.clientWidth === documentElement.scrollWidth`。
