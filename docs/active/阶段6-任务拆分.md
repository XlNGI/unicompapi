## 一、阶段目标

建立视频生成的项目内本地工作区、草稿、显式素材引用、提示词与镜头方案、动态能力预检、任务提交边界、结果校验和真实离线页面，为后续后台视频生成适配器预留稳定端口。

阶段 6 生成工作区只包含：

1. 快速视频；
2. 文生视频；
3. 图生视频。

“基础编辑”继续作为第四个冻结导航入口存在，但正式编辑领域、时间线、媒体引擎、预览代理和导出属于阶段 7。本阶段不得借视频创作之名提前实现视频编辑引擎。

明确不包含视频批量创作，也不恢复“首页”、多图参考独立页、图片批量创作、账号、会员、充值或云同步。

- 当前项目 Session、项目目录和版本化 JSON 仓储；

- 没有视频能力预检、提交确认、调用端口和结果接收端口；
- 没有真实视频生成适配器；
- 没有视频基础编辑领域、媒体引擎、时间线、导出任务或恢复机制。

## 五、强制业务边界

- 视频创作必须属于当前已打开项目；未打开项目时不得创建视频草稿或任务。
- 选择图片或视频素材只建立本地受控引用，不得自动上传、分析、生成或创建任务。
- 快速视频只允许一句话输入和一个可选参考素材，不恢复通用多图参考能力。
- 文生视频只能读取用户明确选择的项目素材、项目上下文和已保存对话上下文；未保存或未选择内容不得自动读取。
- 图生视频的图片槽位、数量和角色必须来自动态能力事实；不得把首帧、尾帧、主体参考等槽位写死为所有模型均支持。
- 图生视频选择图片后不得默认先调用图片识别；识别、提示词增强和生成必须是独立操作。
- 用户原始输入、系统补充内容和最终提交提示词必须分别保存、展示、编辑和追溯。
- 文生视频的镜头草稿、镜头顺序和分镜示意图只属于本地草稿；生成分镜草稿或提示词增强不得创建视频任务。
- 服务商、模型、时长、比例、分辨率、帧率、格式、数量、费用和参考素材限制必须来自动态能力事实。
- 未验证能力不得标记支持；费用、隐私、地区、接收方和外发范围未知时必须保持未知。
- 自动路由不得绕过接收方、素材范围、费用、外发范围、最终提示词和模型确认。
- 保存草稿、预检、创建 Task、创建 Execution、调用远端、接收结果和登记 Work 必须是不同操作。
- 重试必须创建新 Execution，不覆盖原失败记录；取消请求不得提前标记为已取消。
- 远端完成不等于本地完成；必须下载、写入、校验并原子保存后才能登记视频作品。
- 视频结果进入基础编辑时不得自动执行编辑；阶段 7 尚未完成时入口必须禁用并说明原因。
- 基础编辑页不得调用图片或视频生成模型，不得覆盖源视频，也不得因硬件加速失败阻止软件导出。
- renderer 不得接收绝对路径、原始 Hash、凭证、endpoint、远端 operation ID、内部命令或内部错误堆栈。

## 六、当前外部阻断项

后台团队尚未提供视频生成的：

1. Base URL、鉴权方式、接口路径和 HTTP 方法；
2. 请求/响应体、异步任务、轮询、流式事件或回调契约；
3. 错误码、限流、取消、重试、恢复和幂等规则；
4. 图片/视频参考素材的类型、大小、像素、时长、码率、色彩空间和上传限制；
5. 动态素材槽位、角色、数量和模型组合限制；
6. 比例、时长、分辨率、帧率、格式、数量和其他动态参数 Schema；
7. 费用、隐私、地区、数据保留、内容安全、接收方和外发说明；
8. 远端视频状态、进度、结果下载、过期、断点能力和校验契约。

契约齐备前可以实现本地草稿、素材引用、能力预检端口、提交确认快照、任务/结果端口和真实离线 UI；不得猜测 HTTP 请求、伪造进度、费用、成功、视频结果或下载能力。

阶段 7 另有本地媒体引擎选型、FFmpeg/等效引擎许可与分发、硬件编码、代理、字体和跨平台进程管理等准入项，不并入阶段 6 视频生成适配器。

### B1｜视频生成工作区领域契约

- 定义快速视频、文生视频和图生视频三类生成草稿判别联合，不把基础编辑草稿混入生成联合。
- 建立当前项目约束、提示词三层、上下文引用、动态素材槽位、素材角色和模型能力引用。
- 快速视频保持单个可选参考素材；专业工作区的素材槽位和数量只接受能力事实。
- 定义文生视频的短创意/长文本来源、镜头草稿、顺序、动作、运镜、节奏、景深和分镜状态。
- 定义图生视频的保持、允许变化、必须避免、动作、运镜、节奏和景深要求。
- 图片、素材角色、上下文、镜头方案或关键要求变化后，旧预检和旧增强结果必须标记过期。
- 建立派生生成草稿关系；进入其他生成模式只创建草稿，不创建任务。
- 为“生成结果进入基础编辑”定义受控交接意图和来源关系，但不实现阶段 7 EditDraft Schema 或时间线。
- 建立版本化仓储、运行时严格校验和不含路径/Hash 的 renderer DTO。

### B2｜受控参考媒体与本地预览

- 只通过 Electron 主进程原生选择器获得用户明确选择的文件，不接受 renderer 任意路径。
- 图片引用复用阶段 5 内容签名、尺寸、字节和 SHA-256 检查。
- 视频引用必须经过可信媒体探测端口；无法识别容器、时长、尺寸或可读性时不得登记为可用素材。
- 支持外部授权引用或项目受管文件，不强制复制全部大视频；引用策略必须显式记录。
- 将通过检查的素材登记为 Asset 与 FileReference，草稿只保存 ID、角色和受控元数据。
- 预览只返回短期 `unicomp-media` 句柄；MIME、范围请求和失效状态由主进程控制。
- 素材选择不上传、不分析、不创建 Task、Execution 或 Work。
- 文件丢失、变化、断开或不可读时保留草稿并返回真实状态，不静默匹配同名文件。

### B3｜能力预检与提交流水线

- 按 `video_generation` 用途查询真实路由偏好、可用连接、已启用模型、能力证据和动态参数 Schema。
- 校验素材槽位/角色、文本、镜头方案和参数是否满足当前候选模型的真实约束。
- 缺少路由、能力未知、Schema 缺失、素材不符合或适配器缺失时返回明确阻断。
- 显式确认快照冻结接收方、访问类型、外发范围、素材范围、费用/隐私/地区状态、模型、参数和最终提示词。
- 保存草稿、预检、创建 Task、创建 Execution 和调用远端保持独立 IPC。
- 定义快速视频、文生视频和图生视频调用端口；没有适配器时返回 `adapter_unavailable`。
- 进度、排队、取消、重试和恢复能力只接受适配器真实事件或能力事实，不生成模拟值。
- 远端 operation ID、请求细节和凭证只保存在主进程实体，不返回 renderer。

### B4｜视频结果接收与作品登记

- 将远端完成、结果发现、下载、临时写入、媒体探测、字节/Hash 校验、原子落盘和 Work 登记拆分为可测试阶段。
- 大文件下载必须采用流式写入，不把完整视频加载进 renderer 或主进程内存。
- 结果容器、时长、尺寸、可读性和服务声明必须由可信探测/校验事实确认；未知或不匹配时不登记作品。
- 下载、探测、校验、写入或 fsync 失败不得创建正式 Work。
- Execution 只有在本地文件校验与持久化成功后才能完成；Work 按现有领域约束在已完成 Execution 上登记，登记失败不得返回成功，并必须保留可恢复的文件与执行事实。
- 每个成功结果建立独立 FileReference、Work 和来源关系，不覆盖历史版本。
- 受控视频预览继续复用短期媒体句柄，不泄露项目路径和原始 Hash。
