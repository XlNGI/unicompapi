# 阶段 3｜全局页面任务拆分

日期：2026-07-22
状态：待开发
基线：阶段 2 已正式收口的最新 `develop`

## 一、阶段目标

阶段 3 在阶段 2 本地领域、仓储、项目 Session 和受控 IPC 基础上，实现以下全局页面的真实本地状态与主要交互：

1. 对话；
2. 项目；
3. 任务中心；
4. 作品库。

本阶段必须以最终 UI 交接包 V1.2.1 的权威资源为视觉依据：

```text
resources/高保真页面/全局页面/00-对话.png
resources/高保真页面/全局页面/01-项目入口与最近创作.png
resources/高保真页面/全局页面/02-任务中心与任务详情.png
resources/高保真页面/全局页面/03-作品库与作品详情.png
```

## 二、阶段边界

本阶段不做：

- 不恢复“首页”，项目页继续承担主要项目入口；
- 不让对话页直接创建图片、视频或编辑任务；
- 不实现真实 AI 问答、模型调用或服务商连接；
- 不实现图片或视频创作流程；
- 不实现模型与服务商业务页，该能力进入阶段 4；
- 不实现本地设置 10 个分类的业务能力，该能力进入阶段 8；
- 不写死服务商、模型、价格、时长、分辨率、数量、进度或排队时间；
- 不向 renderer 暴露项目根目录、备份路径、原始 Hash 或通用文件系统能力。

## 三、统一事实来源

- 项目、任务、执行、文件和作品继续使用 `src/domain/` 领域契约。
- JSON 仓储和文件索引是本地事实来源，UI 不复制状态机。
- renderer 只消费受控 DTO；路径选择、目录创建、文件读取和恢复由 Electron 主进程执行。
- 任务中心展示真实任务与执行记录，不把草稿当任务，不显示虚假进度。
- 作品库只展示已写入本地并完成校验的作品，不把远端 URL 或未校验文件登记为作品。
- 对话内容只有经过用户明确选择、检查并保存后才能成为项目上下文；未保存内容不得被创作页自动读取。

## 四、开发者 B｜本地读模型与平台流程

建议按以下短期分支拆分：

```text
feature/project-catalog-create
feature/global-read-models
feature/controlled-local-media
```

### B1｜项目目录与新建项目

- 建立主进程项目目录，记录最近打开项目、可用状态和最后打开时间。
- 绝对路径只保存在主进程受控存储，不进入 renderer DTO、日志或项目业务实体。
- 实现原生目录选择后的新建项目流程：校验空目录/冲突、写入 `project.json`、建立固定目录和初始索引。
- 新建成功后设置活动 Session；取消或失败不替换现有 Session。
- 提供按项目 ID 打开、关闭、重新定位和从目录移除最近记录的受控操作。
- 不自动迁移未知版本或损坏项目。

### B2｜全局页面只读 DTO

- 建立项目摘要 DTO：ID、名称、可用状态、最后打开时间和本地内容摘要，不返回绝对路径。
- 建立任务摘要/详情 DTO：项目来源、任务状态、最近执行状态、失败/取消/恢复事实和时间字段。
- 建立作品摘要/详情 DTO：项目来源、媒体类型、版本来源、文件状态和已验证元数据。
- 从主进程项目目录读取多个可用项目；单个项目不可用时返回真实状态，不阻断其他项目。
- 为分页、空白、损坏仓储和外置存储断开建立测试，不提前写死筛选项或远端能力。

### B3｜受控本地文件操作

- 需要缩略图或预览时，以 `fileId` 建立受控读取方案，不返回文件绝对路径。
- 提供按 `fileId` 触发重新定位、备份恢复和系统文件定位的主进程操作。
- 恢复、重新定位和文件状态变化后刷新读模型；所有写操作继续进入统一变更队列。
- 保持 Windows/macOS 契约一致，平台差异留在适配层。

## 五、开发者 A｜全局页面与交互

建议按以下短期分支拆分：

```text
feature/project-center-ui
feature/task-center-ui
feature/work-library-ui
feature/chat-page-ui
```

### A1｜项目页

- 按权威设计图实现项目入口、最近项目、最近任务、最近作品和创作入口。
- 接入项目目录 DTO、新建项目、打开项目和关闭 Session。
- 无活动项目时，创作入口必须先要求创建或选择项目，不创建孤立草稿或任务。
- 页面默认入口在项目页准备完成后从“对话”调整为“项目”，一级导航顺序不变。
- 覆盖空白、加载、项目失效、只读、损坏、断盘和操作失败状态。

### A2｜任务中心

- 按权威设计图实现任务列表、筛选布局、任务快速视图和详情层。
- 展示排队、处理、远端完成、下载、校验、本地完成、失败、取消未知、可重试和不可恢复等真实状态。
- 不显示推算的进度百分比、排队时间或费用。
- 支持返回来源项目和打开已登记作品，不在任务中心复制作品管理能力。

### A3｜作品库

- 按权威设计图实现作品列表、筛选布局和作品详情层。
- 只展示已登记作品；文件缺失、只读、断盘和损坏时保留记录并提供真实恢复入口。
- 展示来源项目、来源任务、来源执行和父子版本关系。
- 不覆盖原始文件或历史版本，不把页面实现成普通文件浏览器。

### A4｜对话页

- 按权威设计图实现独立问答、分析、整理和项目上下文沉淀页面结构。
- 阶段 4 前只展示离线/未配置服务的真实状态，不伪造 AI 回复。
- 附件默认只属于当前对话；用户明确选择内容后形成上下文草稿，检查后才能保存到项目。
- 不加入“生成图片”“生成视频”或提交创作任务按钮。
- 未保存到项目的对话内容不得出现在项目或创作页。

## 六、合并顺序

1. B 提交项目目录、新建项目契约和测试。
2. A 基于已合并 DTO 接入项目页，不复制目录状态。
3. B 提交任务、作品只读 DTO 和受控文件操作。
4. A 分别提交任务中心、作品库和对话页；每个页面使用独立小 PR。
5. 两人在最新 `develop` 完成 Windows 联调、权威截图对照和完整门禁。
6. 项目负责人确认后关闭阶段 3；不得直接合并 `main`。

## 八、阶段 3 验收门禁

- 四个全局页面结构与权威设计图一致，并完成 Windows 截图对照记录。
- 项目页可真实新建、打开、关闭和恢复本地项目状态。
- 项目、任务和作品页面使用真实仓储读模型，没有硬编码业务数据。
- 对话页不直接创建创作任务，未配置服务时不伪造回复。
- 任务中心不显示虚假进度；作品库不登记未完成本地校验的结果。
- 所有文件操作保持 `fileId` 受控边界，不暴露绝对路径或通用 Node 能力。
- 空白、加载、失败、只读、断盘、文件缺失和恢复状态可处理且可访问。
- 导航名称、顺序、展开规则和禁止项保持不变。
- 自动化测试、TypeScript、ESLint、生产构建和 `git diff --check` 通过。
- Windows 可见 Electron 联调通过；macOS 差异记录到阶段 9，不伪标通过。
- `PLANS.md` 和阶段 3 联调记录包含实际结果、失败项与后置事项。
