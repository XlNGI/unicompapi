# 阶段 4｜服务商管理写接口补充记录

日期：2026-07-22
分支：`feature/provider-management-mutations`
来源：开发者 A 页面接入阻断反馈

## 一、补充原因

开发者 A 验收 B1/B2/B3 后确认，只读注册表、凭证、验证、目录、能力和路由接口已经可用，但页面仍缺少以下受控写操作：

- 新增服务商和连接，包括自定义兼容接口；
- 更新、停用和删除连接；
- 启用和停用模型。

该缺口属于开发者 B 的平台契约遗漏，本次已补齐。

## 二、新增 ProviderApi

```text
createProvider(name, accessCategory)
createConnection(providerId, name, endpoint)
updateConnection(connectionId, name, endpoint)
setConnectionEnabled(connectionId, enabled)
deleteConnection(connectionId)
setModelEnabled(modelId, enabled)
```

`accessCategory` 继续只允许 `online`、`local`、`lan`、`custom_remote`，不预置或冒充具体厂商。

## 三、删除与历史边界

- 连接删除采用 `deleted` 墓碑状态，不物理移除连接记录。
- 删除时清除 endpoint、凭证引用和本机加密凭证。
- 关联模型与路由被停用，但模型和能力证据记录保留。
- 不操作项目、任务、执行记录、作品或来源记录。
- 返回 `remoteRevocation: not_attempted`，不伪造服务商侧凭证撤销。

## 四、状态边界

- 新连接有 endpoint 时为 `saved`，没有 endpoint 时为 `unconfigured`。
- 启用连接只恢复为 `saved` 或 `unconfigured`，不会标记为 `available`。
- 更新 endpoint 会清除旧连接验证时间并重置身份状态，不继承“已验证”结论。
- 模型启停不生成任何能力证据。
- renderer 可以提交 endpoint，但只读 DTO 仍不返回 endpoint 或凭证引用。
