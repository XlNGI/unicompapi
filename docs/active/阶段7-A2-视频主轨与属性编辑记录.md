## 二、实际实现

### 受控素材与源状态

- 通过 `selectSource` 添加授权外部引用或项目托管副本；
- 通过 `listWorks` 和 `attachWork` 添加当前项目已登记的视频作品；
- 多次添加按顺序追加到单视频主轨；
- 通过 `getSourceStatus` 展示可用、丢失、内容变化、存储断开和需要重定位；
- 通过 `prepareRelink`、原生明确确认和 `confirmRelink` 完成两阶段重定位；
- 不匹配候选必须由用户明确确认，重定位仍进入 revision 与撤销/重做历史；
- renderer 不读取路径、Hash、缓存位置或媒体引擎命令。

### 预览与播放头

- 通过 `createSourcePreview` 加载重新校验后的短期原片句柄；
- 原片预览限制在当前片段裁剪范围内；
- 播放器时间与全局播放头按裁剪范围和速度互相换算；
- `requestPreviewArtifact` 只在用户点击时检查代理缓存；
- `clearPreviewCache` 明确只清理可重建缓存，不修改草稿或源文件；
- 媒体引擎未审批时真实显示 `adapter_unavailable`，不伪造代理、缩略图、波形或进度。

### 主轨与领域命令

所有操作只提交现有领域命令，成功返回的 EditDraft DTO 是唯一持久化事实：

- `trim_clip`；
- `split_clip`；
- `remove_clip` / `restore_clip`；
- `duplicate_clip`；
- `move_clip`；
- `set_clip_speed`；
- `set_clip_transform`；
- `set_canvas`。

片段起点不保存在 UI。时间线按当前顺序、裁剪、速度和转场实时计算，使用整数微秒与 BigInt 运算，避免浮点持久化和第二套业务状态。

### 属性编辑

- 裁剪开始/结束；
- 整片段速度；
- 缩放、水平/垂直位置、旋转、水平/垂直翻转；
- 标准化裁切范围；
- 画布跟随源比例或用户自定义整数比例；
- 适应/填满；
- 纯色或源画面模糊背景。
