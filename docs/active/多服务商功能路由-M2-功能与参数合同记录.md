## 一、批准边界

本支只实现显式 ProductFeature、固定内部用途映射、ParameterSchema V2、快速/专业参数投影和产品素材约束，并收紧 ModelFeatureProfile 的 productFeature 解析。未修改历史 Draft/Task/Execution 数据、React、preload、Electron 页面、真实协议适配器、阶段 10 或 macOS 实机目标。

本支禁止真实服务商 HTTP、真实凭证读取/验证和收费调用。Vidu 两项已用尽预算继续封存，Image V1 未验证事实不变。

## 二、实际实现

- 冻结九类 `ProductFeature`：文本聊天/推理、图片识别/转提示词、文生图/参考图生图/图片编辑、文生视频/图生视频，并提供带版本快照可引用的固定内部用途映射。
- `ModelFeatureProfileFeature.productFeature` 从任意字符串收紧为 `ProductFeature`；Provider Registry 解析未知 feature 时失败，不再依靠字符串模糊匹配。
- 新增 `ParameterSchemaV2`：稳定 schema/field ID、revision、ProductFeature、类型、分组、顺序、exposure、defaultPolicy、枚举/范围/步长/单位和 secret/internal 约束。
- `required_only` 只投影 `user_required`；`full` 只投影 `user_required + user_optional`；内部、产品固定和适配器派生字段不会进入页面投影。
- 同一校验器拒绝缺失必填、未知字段、旧 Schema、非法类型/范围、快速页传入可选字段和内部字段；可选字段未填写时保持省略，不猜首个枚举、最小值、空字符串或 `false`。
- 快速生图固定 `text_to_image`、快速视频固定 `text_to_video`，二者禁止参考素材和会话上下文；专业 `reference_to_image` 与 `image_to_video` 必须恰好一张受控图片；图片编辑、识别和转提示词继续保持独立单图功能。
