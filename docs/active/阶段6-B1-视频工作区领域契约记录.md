# 阶段 6 B1｜视频工作区领域契约记录

日期：2026-07-23
分支：`feature/video-workspace-contracts`
基线：`ff1d017 Merge phase 6 video creation planning`

## 一、实际修改

### 视频生成工作区

- 新增 `quick_video`、`text_to_video`、`image_to_video` 三模式判别联合；
- 基础编辑继续属于阶段 7，不进入视频生成草稿联合；
- 草稿必须属于当前项目，并保存创建、保存、过期、归档和派生来源事实；
- 用户原始输入、系统补充内容和最终提交提示词继续独立保存；
- 项目素材、项目上下文和已保存对话上下文只保存显式引用 ID。

### 素材与动态能力

- 快速视频结构上最多只接受一个可选参考素材；
- 文生视频和图生视频使用由能力证据绑定的动态素材槽位；
- 每个槽位记录角色、是否必需、可接受媒体类型和可选素材选择；
- 所选素材的媒体类型及角色必须与槽位匹配；
- 模型、动态参数和素材槽位使用同一能力证据时必须保持一致；
- 草稿只保存 Asset ID 和受控业务元数据，不保存路径或 Hash。

### 文生视频与图生视频

- 文生视频区分短创意与长文本/故事/脚本来源；
- 镜头草稿保存稳定 ID、顺序、描述、动作、运镜、节奏和景深；
- 分镜状态与分镜帧 Asset ID 独立保存，不创建视频任务；
- 图生视频分别保存必须保持、允许变化、禁止内容、主体动作、运镜、节奏和景深。

### 过期与派生

- 增强结果、预检结果和分镜结果分别记录未创建、当前和过期状态；
- 提示词、素材、上下文、镜头、变化要求、模型或参数改变时追加对应过期原因；
- 跨生成模式派生只复制提示词和显式上下文，不自动搬运角色不明的素材；
- 派生不会创建 Task、Execution 或 Work；
- 视频作品进入基础编辑只定义最小交接意图，保留来源 Draft/Work，不含时间线、媒体引擎或导出计划。

### 仓储与 IPC

- 新增 `entities/video-workspace-drafts.json` 版本化 JSON 仓储；
- 读取和写入均执行严格运行时校验，拒绝未知模式、额外字段、错误时间、重复镜头、错误能力证据和非法素材角色；
- 仓储按当前项目隔离，拒绝保存其他项目的草稿；
- 新增 `video-workspace:create/get/update/list/derive` IPC；
- 更新使用 `updatedAt` 乐观并发检查，模式、项目、来源和创建时间不可篡改；
- 项目切换前等待视频工作区写队列完成；
- preload 只暴露受控草稿操作，不暴露路径、文件选择、上传、任务提交或远端调用。

## 二、安全边界

- 不接受 renderer 任意文件路径；
- 不返回绝对路径、原始 Hash、凭证、endpoint、远端 operation ID、内部命令或内部错误堆栈；
- 不恢复视频批量创作；
- 不把基础编辑伪装为已实现；
- 不写死服务商、模型、时长、比例、分辨率、帧率、数量、费用或素材槽位；
- 保存、更新和派生草稿均不创建外部任务。
