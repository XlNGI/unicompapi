## 一、批准边界

本支只实现不可变 ProviderExecutionRouteSnapshot、项目级原子仓储和按提交时快照执行的 submit/query/cancel/receiveResult 分发框架。未修改 React、preload、Electron 页面、公开候选、提交编排、真实协议适配器、历史数据、阶段 10 或 macOS 实机目标。

本支禁止真实服务商 HTTP、真实凭证读取/验证和收费调用。Vidu 两项已用尽预算继续封存，Image V1 未验证事实不变。

## 二、实际实现

- 新增 `ProviderExecutionRouteSnapshotV1`，固定 package、adapter、provider、connection、connection config、endpoint policy、credential version、model、Profile、Binding、ProductFeature、功能映射、Parameter/Result/Usage Schema、constraint set、RuntimeAccessPolicy 和授权 claim 的精确版本。
- 快照只保存不可变标识与 revision，不保存 Base URL、endpoint URL、API Key、Token、Authorization Header 或明文凭证；额外字段和非正 revision 均拒绝。
- 新增项目级 route snapshot JSON 仓储，提供共享写入协调、原子变更、有效备份、并发保存、跨项目拒绝、重复内容幂等和同 ID 内容冲突拒绝。
- 新增 `ProviderExecutionRouteDispatcher`，submit、query、cancel、receiveResult 四类操作都接收同一提交时快照，并只选择 `adapterKey + adapterVersion` 精确匹配的适配器。
- 当前存在同 key 的新版本时仍不回退；缺少精确版本、缺少操作或适配器合同不完整时立即停止，不读取当前默认模型或当前全局适配器，也不尝试其他服务商。
- query/cancel 使用受控远端 operation ID，receiveResult 使用主进程内部结果引用；本支只验证合成端口调用，不产生网络请求。
