# M3｜豆包视觉官方合同证据

日期：2026-08-03

适用分支：`feature/volcengine-doubao-vision-adapter`

证据用途：冻结 `VolcengineProviderPackage / DoubaoVisionAdapter` 的官方协议边界，只支持 `image_understanding` 与 `image_to_prompt`。本记录不是实时可用性证明，不批准真实 API、凭证验证或收费调用。

## 一、官方资料

- 对话 Chat API：<https://www.volcengine.com/docs/82379/1494384>
- 图片理解：<https://www.volcengine.com/docs/82379/1362931>
- 结构化输出 beta：<https://www.volcengine.com/docs/82379/1568221>
- 错误码：<https://www.volcengine.com/docs/82379/1299023>
- 返回结构：<https://www.volcengine.com/docs/82379/1298460>
- Base URL 与鉴权：<https://www.volcengine.com/docs/82379/1298459>

资料通过火山引擎官方公开只读文档接口读取；未登录控制台，未提交 API Key、用户媒体、Prompt 或业务数据，未调用方舟数据面生成接口。

## 二、冻结的请求合同

官方数据面 Base URL 为：

```text
https://ark.cn-beijing.volces.com/api/v3
```

视觉请求固定为：

```text
POST /chat/completions
Authorization: Bearer <API Key>
Content-Type: application/json
```

`model` 可以使用 Model ID；官方对多应用与精细管理场景推荐使用 Endpoint ID。本项目不登记模型名称清单，不按名称推断视觉能力。提交时不可变 `RouteSnapshot.providerModelKey` 必须保存用户登记并经受控 Profile 绑定的精确 Endpoint/Model ID。

本版本只使用单张本地 Base64 图片：

```json
{
  "role": "user",
  "content": [
    {
      "type": "image_url",
      "image_url": {
        "url": "data:image/png;base64,..."
      }
    },
    {
      "type": "text",
      "text": "应用生成的受控任务指令"
    }
  ]
}
```

本地门禁固定为：

- 图片只能来自主进程受控项目素材端口，Adapter 接收 `Uint8Array + mimeType + width + height + sizeBytes`；
- 不接受 renderer 路径、任意公网 URL、`file_id`、未知 JSON 或多图输入；
- 单图字节严格小于 10,000,000；整个序列化请求不超过 64,000,000 字节；
- 宽、高均大于 14 px；总像素位于 `[196, 36000000]`；宽高比位于 `[1/150, 150]`；
- 只接受本地已经能够安全探测的 PNG、JPEG、WebP、GIF 与 BMP MIME；
- 可选 `detail=low|high|xhigh`；本版本不同时开放优先级更高且控制面重叠的 `image_pixel_limit`；
- 可选 `max_tokens`；不发送 `frequency_penalty`、`presence_penalty`、`n`、tools、user ID 或采样参数；
- `stream=false`，`thinking.type=disabled`。

## 三、结构化输出合同

官方 Chat API 支持 `response_format.type=json_schema`，严格模式通过 `strict=true` 启用；该能力仍标记 beta。项目只使用官方文档支持的基础 Schema 关键字：`type`、`properties`、`required`、`items` 和 `additionalProperties`。

请求固定为四类字符串数组：

```json
{
  "response_format": {
    "type": "json_schema",
    "json_schema": {
      "name": "unicomp_image_observations",
      "strict": true,
      "schema": {
        "type": "object",
        "properties": {
          "visibleFacts": { "type": "array", "items": { "type": "string" } },
          "modelInferences": { "type": "array", "items": { "type": "string" } },
          "uncertainties": { "type": "array", "items": { "type": "string" } },
          "unrecognized": { "type": "array", "items": { "type": "string" } }
        },
        "required": [
          "visibleFacts",
          "modelInferences",
          "uncertainties",
          "unrecognized"
        ],
        "additionalProperties": false
      }
    }
  }
}
```

图片转提示词不要求远端直接生成最终 Prompt。`DoubaoVisionAdapter` 只解析上述观察事实，应用层固定合同再把目标用途、可见事实、模型推断和用户要求组合为可编辑提示词草稿；不确定项和无法识别项只进入独立 `model_format` 系统补充，不会被改写成可见事实。

## 四、响应、用量与失败合同

正常响应只接受一个 `choices[0]`，其 `message.role` 必须为 `assistant`，`message.content` 必须是符合上述 Schema 的 JSON 字符串。只有 `finish_reason=stop` 计为正常完成；`length`、`content_filter` 和 `tool_calls` 均显式失败。

视觉模型可能返回 `moderation_hit_type`；出现时进入 `volcengine.content_filtered`。`service_status.model_fallback.fallback_triggered=true` 时进入 `volcengine.model_fallback`，防止服务端降级破坏提交时精确路由事实。远端响应 ID、实际模型名、审核标签、原始 JSON 和响应正文不进入公开结果或安全日志。

Usage 白名单固定为：

- `completion_tokens`；
- `prompt_tokens`；
- `total_tokens`；
- `prompt_tokens_details.cached_tokens`；
- `completion_tokens_details.reasoning_tokens`。

前三项为完整用量必需项，且 `total_tokens = prompt_tokens + completion_tokens`；缓存和推理 token 不能超过各自总量。未知 usage 字段、数量矛盾或非整数进入 `invalid_response`，不得作为费用事实。

HTTP 映射冻结为：400 请求错误、401 鉴权失败、403 权限拒绝、404 Endpoint/Model 不存在、408/504 超时、413 请求过大、422 参数错误、429 限流、500/502/503 服务不可用。可重试属性只作为事实记录；Adapter 不自动重试，也不切换 Provider、Connection 或模型。

## 五、未验证与停止边界

- 未读取或验证真实 API Key；
- 未确认任一真实 Endpoint/Model ID 当前是否同时支持视觉和严格结构化输出；
- 未验证真实审核标签、fallback、Usage 或错误正文样例；
- 未执行真实 HTTP、费用或余额检查；
- Access Key 签名鉴权未纳入本版本，只支持结构化 API Key；
- 真实能力开放必须另立专项批准，并先验证具体 Endpoint 的结构化输出、用量和安全失败事实。
