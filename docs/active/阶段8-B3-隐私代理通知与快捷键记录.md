## 二、实际实现

- 新增最小授权与权限状态 DTO，固定只访问用户选择文件和授权目录，禁止用户主目录/整盘扫描与后台剪贴板读取，强制外发和未知费用确认不可关闭。原生系统设置入口只接受“文件与文件夹”“通知”两个白名单目标。
- Electron renderer 权限检查和请求默认拒绝，系统通知与原生目录等能力只通过主进程受控端口执行；不可查询的操作系统权限返回 `unknown`，不伪造已授权。
- 新增系统默认、系统代理、自定义 HTTP/HTTPS/SOCKS5 与直连的严格代理端口。代理测试使用临时隔离 Chromium Session 和固定 `https://example.com/` 空 GET，不携带项目、提示词、请求正文、服务商凭证或自定义请求头。
- 代理测试区分 DNS、证书、认证、超时与未知失败。测试失败不应用运行态；切换只作用于后续请求，状态 DTO 固定声明活动请求不重试。
- 代理用户名和值先进入主进程短期一次性句柄，renderer 共享 DTO 不包含秘密字段。确认执行时凭证写入独立 `userData/settings/proxy-credentials.json` 的 `safeStorage` 加密命名空间 `settings.proxy.v1`；设置 JSON 只保留 `authenticationConfigured` 布尔事实。
- 代理运行态、加密凭证与设置 revision 使用事务顺序：平台应用成功后才写设置，设置写入失败时恢复旧运行态与旧凭证；启动时从已保存设置恢复新请求使用的代理，不改写或盲目重提活动请求。
- 新增应用内、系统与声音通知能力和测试端口。应用内渠道始终保留，系统拒绝/不支持/失败与声音结果分别返回；结果 DTO 固定声明不修改 Task 或 Execution。
- 新增版本 1 快捷键动作注册表、Windows/macOS 独立默认值、未知动作/不可修改动作/非法 accelerator/重复键/系统保留键检测。全局快捷键只在 `app.whenReady()` 后真实注册，失败时注销新绑定并恢复旧绑定，退出时释放。
- 代理、危险隐私变更、快捷键变更及相关恢复默认操作复用一次性 plan/confirm/execute、过期与 revision 复检；普通自动保存无法绕过这些操作。

## 三、安全与恢复边界

- 设置 JSON、便携设置、renderer 状态 DTO、操作计划和日志均不包含代理密码、加密引用、绝对路径或平台句柄。
- 写入用代理值只在主进程短期内存句柄和系统加密回调内出现；句柄一次消费、会过期，系统加密不可用时拒绝暂存认证信息。
- 代理探测不复用服务连接测试，不发送项目内容，不取消或重试活动请求。探测、平台应用或设置落盘任一步失败均不把新配置标为当前有效。
- 一个平台的快捷键更新会把另一平台的有效值原样保留；未显式保存的动作按注册表默认值参与冲突检测，避免隐藏冲突。
- 系统通知只报告已交给操作系统，无法查询最终权限时明确返回未知事实；通知失败与任务业务状态完全解耦。
