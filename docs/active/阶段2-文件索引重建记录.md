# 阶段 2｜文件索引重建记录

日期：2026-07-22
分支：`feature/file-index-rebuild`
负责人：开发者 B｜本地领域与平台

## 一、本次实现

- `FileIndexRebuildService` 从 FileReference 仓储读取当前项目的全部文件事实。
- 项目内文件转换为索引条目，保留状态、基准大小、基准 Hash 和更新时间。
- 外部文件不进入项目相对路径索引，并在报告中单独计数。
- 重建先在内存中构造完整索引，再通过 `JsonFileIndexRepository.replace` 原子替换旧索引。
- 多个文件引用占用同一项目路径时，重建失败且旧索引保持不变。
- 非法项目相对路径导致重建失败，不写入部分结果。
- 重建报告包含源文件数、索引文件数和跳过的外部文件数。

## 二、事实边界

- FileReference 仓储是文件事实源。
- 文件索引是可删除、可重建的派生数据。
- 重建不探测文件内容，不修改 FileReference，不移动或删除文件。
- 外部绝对路径不写入项目索引。
