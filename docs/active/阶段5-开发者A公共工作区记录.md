# 阶段 5 A1｜开发者 A 公共图片工作区记录

日期：2026-07-23

分支：`feature/image-workbench-shell`

基线：`dda88a7 Merge image workspace contracts`

## 一、任务范围

本次只实现阶段 5 A1 公共图片工作区和五个模式的真实本地/离线状态，不实现 B2 单图导入与预览，也不实现 B3 能力预检、动态参数、任务提交或结果接收。

## 二、实际修改

- 五个图片二级页面复用一个公共 `ImageWorkbenchPage`，视频页面继续使用原有骨架。
- `creationModes.ts` 继续作为五个图片入口、页面文案和 B1 工作区模式映射的单一来源。
- 接入 `getProjectSession`、图片草稿 `list/create/update` 和服务商注册表 `getRegistry`。
- 支持在当前已打开项目中新建、读取和保存本地图片草稿；保存草稿不创建任务。
- 建立输入与上下文、画布与预览、服务与能力三个公共区域。
- 覆盖读取中、未打开项目、无草稿、无图片输入、无已启用模型、能力未知、适配器不可用和草稿保存失败状态。
- 未接入能力均明确禁用，不显示示例图片、假进度、假费用或假结果。
- 页面只显示项目名、草稿状态和动态数量，不接收绝对路径、原始 Hash、凭证或 endpoint。
