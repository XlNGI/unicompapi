# 多服务商功能路由分阶段实施计划

日期：2026-07-31

状态：M0、M1 已完成；M2 第一至第七支已合并，第八支已实现并通过自验收

计划基线：`develop@01142f7`；当前执行基线：`develop@6708072`

权威方案：`docs/active/阶段9-UI与多服务商功能路由最终方案.md`

## 一、计划结论

本项属于较大规模的后台契约、协议适配器、路由快照、历史迁移和 UI 接线工程，不能一次性实现，也不应以一个大 PR 收口。

实施采用“一支一验收、一支一合并”的节奏。每支合并后，下一支必须重新从最新 `develop` 创建。项目负责人于 2026-08-03 最新授权 Codex 按计划连续托管完成阶段 10 之前的 M2—M6，不再要求每支之间手工确认；该授权不包含阶段 10、真实服务商联网、真实凭证读取/验证或收费调用，每支仍须保留独立分支、完整证据和停止条件。

## 二、启动闸门

只有以下条件全部满足，才进入第一支实现：

1. 阶段 9 已在 Windows x64 必需目标与 macOS 延期目标边界内收口，记录为 `develop@01142f7`；
2. 项目负责人确认快速页是否移除单参考素材；
3. 项目负责人明确批准第一支 `feature/local-json-persistence-foundation`；
4. 第一支的允许修改范围、测试范围、是否联网和费用上限明确记录；
5. 当前 Vidu 真实预算保持封存，不恢复流程 8 通道。

当前状态：第 1—5 项均已满足。项目负责人已批准 `feature/local-json-persistence-foundation`，允许普通工程联网并授权 Codex 按冻结门禁自行验收及在通过后非快进合并；本分支禁止真实 HTTP 和收费调用，因此实际费用为 0。

已冻结的第 2 项产品决策（2026-07-31）：

- 快速生图固定为纯文生图 `text_to_image`，不接收参考图或其他参考素材；
- 快速视频固定为纯文生视频 `text_to_video`，不接收参考图片、参考视频或其他参考素材；
- 参考图生图、图生视频及其他需要素材的功能继续进入对应专业页面，并由显式 `ProductFeature` 与受控素材槽位承载；
- 不得根据草稿中是否存在素材静默切换快速页协议或功能。

## 五、单支执行门禁

每支分支都必须完成以下闭环：

1. 从包含全部依赖的最新 `develop` 创建；
2. 只修改该支声明的合同、适配器、测试和工程记录；
3. 补齐成功、失败、取消、恢复、并发、迁移和安全边界测试；
4. 运行：

   ```text
   npm.cmd test
   npm.cmd run typecheck
   npm.cmd run lint
   npm.cmd run build
   npm.cmd run audit:platform
   npm.cmd run verify:handoff
   npm.cmd run verify:recovery-audit
   git diff --check
   ```

5. 涉及 Electron、preload 或 UI 时增加 Windows Electron 启动、可见窗口和清理烟测；
6. 更新对应工程记录、证据和 `PLANS.md`；
7. Codex 按冻结门禁自行验收；通过后非快进合并 `develop`，保留本地与远程功能分支；
8. 合并后重新读取最新 `develop` 再启动下一支；任一停止条件触发时中止连续执行并记录阻断。

## 六、联网与数据安全闸门

- M1-M4 默认只允许临时目录、内存 transport、合成响应和零网络测试；
- 真实服务商请求、凭证验证、费用和用量验证必须建立新的专项批准，不由本计划继承；
- Vidu 两项已用尽预算不得恢复，Image V1 不得因本计划晋级；
- Token、API Key、绝对私有路径、原始响应、签名 URL、Prompt、媒体和原始日志不得进入 Git 或证据；
- 任何未知提交结果必须进入 `unknown_outcome`，禁止自动重试；
- 任何未完成本地校验的远端结果不得登记 Work。

## 七、停止条件

出现以下任一情况，立即停止当前支，不增加调用次数或静默切换协议：

- 依赖分支未合并或最新 `develop` 事实不一致；
- 迁移可能覆盖历史、丢失数据或无法恢复；
- DTO、日志、诊断或证据泄漏凭证、路径、Hash、Prompt 或原始响应；
- 适配器只能靠模型名称猜测能力，或把未知 JSON 当作兼容协议；
- 测试出现失败、未解释跳过、假进度、假用量或假 Work；
- 需要真实联网、凭证或收费但没有新的专项批准。
