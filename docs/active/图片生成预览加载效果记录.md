## 权威依据

- 最终 UI 与开发交接包 V1.2.1：图片工作台必须覆盖生成中、空结果、本地文件异常和完成结果状态。

## 实际修改

- `GenerationResultPreview` 增加可选加载态：固定预览区域、阶段文案、旋转进度环、低强度呼吸光和扫描线。
- 专业生图页按现有真实状态传递文案：准备、提交、服务商生成；不伪造百分比或时间。
- 完成结果可短暂从模糊过渡到清晰；本地作品校验、登记和远端链接回退逻辑未改变。
- 增加 `prefers-reduced-motion` 处理，关闭旋转、呼吸、扫描和完成淡入。
- 增加专业生图 UI 契约测试，钉住加载态结构、稳定高度和无百分比约束。
