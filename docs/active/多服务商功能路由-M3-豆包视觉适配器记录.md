## 一、范围

本支只实现 `VolcengineProviderPackage / DoubaoVisionAdapter` 的后台合同、合成 transport 和专项测试，承载：

- `image_understanding`；
- `image_to_prompt`。

未修改 Electron、preload 或 React UI；未启动 M4、M5、阶段 10、macOS 实机与媒体工具链；未调用真实服务商、读取或验证真实凭证、产生收费请求或恢复 Vidu 预算。

## 二、实际实现

- 新增版本化 Volcengine Ark 官方 Package、API Key CredentialSchema、固定 HTTPS EndpointPolicy、无免费验证的 `manual_exact` Endpoint/Model 登记模板；
- Package 不发布固定豆包模型名；`createDoubaoVisionModelDefinition` 对用户登记的精确 Endpoint/Model ID 生成稳定 Definition/Profile ID，能力来自受控 Profile，不来自名称猜测；
- 新增 `image_understanding` 与 `image_to_prompt` ParameterSchema，只开放可选 `detail` 和 `max_tokens`，其余请求字段由 Adapter 固定派生；
- 新增非流式 Chat Runtime，固定官方 Origin、Bearer API Key、手动重定向、系统代理、有界超时和请求/响应上限；安全日志只记录操作、状态、错误码和耗时；
- Adapter 只接受主进程受控图片字节与元数据，执行 MIME、字节、尺寸、像素和宽高比复检后生成单张 Base64 data URI；
- 请求固定关闭 thinking，使用严格 JSON Schema 四分类观察结果，不发送 tools、user ID、任意 URL、未知 JSON 或采样参数；
- 结果只公开本地生成的 observation ID 与四类文本；远端响应 ID、实际模型名、审核标签和原始响应不公开；
- 图片转提示词由应用层固定函数从结构化观察、目标用途和用户要求生成可编辑 Prompt，uncertainty/unrecognized 只进入独立系统补充；
- 仅 `stop` 完成；审核命中、非 stop、服务端 fallback、畸形结构和未知 Usage 均失败关闭；
- 单请求取消记录 `not_reported`，应用退出中断记录 `unknown_outcome`，恢复必须由用户显式创建新 attempt；
- HTTP 与 transport 失败不自动重试，不切换 Provider、Connection 或模型。
