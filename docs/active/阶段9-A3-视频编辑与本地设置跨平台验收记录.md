## 二、实际修改

- 视频文字编辑默认字体由 Windows 专属 `Segoe UI` 改为 Windows/macOS 均具备的 `Arial`，renderer 不新增平台探测或平台分支；
- 修正 FFmpeg 字体校验：解析 `drawtext` 实际解析到的字体文件，并与明确不存在字体的系统回退结果比较，拒绝把静默回退误判为所请求字体可用；
- 新增字体解析单元测试和真实 FFmpeg 集成测试，确认 `Arial` 可用且不存在字体返回不可用；
- 新增 A3 UI 契约测试，锁定编辑器错误/恢复/取消/完成状态、完成 Task 与 `workId` 双门禁、设置 10 分类、平台快捷键映射和响应式工作区；
- 保持设置页从受控 `status.platform` 读取快捷键平台，不在 renderer 使用 `process.platform`、`navigator.platform` 或 User-Agent 推断；
- 没有新增一级页面、第二套业务事实、账号商业入口、批量创作或多图参考能力。
