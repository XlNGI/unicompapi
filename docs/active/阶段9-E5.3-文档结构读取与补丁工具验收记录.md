# 阶段 9 E5.3｜文档结构读取与补丁工具验收记录

日期：2026-09-01
分支：`feature/phase9-document-intent-plan`
状态：E5.3 结构化大纲适配层与自动化验收完成；E5.4-E5.6、E6 尚未启动

## 一、实际修改

- 新增 `readStructuredDocument`，将已校验的 Word/Excel/PPT 统一大纲投影为脱敏结构摘要：文档类型、标题、章节、块类型、条目数量和字符统计。
- 新增 `parseDocumentPatch` 与 `applyStructuredDocumentPatch`，支持受控的：文本替换/插入/删除、章节增删、表格单元格更新、增加列、PPT 页面布局替换和图表创建。
- 所有目标使用结构化索引（section/block/item/row/column/page），不接受路径、URL、凭证或任意代码；未知字段和越界目标直接拒绝。
- 补丁采用不可变更新，并在返回前重新经过 `DocumentOutline` Schema 校验，原始文档对象不会被修改。
- `set_style` 暂时明确返回 `unsupported_operation`，等待 E5.4 的格式化渲染器，不静默伪造样式修改。

## 三、边界与未完成项

- 本轮适配的是已进入项目边界的 `DocumentOutline` 结构，不直接打开或写入外部 Office 文件；真实 OOXML/ExcelJS/docx 读取和写入仍需在 E5.4-E5.6 接入临时版本与发布链路。
- 当前 PPT 页面目标按大纲章节索引处理；封面/结尾页的物理页码映射由 `PresentationPlan` 负责，尚未接入真实 PPTX 形状级补丁。
- E5.4 临时版本、PDF/图片渲染、布局诊断，E5.5 `RepairPlan`，E5.6 原子发布和 E6 Windows 实机验收均未完成。
