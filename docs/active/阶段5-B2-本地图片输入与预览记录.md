# 阶段 5 B2｜本地图片输入与预览记录

日期：2026-07-23

分支：`feature/image-local-media`

基线：`dda88a7 Merge image workspace contracts`

## 一、任务范围

本次实现图片工作区的原生单图选择、真实本地校验、Asset/FileReference 登记、输入变化过期规则和受控预览，不实现上传、远端分析、生成、编辑、任务提交或结果接收。

## 二、实际修改

### 1. 原生选择与真实图片检查

renderer 只传草稿 ID，图片路径只能由 Electron 主进程单文件选择器产生。选择取消返回真实 `cancelled` 状态，不创建任何记录。

新增 Node 图片检查器，按文件字节签名而非扩展名识别本地 PNG、JPEG、GIF、WebP 和 BMP，读取像素宽高与真实文件字节数。空文件、目录、不可读文件、不支持内容、非法结构和无效尺寸分别返回真实失败状态。

检查完成后复用流式 SHA-256 校验器。校验前后重新读取图片元数据，并要求 MIME、尺寸、文件字节数和校验器读取字节数保持一致；文件在处理期间变化时拒绝登记。

这些本地可检查格式只表示桌面端当前能够安全读取基础元数据和提供本地预览，不代表任何服务商或远端模型支持这些输入格式。

### 2. Asset、FileReference 与工作区关联

用户通过原生选择器明确授权后，所选文件登记为 external `FileReference`，保存内部绝对路径、字节数、SHA-256 和验证快照；renderer DTO 不返回这些内部字段。

图片登记为 imported `Asset`，保存文件 ID、展示名称、真实 MIME 和像素尺寸。图片工作区只保存单个 Asset ID：快速/专业生图使用参考图角色，图片识别、编辑和转提示词使用源图角色。图片编辑更换源图时重建父 Asset 起点，不覆盖原 Asset 或原文件。

选择图片只保存本地事实，不创建 Task、Execution 或 Work。

### 3. 过期规则与并发协调

工作区普通更新和本地图片登记共享同一串行修改协调器，避免两个 IPC 同时写入草稿集合造成覆盖。

已有识别或图片转提示词结果时：

- Asset 变化记录 `input_changed`；
- 区域变化记录 `region_changed`；
- 用途变化记录 `purpose_changed`；
- 图片转提示词要求变化记录 `requirements_changed`。

旧观察结果和提示词仍保留，只将分析状态及工作区状态标记为过期。

### 4. 受控预览

新增安全 IPC：

- `selectInput(draftId)`：原生选择、检查、校验并登记单图；
- `getInput(draftId)`：读取安全的名称、MIME、宽高、字节数和文件状态；
- `createInputPreview(draftId)`：重新校验当前输入并创建短期预览句柄。

预览前会使用已保存 SHA-256 重新检查文件。缺失、不可读或内容变化时不生成句柄，并将可持久化的异常状态写回 FileReference。成功时仅返回 `unicomp-media://` URL、过期时间和 MIME。

媒体句柄注册表新增可信 MIME，Electron 协议响应以内容检查结果设置 `Content-Type`，因此即使用户文件扩展名不可信，也不需要向 renderer 暴露真实路径。
