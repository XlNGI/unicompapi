## 四、Windows Electron 真实闭环

使用隔离临时项目和用户目录，在生产 Electron 中完成：

1. 创建项目和空白编辑草稿；

3. 加载短期原片预览，媒体可播放且时长正确；
4. 修改导出设置但不保存，预检和开始导出保持禁用；保存后重新预检；
5. 确认真实 WebM、VP9、Opus、软件编码和空间校验时机后创建后台任务；
6. 页面显示真实排队、编码进度和完成状态；completed 前没有成功文案或作品入口；
7. 输出经独立 ffprobe、字节与 SHA-256 校验后发布，并登记 FileReference 与 Work；
8. 任务中心显示已完成视频编辑任务，作品库显示可用视频与受控预览；
9. 离开并重新进入基础编辑页后，已完成任务与 Work 恢复。

真实输出为 VP9 + Opus WebM，640×360、3.006 秒、322364 字节；SHA-256 `f13b6dbe39a81b008db73c919d3c920e36f8b4ca31034ea4e3666369f9dd9854` 与 FileReference 一致。验收结束后只清理本次测试进程、临时项目、媒体和隔离用户目录，未关闭此前存在的其他 Electron 会话。

## 五、安全与真实边界

- 一级导航没有“首页”，没有恢复批量视频、多图参考、登录、会员、充值或云同步；
- 编辑页不调用生成模型，素材选择不上传、不隐式创建任务；
- renderer 不接收绝对路径、原始 Hash、媒体引擎命令、凭证、进程句柄或内部堆栈；
- 输出格式、编解码器、质量、硬件策略和预计体积来自真实预检，不写死服务商或价格；
- 进程退出、临时文件存在和进度 100% 均不等于完成；
- 只有独立探测、Hash、fsync、不覆盖发布、FileReference、Work 和 Execution 全部成功后才公开作品；
- 当前适配器只声明 `software_only`，不会伪造硬件 attempt，软件导出不因硬件不可用而被阻止；
- `.tools`、FFmpeg 二进制和下载包保持 Git 忽略，不进入生产构建或发布物。
