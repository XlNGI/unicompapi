# UniComp 工程基线

本仓库用于承接 UniComp V1.2.1 产品、UI 与技术交接资料，并从空仓库启动工程实现。

当前状态：阶段 0｜接管审计与工程基线。

## 资料位置

产品经理交接资料已归档在：

```text
handoff/UniComp-技术开发启动包-V1.0.0/
```

开发时不得直接修改交接包中的权威资料、设计图和原始压缩包。如需形成工程侧结论，请写入 `docs/active/`；冻结后的正式结论再移动或复制到 `docs/frozen/`。

## 当前优先级

发生冲突时，以以下顺序为准：

1. 项目负责人最新明确决策；
2. `handoff/UniComp-技术开发启动包-V1.0.0/03-最终UI交接包-已解压/UniComp-AI-最终UI与开发交接包-V1.2.1`；
3. 根目录 `AGENTS.md` 与 `PLANS.md`；
4. `docs/active/` 与 `docs/frozen/` 中的正式开发记录；
5. `handoff` 中的历史归档和旧资料。

## 协作方式

- `main`：稳定基线，只合并已验收内容。
- `develop`：日常集成分支。
- `feature/*`：个人功能分支。

三名开发者建议分工：

| 角色 | 方向 | 第一阶段职责 |
| --- | --- | --- |
| 开发者 A | 工程与架构 | 技术栈、目录结构、构建、CI、规则维护 |
| 开发者 B | UI 与桌面壳 | 导航、主题、Design Tokens、页面骨架 |
| 开发者 C | 本地领域与服务 | 项目、素材、任务、作品、文件状态模型 |

## 下一步

1. 完成阶段 0 审计；
2. 明确本仓库边界：完整桌面应用，还是 API / 服务端；

5. 进入阶段 1：桌面壳、导航、主题与基础组件。
